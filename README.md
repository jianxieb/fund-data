# 标普500 与 纳斯达克 基金清单（fund-data）

交互式清单（单文件 `index.html`）+ 每日自动更新脚本（`update.py`）。数据由脚本生成，无需手动维护。

## 内容

- [`index.html`](index.html)：交互式清单——五张统一 19 列布局的基金表（标普500 ×10、纳指100场外 ×16、纳指100ETF ×12、其他纳斯达克指数场外/场内 ×5），**表格纵向完整展开（不再内部滚动）、名称列横向滚动时冻结**，支持三态排序（升→降→取消恢复默认）、Shift 双列混合排序、**手动逐行排序**（卡片标题「⇅ 调顺序」进入调整模式后用名称列的 ▲▼ 一行一行上下移动，排好点「☆ 固定顺序」存为该表默认顺序：写 localStorage、刷新与切换口径都按它排、CSV 导出同步此顺序，改动后「↺ 恢复固定顺序」找回；每张表各自一份）、天天基金链接直达。
- **页面常驻控件**：左下角「🔍 搜索」（一个关键词同时过滤五张表与可视化勾选列表，不改变已勾选基金）；右下角两个小开关——「☰ 视图：完整/精简」切换列密度（精简隐藏 代码/成立/买入费用/卖出费用/净值日涨跌/规模/备注，可视化对比里也不显示代码；打印与导出始终完整）、「⇄ 口径：累计/年化」（页面唯一口径开关，淡蓝=累计、淡琥珀=年化，基金表、基准参考表、收益/基准图与收益曲线同步，年化时自动隐藏对数Y轴）。勾选/分组/指标/形式/口径/币种/密度都记在 localStorage，刷新后保持。
- **数据总览下方有「申购变动」卡片**：每次更新与上次快照比对，列出场外基金的申购状态与日限额变化（旧值 → 新值，放宽▲/收紧▼），表内对应单元格也有角标。
- 内置 ECharts 对比图（收益柱状 / 收益曲线 / 费用 / **风险收益（波动率×收益）** / 规模 / 基准指数与 ETF / 跟踪偏离；跟踪偏离图对含主动管理期的 539001 标 ⚠）、数据总览、**完整 CSV 导出（35 列基金字段 + 基准双口径 + 数据说明）**、**A4 横向完整打印（19 列不裁切）**。
- [`update.py`](update.py)：每日更新脚本，重算净值/涨跌幅/申购限额/区间涨幅/年化波动率/回撤/场内溢价率与基准。
- [`标普500与纳斯达克基金清单.md`](标普500与纳斯达克基金清单.md)：Markdown 版清单（随 HTML 数据同步更新）。

## 数据每日自动更新

```
python update.py            # 全量：限额/涨跌幅/净值/区间涨幅/波动率回撤/ETF行情/基准
python update.py --quick    # 跳过基准（指数/SPY/QQQ，push2his 较慢且易限流），其余全刷
python update.py --hist     # 只补历史与基准（限流缓解后回填缓存用）
python update.py --offline  # 只用本地缓存
```

**当前已配置 Codex 定时任务**：每个交易日 **14:00（A 股收盘前）** 在本项目下运行 `python update.py` 并做一次体检（净值日期、是否有基金净值滞后、场内快照时间、本次申购变动），只在有变动或异常时展开说明。也可用 Windows「任务计划程序」自行调度，例如 11:30 跑 `python update.py --quick`、15:30 再跑一次全量。脚本直接改写 `index.html` 的 `/*__DATA_*__*/` 数据块（含申购变动的 `/*__DATA_CHG_*__*/`）与标题日期，静态字段（费用/费率档/备注等）不受影响。

> 提示：fundmobapi 对完整桌面 User-Agent 返回"网络繁忙"，脚本已用精简 UA 规避；接口偶发限流时自动重试/保留缓存，历史与基准可后续用 `python update.py --hist` 补齐。基准行情 push2his 限流时**自动降级新浪美股日线**（`US_MinKService`，SPY/QQQ 届时为价格口径、备注注明），USDCNY 汇率接口失败时沿用上一版各期汇率变动，人民币口径仍可计算。

### 更新字段

| 字段 | 来源 | 说明 |
|---|---|---|
| 申购状态 / 日限额 | fundf10 `jjfl_<代码>.html` | 核心。**暂停申购的基金日限额显示 "--"**（买不了谈何限额） |
| 日涨跌幅 / 单位净值 | FundMNFInfo 批量接口（失败用 jjfl 页面兜底） | 核心。表内"净值/日涨跌"列 |
| 近1/2/3/5/10年涨幅 | FundMNHisNetList 历史净值（`.tmp-hist/` 增量缓存）+ fundf10 分红送配页 | 滚动窗口、红利再投逐笔复权；ETF 份额折算用累计净值口径规避假暴跌 |
| 年化波动率 / 最大回撤（近3年） | 同上 | 风险收益图 |
| 盘中价 + **当时溢价率** + IOPV | 腾讯行情 `qt.gtimg.cn` | 生成时刻快照，页面括号内展示 |
| 基准（标普500指数/纳指综合/纳指100指数/SPY/QQQ + USDCNY） | push2his kline，失败自动降级新浪美股日线 `US_MinKService` | 人民币/美元双口径；汇率失败沿用上一版各期变动 |
| 净资产规模 | fundf10 `jjfl` 页面 | 季报口径，随页面更新 |

## 本地 / 离线使用（网络受限电脑推荐）

1. 下载本仓库（GitHub 页面 **Code → Download ZIP**，或直接把 `index.html` 保存下来）；
2. 下载 ECharts 图表库 `echarts.min.js`（约 1MB，任一国内镜像均可）：
   - https://registry.npmmirror.com/echarts/5.5.1/files/dist/echarts.min.js
   - https://cdn.bootcdn.net/ajax/libs/echarts/5.5.1/echarts.min.js
   - https://cdn.staticfile.net/echarts/5.5.1/echarts.min.js
   - https://lib.baomitu.com/echarts/5.5.1/echarts.min.js
3. 把 `echarts.min.js` 和 HTML 放在**同一个文件夹**里，双击打开 HTML 即可——页面优先加载本地图表库，完全离线可用；若未找到本地文件会自动回退到 jsDelivr / unpkg / BootCDN / staticfile 四个在线源。
4. 图表库加载失败也不影响表格、排序、过滤、CSV 导出与打印；盘中价/溢价率为数据生成时刻的快照，不依赖页面联网。

## 口径

- 只保留 A 类人民币份额：C/D/E/I 与美元现汇/现钞份额剔除。
- **区间涨幅**：按累计净值（含分红再投资）计算，**滚动窗口**——以最新净值日回推 1/2/3/5/10 年，取该日前最近交易日为基期；成立不足 N 年标注 "--"。国泰纳指100（160213）、大成标普500等权重（096001）等有分红基金按红利再投逐笔复权。
- **年化收益率** = (1+区间涨幅)^(1/N)−1；由右下角常驻的「⇄ 口径」小开关一键切换，基金表、基准参考表、收益/基准图与收益曲线同步；导出的 CSV 始终同时包含累计与年化两套列，不受开关影响。
- **场内溢价率** = (盘中价 − IOPV)/IOPV × 100%（腾讯行情 IOPV 口径）。QDII 净值 T+1 公布，隔夜美股大涨大跌时溢价率可能失真，请对照 IOPV。
- **买入/卖出费用**：场外两列=申购费（原费率/1折）与赎回费档（按持有期递减）；场内两列=券商佣金（默认万2.5、最低5元/笔，顶部工具栏可改），ETF 免印花税/过户费、买卖同费率。场内行的申购状态/日限额显示 --（类别列已区分场内场外）。
- **风险收益图**：X=近3年年化波动率（日收益标准差×√250），Y=近3年年化收益率，气泡=规模，提示框含最大回撤。
- **排序**：默认清单原始顺序；点击表头 升序→降序→再点取消恢复默认；Shift+点击另一列追加第二排序键（最多两列）；空值恒排最后。排序状态挂在表头的 `data-key` 上，切换累计/年化重建表格后仍然保留。
- **手动顺序**：每张表标题右侧「⇅ 调顺序」→ 名称列出现 ▲▼，逐行上下移动（移动时自动取消该表的列排序，否则排序会盖住手动结果）→「☆ 固定顺序」把该表当前行顺序与列排序写入 localStorage，页面默认进入、切换口径重绘都按它排；有改动时出现「↺ 恢复固定顺序」。基准表不参与。
- **更新可靠性**：`update.py` 写回前会自检（43 行、必需字段、数值范围、META/BM 结构），不通过就整份放弃并把退出码置为非 0；写回方式是先备份到 `.tmp-snap/index.html.prev` 再临时文件 + 原子替换。净值接口缺日涨跌幅时显式置 `--`，不再把上一净值日的涨跌幅配到新净值上。
- 数据来源：天天基金/东方财富公开接口（fundmobapi.eastmoney.com、fundf10.eastmoney.com、push2his.eastmoney.com）、腾讯行情（qt.gtimg.cn）与新浪美股日线（基准兜底）。天天基金 fundgz 估值接口已停用（404），ETF 估值改用腾讯 IOPV。
