# 长衡 · 全球投资研究工作台

**理解市场，研究资产，检验投资方案。**

长衡面向中国个人投资者，把宏观金融、指数与基金、公司研究、历史回测和投资成本连接起来。既研究资产过去如何表现，也检验买入时点、持有年限、投入方式、组合权重及资金路径如何改变结果，为自己的投资判断提供依据。

[打开长衡](https://jianxieb.github.io/fund-data/) · [产品定位与边界](docs/product-decisions.md#current-positioning) · [数据更新与维护](docs/maintenance.md)

## 从一个投资问题开始

| 想弄清楚的问题 | 可以使用的研究工具 |
| --- | --- |
| 美元、通胀和利率如何传导到股票、债券、黄金与房地产？当前指标处在自己的什么历史位置？ | **金融传导、历史事件、历史分位**：条件与反例、政策快照、计算实验，重大事件时间线与实际回报，以及价格与指标叠图、历史分位表和年度表现 |
| 研究什么市场和工具？基金收益来自谁的任期，公司盈利能否持续？ | **指数观察、基金研究、个股深入**：区分指数与可投资产品，比较长期收益、风险、费用及财务和经营证据 |
| 同样买一只资产，换个月份买、持有更久、分批投入会怎样？搭成组合又会怎样？ | **持有期研究、投入策略、组合模拟**：完整历史窗口、过程中的亏损与回撤、现金流、再平衡和持仓贡献 |
| 通过什么渠道持有？税费怎样影响结果？资金如何汇出、取回或消费？ | **投资渠道、跨境资金**：境内外工具的历史成本比较、税种与扣缴依据、分红实例，以及分步资金和收费路径 |

研究总览汇集这些入口；**数据与方法**提供各数据集的来源、观察日期、计算检查和具体缺失证据。各环节既能独立使用，也可围绕同一投资问题继续研究。

## 当前能研究什么

- **市场与资产**：以中国内地和美国的指数、ETF、基金及个股为主，覆盖主动权益、红利、债券固收、宽基、行业及海外工具。指数观察设美债ETF页签，覆盖超短至长债、全期限国债及通胀保值国债。价格指数、ETF和公司股票参照分别展示；研究池与精选名单的实际范围以页面为准。
- **市场历史**：标普500、纳斯达克100各自与其历史比较；把价格和有真实来源的估值、波动、利率等指标放在同一时间轴。每项指标使用自身可核验的覆盖期。
- **公司与基金**：基金的经理任期、净值回报、风险和费用；A股与美股的财务、经营、估值、股息及深入报告。可筛选、排序、查看来源和导出研究数据。
- **持有与投入**：已收录海外ETF及美股的1/2/3/5/10年完整持有窗口，美元或人民币口径；一次投入、分批和定投等历史模拟，分别查看资金收益与净值风险。
- **收益对比**：按类型、市场、方向及代码选择指数、ETF、基金和个股，使用共同日期叠加累计收益，附加区间年化；查看回报柱状图、逐年收益表和回撤曲线，支持美元、人民币及原币与每日CSV导出。
- **组合验证**：按自定权重配置已收录ETF、个股和基金，检验投入、再平衡及费用假设，查看资金XIRR、组合走势与持仓贡献；支持配置导入导出及PDF/CSV。模拟配置保存在当前浏览器。
- **渠道与资金**：国内场内、场外产品与海外ETF的同日人民币历史情景；投资渠道的税种、抵免、QQQI/QQQ/SPY/可口可乐实例及银行券商扣缴依据；内地—香港—证券账户及回款、消费的分步费用测算。
- **ETF分红与再投**：查看近12月及单次分配率，拆解历年价格与现金回报、分红占收益的比例和分配税情景减少的百分点；比较领取现金与DRIP，以及IBKR、汇丰Trade25、富途香港的支持条件与扣缴规则。普通股息、合资格利息分配和ROC分别解释，最终分类注明适用年度。
- **历史事件**：全球金融独立为导航大类，包含金融传导与历史事件。15个阶段串起事件经过、真实累计回报曲线、柱状图、不同交易日期限的回报表和传导分析；涵盖互联网泡沫、金融危机、关税、疫情、加息及伊朗冲突。进行中事件与未完成期限明确区分，事实节点附机构原始来源。
- **金融机制**：货币、通胀、利率、信用、债券、股票、黄金、房地产与周期产业的关系，通过传导图、例子、反例和计算实验说明成立条件。

“全球”是研究视角，当前资产与指标数据并未覆盖所有国家、证券或历史时期。数量、入选结论、观测日期与缺口由实际生成数据提供，README不固定滚动更新的数字。

## 怎样理解研究结果

长衡保留**来源、日期、口径和缺口**，让不同结果能在明确条件下比较。

- **先看身份与回报口径**：指数点位、ETF复权价格、基金净值分别记录；价格回报与含分红回报、美元与人民币、累计与年化需区分。SPY可作含产品费用的投资工具参照，不能冒充标普500全收益指数。
- **只使用有证据的历史**：不足完整期限就列明缺口，不用成立以来代替十年，也不借用其他指数或插值补造路径。基金分红、拆分和股票送转按各自证据处理。
- **区分资产表现与资金结果**：已有资金分批买入前仍在现金账户；后续新投入才是外部现金流。XIRR、现金流中性收益、最大回撤与本金亏损分别表达不同问题。
- **成本保留适用条件**：历史净值已扣的持续费不重复扣除；交易、汇兑和投资者税费按对应模型列示。银行券商规则、税收身份、收入性质和证据日期在详情中说明；缺失费用不默认为零。
- **历史结果保留统计边界**：历史分位、亏损窗口占比、公司入选结论与回测结果用于研究；重叠窗口、样本选择和存续证券偏差可能影响解释，不能直接当作未来概率或收益承诺。
- **核验范围可查**：计算检查通过与原始资料已被独立核验是两回事。部分指标预测期间、基金规模观察日或银行当笔报价等证据仍可能缺失；以[当前质量报告](data/quality.json)及各页状态为准。

当前产品提供公开研究和假设情景模拟，不连接真实证券账户、不执行交易，也不自动生成适合个人的最优配置。税务内容按已列明身份和条件解释，不替代实际账户扣缴与个人申报核定。

## 本地运行

前端为静态网页，直接读取仓库内的公开快照，无需安装npm依赖、前端编译或外部图表库。

```sh
git clone https://github.com/jianxieb/fund-data.git
cd fund-data
python3 -m http.server 8765 --bind 127.0.0.1
```

打开[本地长衡](http://127.0.0.1:8765/)。Windows可将 `python3` 换成 `python`。本地浏览请保留完整仓库目录，不能只复制HTML文件。

## 数据更新与开发

界面、纯计算与Python数据管道分别维护。运行数据脚本需要Python 3.9+、Node.js 18+；安装依赖后可按数据集刷新。

```sh
python3 -m pip install -r requirements.txt
python3 refresh.py --datasets indices      # 按数据集刷新，最后自动检查质量
python3 refresh.py                         # 默认更新流程
```

首次克隆已含可浏览快照。完整原始抓取缓存不入库，`refresh.py --offline` 缺缓存时会明确失败，不能视为已重算成功。全市场发现、基金资料核验、公司报告更新与日常行情刷新是不同任务；具体入口见[维护指南](docs/maintenance.md)、[自动更新方案](docs/automatic-update-plan.md)及[公司研究流程](company-report/SKILL.md)。

完成代码或数据修改后，更新资源摘要并运行相应检查：

```sh
npm run version-assets
npm run check
npm test
python3 -m unittest discover -s tests -q
python3 data_quality.py --strict
python3 scripts/build_portfolio_data.py --check
python3 scripts/build_etf_distributions.py --check
python3 scripts/build_return_indices.py --check
python3 scripts/build_financial_events.py --check
```

`refresh.py`不会自动提交或推送。发布时先同步远端更新，保留定时刷新结果；按独立改动提交并立即推送，由GitHub Actions校验及发布至Pages。失败记录、更新日期与缓存状态可从 `data/update-status.json` 和 `data/refresh-report.json` 追溯。

| 目录 / 文件 | 内容 |
| --- | --- |
| `index.html`、`assets/` | 导航、页面、交互、图表及前端计算模型 |
| `data/` | 展示快照、来源与核验证据、组合日度历史、质量及更新状态 |
| `refresh.py`、`scripts/`、`screens/` | 数据更新、计算、研究筛选和校验 |
| `company-report/` | 公司取数、计算与报告研究流程 |
| `tests/` | 前端模型与Python数据流程的回归检查 |
| `docs/` | 研究方法、维护流程、决策沿革和审查证据 |
