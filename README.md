# 长衡 · 长期投资研究

公开的长期投资研究仓库。把指数、基金、股票与投入策略放在可比较、可追溯的研究框架中，帮助读者理解长期表现、风险、成本和数据边界，再作自己的投资判断。前端为静态网页，Python 数据管道独立运行，不修改界面。

**先观察海外指数，再研究国内与海外的长期主动权益基金；红利、债券与固收集中进入另一研究入口，以标普500作参照。**

## 开始使用

在仓库目录运行：

    python3 -m http.server 8765 --bind 127.0.0.1

浏览器访问 http://127.0.0.1:8765 。无需安装 npm 包、前端编译或加载外部图表库。离线使用请保留整个仓库目录，不能只复制 HTML 文件。Windows 可将 python3 换成 python。

综合策略、行业与主题策略使用相同的主动权益门槛，可在同一页筛选；本次批量恢复及收益复核见[基金策略范围恢复](docs/research/fund-theme-restoration-2026-09-30.md)。个股由全市场财务发现和逐家公司经营研究接入，初筛线索不自动进入产品名单。

基金支持并排对比和公开研究结果 CSV 导出；来源、计算区间和长篇费率条款可在详情中查阅。

## 项目定位

采用**公开研究站 + 可追溯数据管道**。研究内容围绕指数与产品是否可比、候选为何入选、长期风险有多长历史支持、成本有哪些缺口、投入策略比较是否公平展开。每项比较都需交代样本、时期和口径，历史数据不自动给出未来结论。

“长衡”同时表达长期与权衡，覆盖基金以外的研究对象。方案比较、定位变更、初始问题清单和验收要求见 [产品决策](docs/product-decisions.md)。

跨境资金页面的全部用户要求、复发问题、截图证据和发布检查统一记录在[跨境资金需求与验收清单](docs/money-flow-requirements.md)。修改该页面前先对照清单；实现或测试通过不能自行替代产品验收。

## 数据与指标的关键规则

- **指数独立计算**：上证等指数直接取编制机构日线，收益与有无关联基金无关。国内公开数据来自中证指数与国证指数。[万得微盘股指数官方页](https://www.windindices.com/indices/zh/IndexF9/1a073179a3f0bebf923a0259cee963e4)能核对指数身份，但当前没有接入可复核的完整授权日线，因此该指数的收益与风险留空。
- **不混合价格与总回报**：价格指数不含现金分红。基金与ETF的复权定义、币种和区间需分别检查，不把不兼容差值称为跟踪误差。
- **标普500是研究参照**：分别提供价格指数和 SPY ETF 含分红复权参照，后者含产品费用，不冒充指数全收益序列。比较需匹配期间、截至日、币种与回报类型；价格指数与含分红基金回报的差值不能直接用于“跑赢”或超额收益结论。
- **完整周期才显示**：不足期限不以成立以来年化替代10年；风险要求覆盖真实期间。指数发布前的回溯历史另行标记。
- **分红与拆分分开**：基金收益使用明确每日收益或可识别企业动作构建链式序列，拒绝把累计净值之比冒称再投资收益；跨策略转型窗口单独处理。
- **费用分项**：主表用一列汇总管理、托管、销售服务费，悬浮、详情及CSV保留每一项；买入与卖出费用仍分别展示。历史渠道折扣与无持有期的旧赎回费档不能当成交费率。
- **经理任期逐人记录**：以明确的个人上任日计算，经理团队组合变化日不等于每个人的上任日；历史业绩不全属于现任团队。缺少个人日期时不猜补。
- **候选是研究入口**：门槛、名额约束、逐只理由与结果由 data/screening.js 生成，不等同购买推荐。完整旧池保留，但有收益预筛和幸存者偏差；数量少不等于更适合每一位读者。
- **研究范围不冒充全市场**：资产类别、地域、主动或指数、交易渠道与份额分别描述。现金、债券、黄金等覆盖缺口需要补充可核验研究资料；混合基金与固收+不能凭名称归为纯债。
- **历史窗口不是时间曲线**：基金与指数的1/2/3/5/10年区间回报只用于并排比较，不拼成净值曲线。投入策略有“结果表”“曲线对比”两个视图；曲线可比较同一投入方式下的全部可用ETF，或同一ETF的六种投入方式，选择实际账户金额或截至观察日的资金加权年化 XIRR。前者按每周最后一个实际交易日取样，后者满28天后按月末实际交易日取样；首年值是短期年化推算，悬浮可读数，杠杆ETF单独标记。可选1993、1999、2001、2010、2020年起，实际开始日取当年之后所有可用标的的首个共同交易日，上市前不补数据。曲线由对齐的ETF日度复权行情和现金账户逐日计算，不插值或从几个区间收益倒推路径。完整口径见[策略曲线说明](docs/strategy-curves.md)。
- **投入策略现金正确入账**：已有资金首日全额进入账户，等待买入仍作为现金；后续定投才是外部入金。交易成本不能让现金变负；不同投入预算要同时比较累计投入、账面盈亏与XIRR。结果表对两种资金情境都列出相对累计投入本金的最差账面盈亏、低于本金最长交易日，以及剔除外部入金的净值回撤；同一ETF满仓定投的净值风险相同，不代表各投入方式的账户结果相同。[独立账本与发行人业绩核对](docs/strategy-leverage-audit.md)给出复算方法和范围。
- **买入渠道税后比较**：对同一指数分别比较美股 ETF、国内场内 ETF 与场外基金。历史价与净值已包含产品持续费用；交易费、换汇价差、分红税、卖出收益税按可调假设逐笔入账。大陆税收居民通过香港券商持有美国 ETF 的税务假设、共同交易日、场内溢折价和模型边界见[买入渠道研究方法](docs/buy-location-method.md)。固定公开快照由 `scripts/build_buy_location_data.py` 生成。

当前数据的逐项核验情况见 data/quality.json，真实源抓取与修复证据见 [数据链路审计](docs/data-pipeline-audit.md)、[指数与筛选审计](docs/indices-screening-audit.md)、[经理字段审计](docs/manager-field-audit.md) 和 [官方资料抽查](docs/official-source-spot-check-2026-09-24.md)。计算检查通过不等于全部原始资料已经独立验证。

## 更新

个股研究整合了 `jianxieb/stock-research` 的公司研究资源。当前筛选口径见[长期优质与高质成长](docs/stock-quality-method.md)，与五个开源项目、七份 skill 的逐项对照及修订见[研究工具比较](docs/research/stock-skill-comparison-2026-09-30.md)。可复用的研究流程在 [company-report/SKILL.md](company-report/SKILL.md)。

    python3 company-report/scripts/01_fetch_data.py 601138 --as-of 2026-09-30
    python3 company-report/scripts/02_compute.py company-report/data/601138/summary.json
    python3 scripts/build_stock_reports.py
    python3 scripts/build_stock_reports.py --check

取数后需审阅公司原始公告，并更新 `data/stock-report-research.json` 的业务判断、风险和证据日期，才能生成对应日期的报告。报告输入冻结行情、财务和当时的分类依据；定时行情刷新不会改写旧报告的日期或结论。网页版由 `data/stock-reports.js` 提供，Markdown 和原版修订记录位于 `docs/company-reports/`。

分步操作、扩展基金核验、失败排查与发布流程见[数据更新与维护指南](docs/maintenance.md)；GitHub Actions 的定时抓取、验证与 Pages 发布见[自动更新方案](docs/automatic-update-plan.md)。

需要 Python 3.9+；数据校验和筛选策略解析还会调用 Node.js 18+。Windows 等缺少 IANA 时区数据库的环境还需安装 requirements.txt 中的 tzdata，用于正确识别汇率日线交易日期。

    python3 -m pip install -r requirements.txt

    python3 refresh.py                         # 全部数据集，单项默认限时180秒
    python3 refresh.py --offline               # 仅回放已有缓存，不联网
    python3 refresh.py --datasets indices      # 指数 + 最后自动运行质量检查
    python3 refresh.py --datasets funds --timeout 90
    python3 verify_samples.py                  # 代表样本与企业动作证据
    python3 update.py --managers-only --refresh-managers  # 仅重新核对基础基金集的经理资料
    python3 screens/fund_screen.py managers --codes all --refresh  # 核对扩展研究池全部经理资料
    python3 screens/fund_screen.py policy      # 根据当前快照重新生成研究候选

细粒度入口仍可用：update.py、indices.py、stock_screen.py、strategy_backtest.py、screens/fund_screen.py。全市场初筛/丰富/指标抓取是独立研究任务；日更的 screening 阶段重新应用研究规则，**不会假称已更新上千只国内基金的净值**。

daily_update.ps1 调用相同更新入口，兼容 Windows 原有调度命令。它不创建或修改操作系统任务计划，也不自动提交或推送；更新后由维护者审核并发布。

数据写回使用原子替换，统一入口有并发锁；验证失败与数据源失败返回非零状态，允许其他数据集继续运行。所有刷新最终执行质量检查。
统一入口会撤销失败阶段对页面数据文件的写入，保留该阶段的失败日志和状态。准备发布快照时，先运行`npm run version-assets`更新HTML中的资源内容摘要，再运行`npm run check`核对版本，避免已缓存的旧脚本配上新数据；[新环境验证](docs/fresh-clone-validation.md)记录了不带本机缓存的实际回放。

## 指数产品覆盖与当前爆发股复核

- 指数产品不套用主动基金的长期收益门槛。`data/index-fund-catalog.json`补充55只代表产品，包含宽基、主要行业、细分主题、商品及债券；不是全市场ETF清单。每只保留实际跟踪指数、净值历史和费用来源。重建：`rtk proxy python3 scripts/restore_index_funds.py`；后续由已核验产品的每日刷新更新。
- 行业板块筛选按名称及跟踪指数归类，多个板块取并集，与交易渠道等条件交集；不声称已穿透基金最新持仓。新产品可展示净值，未满周期的收益及风险留空。
- 爆发股的商品价格、并表、低基数和交付来源设为独立发布条件，见[2026-09-30复核](docs/research/breakout-cycle-review-2026-09-30.md)。科创/创业板可在个股页面一键隐藏；长期与成长重叠用公司名称颜色和浅底标识。

### A股与美股研究

个股深入按A股、美股分市场，并各设长期优质企业、高质成长股、业绩爆发股、红利价值、其他已收录五类。美股覆盖62家跨行业蓝筹和成长候选，使用SEC历史财报与本期业务来源复核；苹果等未满足当前门槛的蓝筹仍保留完整研究。财务、估值、收益风险、行业筛选、深入报告及组合模拟均可使用。计算与更新规则见 [美股个股研究](docs/overseas-stocks.md)。
