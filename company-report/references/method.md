# 研究与计算口径

## 质量、成长与价格分别判断

长期优质看多年盈利、资本回报、现金回收与业务持续性；高质成长看当前主营盈利的连续扩张；估值判断另列。股价上涨不作为质量证据，不用历史收益反推门槛。参数是本项目研究定义，不是全A股排名或市场共识。

2026-10-01起，营收增速继续展示，取消统一的营收同比/CAGR淘汰线。总收入会受贸易、净额确认、产品组合、价格及合并范围影响，不能取代扣非盈利和资本回报。必须有真实、正的营业收入金额，利润增长、ROE与现金条件继续检验。

- **长期优质**：连续5年正归母、正扣非及正经营现金流；5年平均年度ROE≥15%且各年为正；近3年平均ROE≥15%、各年≥10%、最新年≥15%；近3年归母/扣非逐年增长且相距3年的CAGR均≥10%；最新完整年度及最新累计归母/扣非增长均≥10%；当期ROE为正且比上年同期相对下降≤20%；实际价格历史≥5年，并有当前报告期的持续经营、再投资和失效信号研究。
- **高质成长**：最新累计以及连续两个相邻单季，归母与扣非同比均≥30%，基数为正；扣非/归母≥80%、当期ROE为正；最近两个完整财年归母、扣非及经营现金流为正；上年年度ROE≥10%、TTM经营现金流为正；当前经营证据与盈利贡献复核均成立。
- **业绩爆发**：最新累计及连续两个相邻单季，归母与扣非同比均≥100%，基数为正；扣非占比≥80%、当期ROE为正；两年正利润/扣非/经营现金流，上年年度ROE≥5%；本期经营现金流≥归母50%、TTM经营现金流为正；量化复核增长来源、周期、并表、低基数及费用。主表仅展示未进入前两类的公司。

三类均限定沪深非ST、非金融企业，总市值≥100亿元。成长和爆发不因上市不足一年而删除财务记录，缺少的收益区间/PE分位保留空值。完整参数与日期约束以 stock_fundamentals.py、stock_groups.py 为准。

## 盈利贡献复核

成长和爆发共享本期 earningsReview，分别保存 growthDecision / breakoutDecision。必须有数量或金额、单位、公告URL、来源位置、报告期、核对日及 disclosed / calculated / estimate 口径；不能把一个笼统风险标签当作完成拆分。

1. 取公司主要会计数据及合并利润表。用营业成本 OPERATE_COST 计算毛利，不用包含费用的营业总成本替代。收入规模效应=(本期收入−上期收入)×上期毛利率；毛利率效应=本期收入×(本期毛利率−上期毛利率)。两者之和必须等于毛利增量，但分别包含量、价、成本、组合及范围变化，不能冒称纯销量或纯提价。
2. 有同一产品的可比销售数量、平均售价和单位成本时，计算：销量效应=销量变化×上期单位毛利；售价/组合效应=本期销量×售价变化；成本效应=−本期销量×单位成本变化。单位先统一。产量、库存、受控运力不能替代销量；平均售价还可能包含品位、产品结构、汇率。披露值四舍五入或成本由增幅倒推时标为估算。
3. 从毛利到归母扣非，另桥接其他税前损益、所得税、少数股东归属及非经常损益扣除。产品表在内部抵销前时，不将产品贡献总和等同合并归母利润。
4. 并购先确认合并日期及比较数据是否已经重述。同一控制重述后的上年比较不能再扣一次被并购公司；已披露的归母贡献不能再乘持股比例。子公司全口径净利润不等于对母公司的归母扣非贡献；H1贡献不能任意摊到Q1/Q2。
5. 未逐产品披露量价时，继续查问询回复、审阅/审计报告、重大资产报告及公司投资者记录；金额桥仍可完成，并具体说明未能单独识别的分项。卖方预计销量只能作为预测，不能补成公司已实现数据。公司明确未公开的单季贡献写明披露限制，不能造数。

价格贡献不自动否定具有多年回报和现金记录的成长企业。独立爆发还须有可核对的实际交付、产能释放或产品升级依据：主要靠即期商品/运价修复、缺乏独立结构性贡献的企业不发布。已锁定订单的交付变化与现货涨价分别分析。高PE不孤立否决，周期高点的低PE不当便宜证据。

## 财务和现金

- 取40期主要指标、32期资产负债表/现金流及最近8期累计利润表。五年表必须包含五个完整年度；中报单列。供应商重述数据仅支持当前已知口径回顾，不是无前视偏差回测。
- TTM金额=最新累计+上年全年−上年同期。PE用同日市值与当时已公告的TTM归母金额，不相加不同股本下的EPS。A/H公司的来源市值口径与利润金额复算并列，不强行覆盖。
- 单季=累计减上季累计；同比须上年同季正基数。ROE不相减、不年化。
- 经营现金流减购建长期资产支出只是资本开支后的现金余量，不是严格FCFF。缺失保持空值；不能默认取绝对值掩盖异常。
- 应收、库存与同期间收入、回款和季节性比较；较年末变化不能冒充同比。金融租赁、银行、保险采用行业模型，不套工业净现比。

## 预测、股息与估值

- 卖方输入列机构、发布日期、预测财年、EPS、股本及来源。同机构同年只留最新一条，剔除未来/超过180天/字段不明记录，不同股本口径分开。仅称公开研报样本。
- 自建预测须有分部收入、利润率、股数桥接。PEG来自同一套假设，不用单一阈值判断便宜。
- 可比公司有主营/盈利模式依据，排除自身，统一日期、币种及TTM/预测财年；不足3个合格样本不输出中位数结论。不默认固定PE倍数或目标价。
- 股息按实施状态、公告日、除权日过滤，按所属财年合计；滚动12月按除权日，送转前后另作股本调整。未来预案不计已实现股息。
- DCF需经营预测、税后EBIT、折旧、资本开支及营运资金桥接。现金流暂负不等于禁止DCF，缺可信预测才不估值。
- WACC用权益/有息债务市值权重；现金在企业价值到股权价值中单列。贴现率、终值增长有依据和敏感性，不设通用10%。

## 更新范围

研究日、行情日、财报期及公告日分别保存。行情刷新不改旧业务判断日期；新财报仅能自动重算财务门槛，经营复核未覆盖新报告期时不延续成长资格。未入选研究留在报告及审计记录，不在主表堆“未通过”。发现范围、已复核范围和实际发布名单必须分别计数。
