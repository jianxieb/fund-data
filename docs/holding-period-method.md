# 持有期研究

## 页面目的与范围

回答“买入月份不同，持有同样久，历史结果相差多大”，而不是用当前估值预测未来回报。独立入口为 `#holding-period`，默认伯克希尔 B 类股 `BRK-B`、美元、持有 2 年。标准链接如 `#holding-period?symbol=BRK-B&currency=CNY&years=2` 保存证券、收益币种和期限，刷新或分享后恢复这三个选择。累计/年化遵循项目共享偏好，未提供偏好时初始使用年化，不单独写入链接。

保留 `#holding-period/QQQ`、`#holding-period?symbol=QQQ` 及 `#holding-period/QQQ?currency=CNY&years=5` 旧链接。查询参数的 `symbol` 优先于旧路径；目录加载完成后才核对证券身份，并用 `history.replaceState` 规范为标准链接，筛选操作不增加后退记录。币种仅接受USD/CNY（不区分大小写），期限仅接受1/2/3/5/10；缺失或非法值分别回到USD/2。证券代码与目录按大小写无关匹配，未收录代码保留具体缺失状态，不替换为其他证券。无浏览器location/history的独立渲染仍可使用传入的symbol和页面控件。

支持公开组合目录中 `market=us`、`currency=USD`、`kind=stock/etf` 的证券。个股、ETF保持自身身份，指数点位不进入该名单，不用ETF代替未收录指数。来源、成立前历史和缺口继续遵守现有[组合历史方法](portfolio-method.md)。

此页是历史研究，不提供买卖规则、预测成功率或收益保证。

## 数据加载与校验

- 复用 `data/portfolio/catalog.js` 的已发布目录及带内容摘要的单证券历史文件，只按需载入所选证券和必要汇率。
- 浏览器检查历史文件 SHA-256 与目录一致，随后检查证券 ID、币种、回报口径、分红再投标记、目录/历史起止日、条数、严格递增日期和正数有限价格。
- 仅接受 `provider_adjusted_close`；缺历史、身份冲突、文件损坏分别显示具体原因，不更换另一证券或补历史。
- 人民币换算使用目录的 `fx:CNY` / `CNY=X`，表示每美元对应多少人民币。缺汇率不影响美元研究，其他可用证券也继续可选。
- 文件一致性与计算校验不代表已独立核验全部供应商原始行情。价格来源保留在页面详情与CSV。

## 历史窗口

1. 期限固定为 1、2、3、5、10 年。每个已经结束的自然月取最后一个真实股价交易日作为买入收盘日，不包含当月尚未结束的月末样本。
2. 买入日期距离该月日历月末不得超过 7 天，防止长期缺价被误识别为月末交易。
3. 目标终日为买入日加相应自然年数。闰年 2 月 29 日在非闰年取 2 月最后一天。实际卖出日为目标日及此前 7 天内最近真实收盘日，不取未来交易日。
4. 目标终日必须已经到达研究截至日。未走完的持有期不以截至日提前卖出，也不将短期收益外推成完整窗口。
5. 持有区间内部若相邻股价观测相隔超过 14 个日历日，则剔除该窗口。这是公开行情完整性规则，不是交易所日历认证；期间正常休市保留真实日期。
6. 人民币仅对股价的起止端点配汇率，分别取当日或之前 7 天内最近有效观测。缺任一端点就排除该人民币窗口。原币窗口仍保留。汇率实际日期和数值逐条导出。
7. 缺完整窗口时保留空值及原因，不使用成立以来回报替代较长期限。页面汇总逐项列出被剔除窗口的数量与原因。

## 计算

设复权价为 `P`，USD/CNY 为 `F`：

```
美元持有倍率 = P_end / P_start
人民币持有倍率 = (P_end / P_start) × (F_end / F_start)
累计收益 = (持有倍率 − 1) × 100%
实际年数 = 实际起止日历天数 / 365.2425
年化收益 = (持有倍率 ^ (1 / 实际年数) − 1) × 100%
```

按指数、基金和股票区间表的实际天数年化口径计算。周年日休市会使某些一年窗口略短于一年，此时仍按真实天数年化，不改写实际日期或补齐价格。明细与CSV提供实际起止日和年数；该规则与组合模拟专门的首年显示规则不同。

复权序列已包含供应商定义的税前分红再投资，ETF运营年费已经反映在序列中，不额外增加分红、不再次扣产品年费。未计个人股息税、卖出税、佣金、买卖价差和换汇价差。

最近区间单独计算：以最新实际股价日为终点，起点取其向前相应自然年的目标日及此前 7 天内最近真实收盘。它通常不是月末窗口，所以仅作参照，不混入历史月末样本数。当前年化在历史样本中的位置为中位秩：`(小于当前的样本数 + 相等样本数 × 0.5) / N`。

## 展示与统计解释

- 主曲线横轴是买入月份，每个点代表一段完整的持有区间，纵轴为当前选择的累计或年化收益；它不是账户净值路径。最新区间用水平虚线单列。
- 表格包含每个期限的样本数、中位、10%—90%分位、最好/最差收益及真实起止日期。分位采用 R type 7 线性插值。切换累计/年化后，先读取每个真实窗口相应的收益，再分别排序并计算统计；不能把年化中位数直接按名义年数复利后当作累计中位数，因为实际持有天数并不相同。当前区间的历史分位也使用所选口径。
- “历史亏损月份占比”是期末累计回报严格小于 0 的买入月份数除以有效样本数。零收益不算亏损；无样本不显示 0%。
- 月度窗口大量重叠，既不是独立试验，也不是未来亏损概率。不同持有期限和币种的样本区间可能不同，不能由表中频率机械推出哪种期限或币种更安全。
- 当前收录证券存在人工选择和存续证券偏差，未收录已退市或清盘的完整总体。ETF的历史策略、杠杆目标或跟踪基准可能发生过变更。目录已记录的策略变更（例如XMMO）在页面直接展示具体边界，并随CSV导出当前策略起日、历史说明与来源；较早样本不冒称当前策略的完整历史。
- 查看具体窗口时，以初始价值 100 展示自身含分红持有路径。人民币路径中间日也最多沿用此前 7 天内汇率；缺失时断线。只要两端证据完整，区间收益仍有效，不补出中间行情。
- CSV包含全部当前期限样本的原始精度数值、股价与汇率日期、持有倍率所需端点、证券身份、来源、累计及年化收益，并单列当前展示口径与对应收益。窗口路径风险及缺失日期同步导出，无风险证据时留空而不是0。

## 持有途中风险（2026-10-16）

窗口详情在收益和真实路径下列出三项不同含义的读数。统计均基于同一币种、含分红的**收盘估值**，不代表盘中极值；不将期末盈利视为期间安全。

1. **最大收盘回撤**：在窗口内依时间更新此前最高估值，取之后收盘值相对该高点的最深跌幅，并提供峰值和谷值日期。不会拿后来的高点倒算之前的低点。
2. **相对初始金额最深亏损**：逐日估值与初始100比较，取最低收益，正数不计为亏损；全程未跌破本金时为0。它与从历史高点回撤不是同一个指标。
3. **最长连续低于本金**：每段从第一个低于初始100的收盘日开始，到第一个恢复到100或更高的收盘日结束。持续时间使用两日期之间的日历天数，节假日包含在内。低于本金的收盘观测数另存于模型。不将该值称为“从买入到回本”，因为买入后可能先盈利，再出现多段本金亏损。

窗口结束时仍低于本金的一段记录为**未恢复**，终日仅表示观察截止，不虚构回本日；如果只有最后一天首次低于本金，日期差为0，界面显示“不足1天”。最长一段已经恢复、但期末另有一段尚未恢复时，两种状态均展示。全程未低于本金则不存在恢复事件，不伪造起止日。

任一中途估值因缺少7天内汇率而无法计算时，保留可核验的起止收益及断线图，但暂停全部上述路径风险，并列出具体缺失日期。价格路径中超过14天的缺口同样不能生成完整风险。不会跳过缺口，给出偏小的回撤或偏短的低于本金时长。对初始100的浮点比较容许1e-9的数值噪声，避免生成虚假本金亏损段。

真实历史复核案例：伯克希尔 B 类股 2008-07-31 至 2010-07-30 的美元累计收益约+2.01%，但期间最大收盘回撤约−50.54%，相对初始金额最深亏损约−39.93%。该例检验“期末正收益不能替代路径风险”。数值直接来自本仓库公开复权历史，并非新增外部预测。

## 实现接口与验证

模型：`assets/holding-period-model.js`，UMD/CommonJS；导出 `analyze`、`windowPath`、`pathRisk`、`toCSV` 等纯函数。`analyze({..., annual})`按所选口径汇总窗口。页面：`window.ChanghengHoldingPeriod.view({render, openModal, modalTitle, download, symbol, annual, setAnnual})`；`setAnnual(value)`交由根页面更新共享偏好并重新渲染，模块不私自修改全站存储。页面样式独立于其他模块。

测试位于 `tests/holding-period.test.cjs`，覆盖证券身份、年月末及周年、闰日、尚未完成窗口、无前视、历史缺口、汇率方向和回填上限、空样本、同值分位、路径端点勾稽、累计与年化分别排序、CSV全精度复算、峰谷顺序与本金亏损区别、多段恢复和未恢复、汇率中途缺口暂停风险、共享口径交互、页面错误状态、公开伯克希尔与汇率历史，以及链接状态往返、异步加载后的旧路径兼容、非法参数、未知证券及无浏览器环境。

本地测试不等同于用户验收；上线后页面核对未列为本轮工作。
