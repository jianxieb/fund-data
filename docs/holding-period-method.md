# 持有期研究

## 页面目的与范围

回答“买入月份不同，持有同样久，历史结果相差多大”，而不是用当前估值预测未来回报。独立入口为 `#holding-period`，默认伯克希尔 B 类股 `BRK-B`、美元、持有 2 年。`#holding-period/QQQ` 等链接可直接带入已收录证券。

支持公开组合目录中 `market=us`、`currency=USD`、`kind=stock/etf` 的证券。个股、ETF保持自身身份，指数点位不进入该名单，不用ETF代替未收录指数。来源、成立前历史和缺口继续遵守现有[组合历史方法](portfolio-method.md)。

此页是历史研究，不提供买卖规则、预测成功率或收益保证。

## 数据加载与校验

- 复用 `data/portfolio/catalog.js` 的已发布目录及带内容摘要的单证券历史文件，只按需载入所选证券和必要汇率。
- 浏览器检查历史文件 SHA-256 与目录一致，随后检查证券 ID、币种、回报口径、分红再投标记、目录/历史起止日、条数、严格递增日期和正数有限价格。
- 仅接受 `provider_adjusted_close`；缺历史、身份冲突、文件损坏分别显示具体原因，不更换另一证券或补历史。
- 人民币换算使用目录的 `fx:CNY` / `CNY=X`，表示每美元对应多少人民币。缺汇率不影响美元研究，其他可用证券也继续可选。
- 文件一致性与计算校验不代表已独立核验全部供应商原始行情。价格来源保留在页面详情与CSV。

## 历史窗口

1. 期限固定为 1、2、3、5、10 年。每个已经结束的自然月取最后一个真实股价交易日作为买入收盘日，不包含当月尚未结束的月末样本。
2. 买入日期距离该月日历月末不得超过 7 天，防止长期缺价被误识别为月末交易。
3. 目标终日为买入日加相应自然年数。闰年 2 月 29 日在非闰年取 2 月最后一天。实际卖出日为目标日及此前 7 天内最近真实收盘日，不取未来交易日。
4. 目标终日必须已经到达研究截至日。未走完的持有期不以截至日提前卖出，也不将短期收益外推成完整窗口。
5. 持有区间内部若相邻股价观测相隔超过 14 个日历日，则剔除该窗口。这是公开行情完整性规则，不是交易所日历认证；期间正常休市保留真实日期。
6. 人民币仅对股价的起止端点配汇率，分别取当日或之前 7 天内最近有效观测。缺任一端点就排除该人民币窗口。原币窗口仍保留。汇率实际日期和数值逐条导出。
7. 缺完整窗口时保留空值及原因，不使用成立以来回报替代较长期限。页面汇总逐项列出被剔除窗口的数量与原因。

## 计算

设复权价为 `P`，USD/CNY 为 `F`：

```
美元持有倍率 = P_end / P_start
人民币持有倍率 = (P_end / P_start) × (F_end / F_start)
累计收益 = (持有倍率 − 1) × 100%
实际年数 = 实际起止日历天数 / 365.2425
年化收益 = (持有倍率 ^ (1 / 实际年数) − 1) × 100%
```

按指数、基金和股票区间表的实际天数年化口径计算。周年日休市会使某些一年窗口略短于一年，此时仍按真实天数年化，不改写实际日期或补齐价格。明细与CSV提供实际起止日和年数；该规则与组合模拟专门的首年显示规则不同。

复权序列已包含供应商定义的税前分红再投资，ETF运营年费已经反映在序列中，不额外增加分红、不再次扣产品年费。未计个人股息税、卖出税、佣金、买卖价差和换汇价差。

最近区间单独计算：以最新实际股价日为终点，起点取其向前相应自然年的目标日及此前 7 天内最近真实收盘。它通常不是月末窗口，所以仅作参照，不混入历史月末样本数。当前年化在历史样本中的位置为中位秩：`(小于当前的样本数 + 相等样本数 × 0.5) / N`。

## 展示与统计解释

- 主曲线横轴是买入月份，每个点代表一段完整的持有区间，纵轴为该区间年化；它不是账户净值路径。最新区间用水平虚线单列。
- 表格包含每个期限的样本数、年化中位、10%—90%分位、最好/最差年化及真实起止日期。分位采用 R type 7 线性插值。
- “历史亏损月份占比”是期末累计回报严格小于 0 的买入月份数除以有效样本数。零收益不算亏损；无样本不显示 0%。
- 月度窗口大量重叠，既不是独立试验，也不是未来亏损概率。不同持有期限和币种的样本区间可能不同，不能由表中频率机械推出哪种期限或币种更安全。
- 当前收录证券存在人工选择和存续证券偏差，未收录已退市或清盘的完整总体。ETF的历史策略、杠杆目标或跟踪基准可能发生过变更。目录已记录的策略变更（例如XMMO）在页面直接展示具体边界，并随CSV导出当前策略起日、历史说明与来源；较早样本不冒称当前策略的完整历史。
- 查看具体窗口时，以初始价值 100 展示自身含分红持有路径。人民币路径中间日也最多沿用此前 7 天内汇率；缺失时断线。只要两端证据完整，区间收益仍有效，不补出中间行情或据此计算风险值。
- CSV包含全部当前期限样本的原始精度数值、股价与汇率日期、持有倍率所需端点、证券身份、来源与收益口径，可逐行复算。

## 实现接口与验证

模型：`assets/holding-period-model.js`，UMD/CommonJS；导出 `analyze`、`windowPath`、`toCSV` 等纯函数。页面：`window.ChanghengHoldingPeriod.view({render, openModal, modalTitle, download, symbol})`。页面样式独立于其他模块。

测试位于 `tests/holding-period.test.cjs`，覆盖证券身份、年月末及周年、闰日、尚未完成窗口、无前视、历史缺口、汇率方向和回填上限、空样本、同值分位、路径端点勾稽、CSV全精度复算、页面错误状态、公开伯克希尔与汇率历史。

本地测试不等同于用户验收；上线后页面核对未列为本轮工作。
