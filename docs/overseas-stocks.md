# 海外个股研究

## 页面层级

个股深入先选择“国内 / 海外”。国内的长期优质、高质成长、业绩爆发、红利价值及其他已收录分组保持独立。海外首批 LITE、TSM、NVDA、MU、TSLA、SPCX 是用户指定研究名单，按行业筛选；没有把指定名单等同于通过国内质量筛选。

海外提供财务与理由、估值、收益风险三个视图，与国内使用相同的公司信息、独立理由与风险列、报告入口及字体层级。财务页同时显示TTM ROE、最近三财年平均ROE、最新季度同比、三年营收复合增长、TTM净利率和现金回收。点击公司名查看年度/季度明细，名称下的“深入报告”进入完整研究页面。国内与海外分别保留搜索和筛选状态；收益周期及年化/累计共用全站控制。

六家公司均有业务竞争力、季度变化、年度财务、盈利质量、估值假设、分红回报、风险和后续验证章节。`data/overseas-stock-research.json`保存人工复核的观点与日期；`overseas_research.py`从当次财报/行情重新生成指标和报告表格。报告对象、Markdown下载内容与公司快照一起写入同一个原子文件，因此定时刷新不会留下旧报告配新数据。报告库同时收录国内与海外报告。

## 身份与行情

- 名单和发行人保存在 `data/overseas-stock-catalog.json`。
- Yahoo Chart 必须同时匹配证券代码、发行人全名、EQUITY 类型、USD 币种以及明确的 adjusted close 字段。收盘价用于PE，复权价用于含分红收益，不能互换。
- 使用交易所当地日期，剔除未收盘当日数据；连续日线出现超过14日的缺口则拒绝发布。
- SPCX 是2026年6月12日上市的 Space Exploration Technologies Corp.。根据 Nasdaq DTN2026-8，旧同代码ETF历史不能接入。接口若返回旧ETF身份直接拒绝；通过身份核对后仍按上市日期切断更早观测。收益起点是上市首日收盘价，不是135美元IPO发行价。
- 不拼接其他证券补足历史。1/2/3/5/10年收益要求完整窗口；近5年风险允许使用明确标出的较短实际历史。另列上市以来累计收益。
- 美元含分红再投资回报尚未扣个人佣金、股息税和出售所得税。组合模拟按既有人民币换汇规则处理海外持仓；税后跨境投资比较仍在投资渠道模块。

## 财报与估值

`overseas_stocks.py` 下载每家公司的年度与单季财报，核对代码、币种和3M/12M周期。财报币种与上市币种分开保存：TSM的报表以新台币计价，行情及ADR每股收益以美元计价。

- 同比以相同公司、币种、对应季度计算。上年利润不为正时不输出无意义的增长率，显示扭亏、亏损收窄或扩大。
- TTM ROE = 连续四季报表净利润 / 期初期末平均股东权益。四季必须连续、间隔三个月；缺失时明确列出缺少连续利润或哪个季度的正净资产。不得把最新一季ROE当作全年TTM或把历史平均ROE标为最新。
- Yahoo有时把52/53周制财报归一到月末。已核对的真实财报截至日和官方补充数据放在 `data/overseas-stock-evidence.json`。未核对的历史日期只展示月份加“季”。MU FY2026实际截至2026-09-03，归一化财季键为2026-08，避免与接口后续补齐形成重复季度。
- 官方补充只适用于明确财季。较新接口报告会自然成为最新；相同字段与官方差异超过0.5%则拒绝，不静默覆盖。
- 营业利润只使用接口的 `TotalOperatingIncomeAsReported` 或公司正式报表，拒绝以已调整重组费用的标准化 `OperatingIncome` 冒充报表营业利润。
- LITE FY2026债转股的一次性非现金损失保留在GAAP净利润中，Non-GAAP只在说明中并列；不人为调成正PE。
- PE = 已完成交易日的普通收盘价 / 接口该美元证券的TTM EPS。负EPS标注亏损。TSM不以美元价格除以新台币EPS。
- 预测PE = 收盘价 / 接口分析师年度EPS预期，预测采集日单列。该接口没有足够保证将其命名为某个确定财年或NTM，所以不冒充国内“本期利润年化”的动态PE。缺逐时点历史EPS，不生成5/10年PE分位。
- 季度年化PE = 收盘价 / (最新单季美元EPS × 4)，与预测PE独立，存在季节性；静态PE使用最新完整财年美元EPS。TSM的2026Q2美元ADR EPS 4.31来自公司原始财报补充，仅对应该季度；不能以新台币EPS替代。缺相应美元年度EPS时静态PE留空。
- 年度ROE按本财年利润/期初期末平均权益计算；三年均值要求三个连续完整财年的可用ROE。三年CAGR要求相距36个月、正数的起止年度金额，负利润基数不计算CAGR。现金流/净利润倍数只在连续四季净利润为正时计算，不能以负负得正掩盖亏损。
- 近12月股息率使用已核对为USD上市身份的Chart分红事件，按交易所当地除息日筛选并除以相同收盘价。TSM不使用报价接口中可能混入新台币普通股口径的26.0分红数。窗口内发生拆股时，统一每份口径尚未核对的分红率留空并说明。
- 研究要点与风险是对业务的观察框架，不是自动选股结论或买卖建议。

## 定时刷新和组合模拟

`refresh.py` 新增 `overseas_stocks` 阶段，在组合数据前执行；失败退出并保留原页面快照。匿名Yahoo报价会话仅在进程内使用，不保存或公开会话cookie/crumb。

历史进入组合标的库时身份为 `stock:LITE` 等，类型是个股，市场为海外，币种USD。ETF继续使用 `us:QQQM` 等身份。不能因为都在美国上市就把股票计入ETF占比。

更新后运行数据质量检查、完整标的/来源日期回退门禁和内容哈希验证。GitHub Actions缓存海外来源，九阶段全部成功才发布。
