# 美股个股研究

## 范围与页面

个股深入使用 **A股 / 美股** 两个市场入口。美股包括美国交易所上市普通股及ADR，不泛指所有海外市场。

当前研究池由62家公司组成：既有六家指定公司、重要蓝筹，以及科技、消费、医疗、金融、能源、工业的行业代表与成长候选。参考[S&P 100的蓝筹覆盖定义](https://www.spglobal.com/spdji/en/indices/equity/sp-100/)，不是完整复制该指数，也不是已穷尽美国市场。苹果、微软、Alphabet、亚马逊、伯克希尔、摩根大通等即使未进入当期质量或成长组，也保留完整财务、估值、收益、业务理由、风险和报告。

五类页签为长期优质企业、高质成长股、业绩爆发股、红利价值、其他已收录。长期优质与高质成长可以重叠，用公司栏绿色表示；其他已收录放在最右侧，列出具体未入选原因。财务、估值、收益风险三个视图和行业筛选在每类中均可使用，搜索不因切换分组清空；收益周期与年化/累计使用全站控制。

每家公司有11个报告章节。`data/overseas-stock-research.json`保存本期业务持续性、再投资、失效信号、主营增长、非经营项、周期及合并范围研究；`data/us-financial-history.json`保存SEC年度/季度来源、日期、XBRL标签、计算操作数与接口差异。`overseas_research.py`从同次快照生成页面和Markdown报告，不用旧表格配新行情。

## 当前分类方法

`us_stock_groups.py`执行独立财务门槛，并核对当期业务研究。所有经营分类要求最新已披露财季距核对日不超过155天、公告不晚于核对日、人工研究与该财季精确匹配。新财报出现后，旧经营观点不能自动续期授予分类。

| 分组 | 财务条件 | 经营条件 |
|---|---|---|
| 长期优质企业 | 连续5个完整财年净利润及经营现金为正；5年平均年度ROE≥15%、各年为正、最新年度≥15%；3年利润复合和最新年度利润增长均≥10%；最新单季利润及营业利润同比均≥10%；当前TTM ROE≥10%，TTM利润与经营现金为正 | 本期长期业务持续性、再投资和失效信号研究成立；已复核主营、特殊项目、周期及合并范围 |
| 高质成长股 | 连续2个相邻单季净利润和报表营业利润同比均≥30%、同比利润基数为正；最近2个完整财年利润及经营现金为正；最新年度和TTM ROE均≥10%；TTM现金/净利润≥50% | 本期增长来源复核成立，不能用投资收益、税收收益或未拆清的周期反弹直接授予成长 |
| 业绩爆发股 | 连续2个相邻单季净利润和营业利润同比均≥100%、正基数；最新完整年度利润和经营现金为正；年度和TTM ROE均≥5%；TTM和最新单季现金/净利润均≥50% | 本期爆发来源已有金额证据；已进入质量/成长的公司展示在对应组，爆发组收录质量记录尚短的当前高增长 |
| 红利价值 | 近12月已除息现金股息率≥3%；最近5个完整日历年都有现金分红；派息比率≤85%及行业现金/资本条件成立 | 本期派息承受能力复核成立，与成长条件独立 |
| 其他已收录 | 未进入以上任何当前分类 | 保留蓝筹及行业研究，不以“已收录”冒充满足质量条件；展示未入选原因 |

不设统一营收增速硬门槛。量价、结构、毛利和费用改善可能令利润增速高于营收；两项都展示，利润和营业利润须交叉验证。

每个经营复核必须提供对应本期的数值、单位、原始链接、报表位置及披露/计算性质。GOOGL投资收益、ALAB税收收益、LITE债转股损失、APP出售游戏业务、美光存储量价周期等分别写入报告，保留GAAP利润，不把Non-GAAP改成报表数。未拆清的项目不能因为报表涨幅高而直接进入成长/爆发。

银行、金融服务、REIT及投资控股不套经营企业现金/利润门槛。它们暂保留专题研究；红利条件使用相应资本或AFFO证据。Realty Income本期AFFO派息比率74.5%、杠杆5.4倍及出租率98.8%已单独核对。回购令净资产很低甚至为负时，ROE可能畸高或不适用，不能为获得标签而人工补成正数。

苹果已收录，但当前三年报表利润复合增速约3.92%，未达到10%的长期质量门槛；两季利润及营业利润增长未同时达到30%，未进入高质成长。其品牌生态和服务业务研究仍在其他已收录及报告库中完整保留。

## 身份与行情

- 名单和发行人保存在 `data/overseas-stock-catalog.json`。
- Yahoo Chart 必须同时匹配证券代码、发行人全名、EQUITY 类型、USD 币种以及明确的 adjusted close 字段。收盘价用于PE，复权价用于含分红收益，不能互换。
- 使用交易所当地日期，剔除未收盘当日数据；连续日线出现超过14日的缺口则拒绝发布。
- SPCX 是2026年6月12日上市的 Space Exploration Technologies Corp.。根据 Nasdaq DTN2026-8，旧同代码ETF历史不能接入。接口若返回旧ETF身份直接拒绝；通过身份核对后仍按上市日期切断更早观测。收益起点是上市首日收盘价，不是135美元IPO发行价。
- 不拼接其他证券补足历史。1/2/3/5/10年收益要求完整窗口；近5年风险允许使用明确标出的较短实际历史。另列上市以来累计收益。
- 美元含分红再投资回报尚未扣个人佣金、股息税和出售所得税。组合模拟按既有人民币换汇规则处理海外持仓；税后跨境投资比较仍在投资渠道模块。

## 财报与估值

`us_filings.py` 从SEC CompanyFacts提取每家公司至多7个完整财年、12个单季，`overseas_stocks.py` 下载补充年度与单季财报，核对代码、币种和3M/12M周期。财报币种与上市币种分开保存：TSM的报表以新台币计价，行情及ADR每股收益以美元计价。

- 同比以相同公司、币种、对应季度计算。上年利润不为正时不输出无意义的增长率，显示扭亏、亏损收窄或扩大。
- TTM ROE = 连续四季报表净利润 / 期初期末平均股东权益。四季必须连续、间隔三个月；缺失时明确列出连续利润或哪个期间的母公司净资产；已知负净资产标为ROE不适用，不伪装成缺数据。不得把最新一季ROE当作全年TTM或把历史平均ROE标为最新。
- Yahoo有时把52/53周制财报归一到月末。已核对的真实财报截至日和官方补充数据放在 `data/overseas-stock-evidence.json`。未核对的历史日期只展示月份加“季”。MU FY2026实际截至2026-09-03，归一化财季键为2026-08，避免与接口后续补齐形成重复季度。
- 官方补充只适用于明确财季。较新接口报告会自然成为最新；相同字段与官方差异超过0.5%则拒绝，不静默覆盖。
- 营业利润只使用接口的 `TotalOperatingIncomeAsReported` 或公司正式报表，拒绝以已调整重组费用的标准化 `OperatingIncome` 冒充报表营业利润。
- LITE FY2026债转股的一次性非现金损失保留在GAAP净利润中，Non-GAAP只在说明中并列；不人为调成正PE。
- PE = 已完成交易日的普通收盘价 / 接口该美元证券的TTM EPS。负EPS标注亏损。TSM不以美元价格除以新台币EPS。
- 预测PE = 收盘价 / 接口分析师年度EPS预期，预测采集日单列。该接口没有足够保证将其命名为某个确定财年或NTM，所以不冒充国内“本期利润年化”的动态PE。缺逐时点历史EPS，不生成5/10年PE分位。
- 季度年化PE = 收盘价 / (最新单季美元EPS × 4)，与预测PE独立，存在季节性；静态PE使用最新完整财年美元EPS。TSM的2026Q2美元ADR EPS 4.31来自公司原始财报补充，仅对应该季度；不能以新台币EPS替代。缺相应美元年度EPS时静态PE留空。
- 年度ROE按本财年利润/期初期末平均权益计算；三年均值要求三个连续完整财年的可用ROE。三年CAGR要求相距36个月、正数的起止年度金额，负利润基数不计算CAGR。现金流/净利润倍数只在连续四季净利润为正时计算，不能以负负得正掩盖亏损。
- 近12月股息率使用已核对为USD上市身份的Chart分红事件，按交易所当地除息日筛选并除以相同收盘价。TSM不使用报价接口中可能混入新台币普通股口径的26.0分红数。窗口内发生拆股时，统一每份口径尚未核对的分红率留空并说明。
- 研究要点与风险是对业务的观察框架，不是自动选股结论或买卖建议。

## 定时刷新和组合模拟

`refresh.py` 新增 `overseas_stocks` 阶段，在组合数据前执行；失败退出并保留原页面快照。财务历史审计文件与页面快照同属该阶段事务；刷新不自动改写人工业务研究。匿名Yahoo报价会话仅在进程内使用，不保存或公开会话cookie/crumb。

历史进入组合标的库时身份为 `stock:LITE` 等，类型是个股，市场为海外，币种USD。ETF继续使用 `us:QQQM` 等身份。不能因为都在美国上市就把股票计入ETF占比。

更新后运行数据质量检查、完整标的/来源日期回退门禁和内容哈希验证。GitHub Actions缓存海外来源，九阶段全部成功才发布。
