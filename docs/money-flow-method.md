# 跨境资金费用测算

核对日期：2026-10-09。数据在 `data/money-flow.js`，牌价在 `data/money-flow-quotes.js`，计算在 `assets/money-flow-model.js`，界面在 `assets/money-flow.js`。

## 页面结构与账户关系

页面按四个动作展开：购汇并汇到香港、香港银行转入股票账户、买卖美股、取回或消费。顶部集中显示出发银行、香港收款银行、买股账户和最终用途。关键选择使用独立弹窗，其他条件使用原生选择框；弹窗不占正文流的位置。每行只有一个计费动作，原币、人民币折合、占人民币本金比例分别标明。

香港收款银行、证券结算银行、卖出后的取回银行是独立选择。例如：中国银行→中银香港→本人ZA美元账户买股→中银香港。选择ZA或汇丰证券不再覆盖两个香港银行选择。银行证券直接从本行存款账户交收；与收款银行不同时，增加两家银行之间的本地USD CHATS转账。

四种终点分别计算，不再强制回内地结汇：

| 终点 | 最终币种 | 计价方式 |
|---|---|---|
| 保留美元 | USD | 卖出后回所选香港银行，不换汇 |
| 美元原币消费 | USD | 支持USD的多币种扣账卡、余额充足、直接刷卡 |
| 换人民币后刷卡 | CNH | 中银香港USD/CNH买入价换CNH，再原币直接刷卡 |
| 汇回内地结汇 | CNY | 香港汇出后，按所选内地收款行USD现汇买入价结汇 |

ZA卡不支持本页USD存款原币扣账情景，选择后会明确提示更换消费银行。当前CNH刷卡情景只收录中银香港，因为它同时具有已核实的卡产品和公开USD/CNH牌价。内地CNY与香港CNH不是同一成交价。支付宝、微信、商户另收费用和未发生的回赠不在直接刷卡费用中。

交互只计算当前所选组合（`selectedOnly`），不再将含不同操作、证据缺口的组合排成“最低损耗”推荐，也不再显示原来的逐段横向比较表。旧规划纯函数保留给既有回归，不作为当前页面推荐。

## 中行到中银香港：已证实内容与证据等级

1. [中银香港同名跨境汇款官网](https://www.bochk.com/tc/crossborder/personal/financialservicehk/remittance.html)确认个人网上／手机银行同名中行汇款的基本汇出、汇入手续费豁免。条款第3项排除代理行及其他费用。BOCHK收到同名内地中行汇款的基本手续费按0计算。
2. [中国银行官方2025公告](https://www.boc.cn/big5/ebanking/bi3/bi31/202504/t20250430_25339098.html)确认2025年5月1日至12月31日手机银行向境外中行汇款手续费、电讯费双免；不能将期限直接续写至2026。
3. [2026年5月28日公开报道](https://www.sohu.com/a/1028992119_121123789)记录中行山西省分行介绍的手机银行境外中行手续费、电讯费豁免；[2026年6月30日用户实录](https://linux.do/t/topic/2632770?tl=zh_CN)记录同名中银香港到账及本地转账。两者是公开报道／操作记录，不是总行现行全国公告。
4. 因此“中行手机银行→同名中银香港”的USD/HKD渠道提供**2026公开报道双免情景**：手续费0、电讯费0，页面标明证据类型，详情保留完整来源。不再把这两项笼统写作“待确认”，也不声称所有账户、所有币种、所有汇路永久免费。该情景不进入确定资费最低排名。
5. [中行现行标准目录](https://pic.bankofchina.com/bocappd/pricelist/202511/P020251110646838136627.pdf)的普通电汇1‰、最低50元、最高260元及港澳电讯费80元保留为独立渠道。它不是手机银行优惠价。

原币汇款免手续费不代表人民币购汇也没有点差。点差按出发银行自己的现汇买卖价计算。未确定的跨境代理费用只保留一条具体提示，不把缺少这项金额扩散成全路线“缺报价”。

跨境支付通是另一个渠道，不套SWIFT电讯费。[中行产品页](https://www.boc.cn/aboutboc/bi1/202506/t20250620_25390382.html)、[2025年政府网站实例](https://huangshi.gov.cn/xwdt/hsyw/202507/t20250701_1235188.html)和[金管局2026年说明](https://www.hkma.gov.hk/chi/smart-consumers/payment-connect/)支持人民币汇出、人民币／港币到账和相应限额；当前未收录统一现行服务费原文，仍具体注明该服务费，不推荐将受用途限制的便利化渠道用于证券入金。

|---|---:|---:|---|
| 中银香港 | 0 | 0 | 0 |
| ZA | 0 | 0 | 0 |
| 汇丰One | 0 | 0 | 符合豁免条件0；2026年新开非香港身份证账户不满足条件100 HKD/月 |
| 恒生优进 | 0 | 0 | 0 |
| 渣打快易 | 22 USD | 0 | 0 |

依据：[中银香港汇款收费](https://www.bochk.com/sc/crossborder/remittance/charges.html)、[ZA现行收费](https://bank.za.group/hk/notice-detail/979ca80f-2fb4-4add-b30c-18144d3a757f)、[ZA官方本地USD指南及直连名单](https://cdn.zaticdn.com/if/ipage/prd/data/blog/a1e7a724-9c51-421a-936a-a339d6d18c4e/en/USD-local-bank-transfers.html?v=1758617552695)。其他银行官方来源见数据源清单。ZA直连名单包括中银香港、汇丰、恒生和渣打；其2026年11月SWIFT收费变更不改变本地CHATS零收费。

收款、证券结算、取回三类银行账户按银行去重计管理费。每月单价×持有月数先得到原币期间金额，再折人民币。例如100 HKD/月×12个月=1,200 HKD，人民币金额为1,200×当次HKD/CNY参考价。HSBC One的银行管理费与Trade25证券月费是两项。证券市值可计入该行全面理财总值，但不能假定所有资金在整个期间都满足其平均结存要求；页面提供已满足条件的选择。

中银快汇和网上SWIFT到内地同名中行的基本汇出费均为0；SWIFT须按官网要求以BKCH开头的11位BIC或CNAPS指定收款行。汇至其他银行的普通SWIFT保留65 HKD标准价，代理费用均另列。外部券商汇入中银香港超过500 HKD等值时基本汇入费60 HKD；不将本地个人银行CHATS的0元覆盖这项费用。致富美元支票出金的收款银行处理费另列。

## 牌价、费用及人民币核对

- 自动牌价覆盖中行、招行、工行、建行、农行、交行、汇丰中国及中银香港USD/HKD、USD/CNH。每行保留独立官网链接与时间；缺失不借用其他银行成交价。
- 工、农、交、中、招报价按每100外币归一；建行接口直接每1外币；汇丰中国按官网算法取倒数。中银香港的每1USD外币金额不再除100，人民币归类CNH。
- 购汇用所选出发行现汇卖出价；内地结汇用收款行现汇买入价；香港USD换CNH用中银香港USD/CNH买入价。
- USD/CNY统一估值参考取中行买卖中间值，缺失时取另一完整银行；USD/HKD和USD/CNH参考取中银香港中间值。该参考用于各币种成本折算，不是另一家银行的可成交价格。
- IBKR换汇或缺公开牌价的香港银行只能显示明确的中间价参考情景；成交点差不伪装成0，已知佣金仍计算。IBKR手动换汇为0.002%、最低2 USD；自动兑换为0.03%加价，二者不叠加。
- 兴业当天公开查询无报价行，恒生中国、渣打中国未收录公开可执行牌价，选择时准确说明缺失币种。报价超过3天在结果处提示，保留原时间。
- 手填实际报价只绑定当前账户／渠道；切换相关选择后清除，不影响无关银行的费用。

汇款预算内扣公式：`每笔汇出主金额CNY + 本笔手续费 + 电讯费 + 全额到账附加费 = 人民币本金 / 汇出笔数`。手续费按实际主金额逐笔应用最低、最高费。农行全额到账附加25 USD为每笔，不漏乘笔数。

买入佣金从可用美元内求解，不能把全部现金算成购股本金后重复扣费。换汇点差是余额中已发生的价差解释，不再扣第二次。按各银行买卖中间价定义非负点差；与统一估值参考的差额另记有正负的 `fxImpactCny`，不伪造负手续费。

`最终余额折合CNY + 已列费用（含点差） + 税款 = 人民币本金 + 交易费前盈亏折合CNY + 汇率折算影响`

`折算损耗率 = (人民币本金 + 交易费前盈亏折合CNY − 最终余额折合CNY) / 人民币本金`

每个费用行的比例统一为本项CNY费用／初始CNY本金。费用合计与折算损耗的差别来自税款及汇率折算影响，存在差额时展示一行人民币核对式。移除重复的保留系数。金额内部完整精度，显示到分可能出现逐行舍入差。

明细行只展示已定金额；结果紧邻列出具体未扣项目及地区价格区间，来源详情保留所有缺项。不把浮动费默认为实际免费，也不因一个缺项隐藏其余已核实的金额。含未定费用时最终余额只是已列费用扣除后的测算值。

## 税款、用途与验证

默认交易盈亏0。税款以正的净交易利润折人民币估算，或以用户已核算的人民币应税所得覆盖，减有依据的境外抵免；不对本金征税，不产生负税额。境外财产转让所得税依据见[税务总局说明](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)。真实成本、汇率、允许费用及股息税须按对应事实处理。

大陆个人便利化购汇不得用于境外证券投资；银行免汇款费不代表资金用途获得许可。同名香港账户不改变这一限制。页面保留一句适用提示，细则放详情；不编造消费、留学等用途绕过审核。

报价刷新脚本对单行失败保留原价和时间，全失败不改文件，拒绝未来时间、异常买卖方向和倒退时间。静态费用核对日期不随市场报价自动更新。

回归覆盖：预算内扣、按笔收费、不同换汇币种及报价、交易及券优惠、独立收款／证券／取回账户、本地CHATS与SWIFT区分、管理费去重及期间单位、Trade25月费与首次跨额订单、四种终点的原币余额、每段及全程人民币守恒、具体缺项保留。浏览器实际核对主要选择器、费用券、银行组合及终点切换；运行 `npm test` 与 `npm run check`，变更交付前更新资源版本。
