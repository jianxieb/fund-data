# 跨境资金：路径、费用与计算口径

核对日期：2026-10-08。页面入口为「研究方法 / 跨境资金」，路由 `#money-flow`。

## 适用身份与路径

按中国大陆税收居民研究。大陆个人年度便利化购汇、结汇额度分别为等值5万美元；额度不能用于境外证券投资，同名香港账户不改变用途。超过便利化额度的真实经常项目与账户内外汇汇出另有材料要求。本页不能据费用更低推断一条投资汇款路径可用。

页面提供两个起点：

- 大陆人民币：真实、银行审核通过的境外消费、留学、生活等用途；画出 CNY → 现汇购汇 → 香港同名银行 → 消费。
- 已有合法境外资金：只有在券商账户获准使用、资金来源可投资时测算香港银行 → 券商 → 卖出结算 → 税款预留 → 同名银行出金 → 消费。另展示 USD、HKD、CNH 入金及 USD、HKD、大陆 CNY 消费。

境外账户并不自动赋予券商开户资格。证监会2026年5月发布的非法跨境展业整治信息应与银行开户要求分开阅读。不能把券商设计成只为换汇、立即出金的汇款中转站，也不能把闭环理财通的资金接入普通券商。

主要依据：[外汇局购汇用途](https://www.safe.gov.cn/shanghai/2019/1213/1198.html)、[外汇汇出材料规则](https://www.safe.gov.cn/tianjin/2026/0422/3039.html)、[证监会2026年整治信息](https://www.csrc.gov.cn/csrc/c100028/c7634324/content.shtml)。

## 券商费用、结算、税款

采用IBKR直接客户的公开费用作为示例：

- 手动换汇首档0.002%，最低US$2。费用计入资金预算，不能让全部现金先换汇后再形成欠费。
- 自动换汇通常在汇率上加价0.03%，没有另外一笔独立换汇佣金；仅按合资格证券买入情景使用。
- 按核对时的现行价目表，每个日历月前 **两次** 出金免券商手续费；第三次起USD电汇US$10。不要沿用旧资料中的每月一次。
- 银行费、中转费、入金限制、结算及提现等待期另计；第三方资金可能被拒绝。

来源：[换汇](https://www.interactivebrokers.com/en/pricing/commissions-spot-currencies.php)、[出金](https://www.interactivebrokers.com/en/pricing/other-fees.php)、[入金及资金持有要求](https://brokerage.ibkr.com/en/support/fund-my-account.php)。

部分券商采用香港证监会的指定银行远程开户方法，需要同名银行初始转入不少于HKD10,000，并限制后续指定银行存取。这笔钱属于客户，不是手续费；不能写成所有券商、所有开户方式的统一验资门槛。[香港证监会](https://www.sfc.hk/en/Rules-and-standards/Account-opening/Acceptable-account-opening-approaches)

大陆税收居民境外所得应按适用规则申报。境外股票转让的预留税款按用户已核算的人民币应税所得计算，默认20%，减去用户填入的可抵免税额，最低0。**不对本金、提现总额或美元盈利直接征20%。** 美元卖出盈亏填扣除交易费用后的金额，是银行资金流输入，人民币应税所得是独立税务输入，不能互相自动替代；抵免资格和限额由申报证据决定。[税务总局](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)

## 计算方法

### 同一预算内扣手续费

每笔总预算 `B`、购汇本金 `P` 与汇出费 `F(P)` 满足：

`P + F(P) = B`

对每笔分别应用最低费、百分比费、封顶费及电讯费，并用二分法求本金。10万元中行标准预算的一次汇出费约179.82元；均分12笔，逐笔最低费50元加电讯费80元，合计1,560元。不能对全年总额只计算一次最低费。

外币余额按现汇卖出成交价换算。大陆参考牌价通常每100外币，本页录入控件保持这个单位，模型内部改为每1外币。汇回大陆结汇采用银行现汇买入成交价。

中转费用以用户录入的CNY等值记账，再按同一组参照汇率折算到账币种。实际到账验证应使用银行回单扣费币种、金额、成交价与日期重新填入。

### 参照汇率与价差

为了把各币种成本统一列成CNY，采用用户可修改的一组一致参照：USD/CNY、USD/HKD、USD/CNH；HKD与CNH的CNY折算值由这组参照推出。初始USD/CNY取中行公开买卖牌价中间值，**不是市场中间价**；HKD 7.85、CNH 6.70为演示情景，不能冒充用户的可执行报价。

成交价已经含买卖价差。模型用成交价与参照折算值之差展示换汇影响，不再扣一次所谓“换汇点差百分比”。价格优于参照时差额可以为负；它是相对参照的差额，不代表普遍无损兑换。

自动换汇用 `基准美元金额 / (1 + 0.0003)`，不再附加手动佣金。手动换汇用扣最低佣金后资金，超过最低佣金适用范围后按成交金额比例求解。

税款独立列示。验证恒等式：

`消费前银行余额×参照价 + 流转成本 + 税款 = 起始资金×参照价 + 已实现盈亏×USD参照价`

### 消费预算与签账费

消费额 `C` 与附加费 `r` 使用 `C × (1 + r) = 可用余额`。不能先对整笔预算收1.95%，再对剩余消费额形成第二层不一致计算。

ZA以USD余额消费美元商品的模型为：

`商品金额USD = USD余额 × 银行USD换HKD成交价 / [Visa每1USD的HKD折算价 × (1 + 签账费率)]`

银行价与Visa价均须录入，Visa价不能已经包含1.95%后又加一次。示例：US$1,000余额，银行7.80、Visa7.85、签账费1.95%，可买约US$974.63的商品；与支持足额USD直接扣账的0签账费方案比较时，还要看前序入出金及月费。

### 月费、验资与机会成本

「另有理财总值」与本次全部投入/消费预算分开，假设整个选定月数内保持该条件。本次资金不能一边全部投资/消费，一边永久算作留在银行的免月费资产。

保留资产或验资本金不整笔记为损耗。额外占用资产的机会成本：

`额外资产 × 用户填写的年收益差 × 使用月数 / 12`

额外开户、赴港支出单列。50万元、2%收益差、12个月的机会成本为1万元；2%只是情景假设，默认0不代表真实机会成本为0。税款与机会成本也不能混为汇款手续费。

### 未知与无效输入

未报价的非负中转费不静默替换为0；页面给出已知费用下的余额上限，并列出缺少的费用。确认免收才填0。未提供购汇价时不展示伪造到账金额。满足指定全免费渠道条件时使用已核对的费用豁免，实际自填扣费可覆盖。

费用不能是负数，笔数必须为整数，汇率必须为正数。合法路径或优惠资格未成立时，金额结果不出具；流程、材料与收费表仍可查看。

## 最低损耗与最佳实践

两种方案是满足条件后的路径设计，不是无需报价即可得出的全市场银行排行榜。

- 最低损耗：减少固定费用与反复换汇。已有两地合资格同名账户可用指定免费渠道；无高资产账户可比较兴业卡当前优惠。合法境外USD投资及USD消费保留同一币种，使用合适本地入金、免费出金次数及直接USD扣账卡。
- 最佳实践：先使用已有账户比较App成交价；从零开始比较无需高额资产维持的账户。先小额验证同名收款、附言与实际费用，再按真实用途操作。预留税款、等待资金可提现后集中出金，投资资金与生活费分开。

香港居民每日8万元同名人民币汇款安排不应套用到仅有大陆身份证的客户。跨境支付通是另一套资格及限额；例如汇丰目前北向服务要求香港居民。来源：[香港政府](https://www.info.gov.hk/gia/general/202509/10/P2025090900719.htm)、[汇丰资格](https://www.hsbc.com.hk/zh-hk/help/faq/transfers-and-payments/)。
