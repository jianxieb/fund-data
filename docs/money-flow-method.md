# 跨境资金费用测算

核对日期：2026-10-10。需求、原始截图和验收记录以[跨境资金需求清单](money-flow-requirements.md)为准。资料在data/money-flow.js，牌价在data/money-flow-quotes.js，模型和界面分别在assets/money-flow-model.js、assets/money-flow.js。

## 账户选择与报价分别处理

银行目录固定为中行、兴业、招行、工行、建行、交行、汇丰中国、恒生中国、渣打中国；香港银行为中银香港、汇丰、ZA、恒生、渣打；买股账户为IBKR、汇丰证券、ZA、致富、盈立。农业银行按用户明确要求移除，历史数据只留研究测试。

选项顺序不随当前选择或报价变化，不隐藏、不禁用其他银行与券商。渠道的适用条件只作用于对应步骤：例如同名集团渠道须配对账户，FPS不能汇USD；这些条件不能取消用户更换账户的权利。缺少成交报价不表示账户不可选，也不能成为删除银行的理由。

## 主界面与快捷方案

左侧始终显示四步及已选账户，右侧只编辑当前一步；各步可以直接跳转。第一步放本金、汇出笔数、出发银行、汇出币种与渠道；第二步放香港收款银行、期间月数和HSBC One等银行条件；第三步选择真正的买股账户、必要的到港换汇、入金方式及交易优惠；第四步选择资金用途。

快捷方案包括兴业→汇丰→汇丰证券、兴业→中银香港→ZA、中行→中银香港→盈立、汇丰两地同名→汇丰证券、中行→中银香港→IBKR。它们提供常用配置，不宣称在所有资格和汇路下绝对最低。选择后仍可自由改所有账户与渠道，保留本金、汇出笔数、月数、资金用途和个人资格；不增加汇出笔数，不自动勾选优惠。兴业方案使用普通汇款，SWIFT GO另选。

长收费条款、采集时间、完整报价表、回单覆盖与逐项证据放在弹窗详情。选择弹窗不进入正文布局，保留完整边框；点击外部、关闭按钮与Esc均可关闭并返回焦点。

## 实际动作与资金用途

收款银行与买股账户分开。中银香港→本人ZA或汇丰银行USD账户使用本地转账，再由银行证券服务内部交收；换券商不会改收款银行。独立券商使用其公布的收款账户及支持渠道。

| 终点 | 实际动作 |
| --- | --- |
| 留在买股账户 | 卖出后保留USD；不发生出金、香港回款或内地结汇 |
| 取回香港银行、保留美元 | 出金至所选本人银行，保留USD |
| 美元原币消费 | 出金至支持USD扣账的银行，以足额USD直接刷卡 |
| 换人民币后消费 | 本次有公开报价的中银香港USD/CNH兑换后刷卡 |
| 汇回内地结汇 | 所选香港银行汇回所选内地银行，按其USD买入价结汇 |

ZA卡不适用USD原币扣账，其他消费账户可重新选择。香港银行没有公开的CNH兑换报价时，不能自动借用中银香港的价。CNY、CNH和USD始终保留真实币种。

## 组合检查与真实边界

运行node scripts/audit_money_flow.cjs --write，结果见[money-flow-combinations.json](money-flow-combinations.json)。9×5×5×5×9×3×5＝151,875个目录状态全部经过检查，包括未使用取回账户、内地收款账户的重复状态。每一状态须能选择；模型返回可核金额或具体步骤问题。已算余额全部校验本金、盈亏、费用与税款等式；不允许NaN、不允许缺项却标“完整”。

本次公开快照的普通默认渠道检查中：272条状态有完整报价（去重24条），97,478条有部分报价，54,125条需要具体渠道／成交价调整。这个结果**不是“所有费用已经查齐”**。它暴露了普通电汇代理费、券商特定收付款汇路、客户专属换汇价和地区费率仍无法由统一价表确定。模型检查覆盖所有状态，并不把每个笛卡尔积组合宣称为真实可办理汇路，也不把未知项改成0或删除账户来让数字好看。

附加服务与个人报价在独立边界测试覆盖，不含在上述普通默认渠道计数中。测试涵盖金额不足、GO单笔边界、优惠第30／31笔、过期、0／1／12个月、佣金、券、买卖订单、利润和报价失效。真实无法统一定价的项目仍是需求清单中的开放事项，不能将自动检查写成用户验收通过。

## 牌价、费用及人民币核对

- 自动牌价覆盖中行、招行、工行、建行、农行、交行、兴业、汇丰中国及中银香港USD/HKD、USD/CNH。每行保留独立官网链接与时间；缺失不借用其他银行成交价。
- 工、农、交、中、招报价按每100外币归一；兴业使用接口货币单位归一；建行接口直接每1外币；汇丰中国按官网算法取倒数。中银香港的每1USD外币金额不再除100，人民币归类CNH。
- 购汇用所选出发行现汇卖出价；内地结汇用收款行现汇买入价；香港USD换CNH用中银香港USD/CNH买入价。
- 当前页面以目录内最低有效USD卖出价确定USD/CNY参考值，以最低有效HKD卖出价确定HKD/CNY参考值。CNH仍用中银香港USD/CNH参考中间价折算，不能借作其他银行成交价。
- IBKR手动换汇佣金0.002%、最低2 USD；自动兑换0.03%加价，二者不叠加。实时买卖价不是静态佣金表；没有该笔成交价时保留已知费用，不把参考中间价标成实盘报价。
- 兴业公开页面通过jqGrid接口加载数据，不能把初始HTML没有价格行当成银行没有报价。请求须含 `dataSet.page=1`、`dataSet.rows=80` 等官网脚本中的分页字段；缺少参数返回520。接口不提供牌价发布时间，`timeBasis=observed`明确记录采集时间，不拿页面时钟冒充发布时间。恒生中国、渣打中国的客户专属购汇价没有公开可采集接口；银行与免费同名渠道保留可选，不能用别行价格冒充。
- 手填实际报价只绑定当前账户／渠道；切换相关选择后清除，不影响无关银行的费用。

汇款预算内扣公式：`每笔汇出主金额CNY + 本笔手续费 + 电讯费 + 全额到账附加费 = 人民币本金 / 汇出笔数`。手续费按实际主金额逐笔应用最低、最高费。兴业GO附加50 CNY为每笔；农行25 USD旧模型仅保留历史测试，不在可选目录。

买入佣金从可用美元内求解。损耗分析只解释余额变化，不再扣一次换汇差额。新版页面使用相同参考值计入所有实际换汇差额，保留正负方向，避免把有利价差藏到另一套指标。

    内地购汇差额 = 扣汇出费后的人民币 × (1 − 最低有效卖出价 / 实际所选卖出价)
    本步损耗率 = 本步换汇差额及手续费CNY / 人民币本金
    全程损耗率 = 所有步骤差额及手续费CNY / 人民币本金
    最终余额折合CNY + 成本CNY + 税款 = 人民币本金 + 交易费前盈亏折合CNY

CNY原币到港成为CNH时第一步没有换汇差额；该人民币基准差异在真正兑换USD的步骤计入。原有研究API保留历史“各行自身中间价点差”计算，用于旧测试；当前页面统一走best-quote计算，不并列显示两套损耗。

截图回归：10万元、汇丰USD卖出价6.7321027、兴业优惠价6.70175，购汇差额450.86507667 CNY，即450.87元／0.451%。页面与选择器均保留报价原有小数精度；不再显示旧口径596.40元／0.596%。

未知但非负的银行费用不当作0：成本显示下限、余额显示上限；缺购汇成交价、地区单一费率或过期价格时，不显示一个貌似精确的总损耗。仍保留账户选择、已有收费与对应科目说明。具体缺项在明细中逐条命名。静态收费和已经选择的账户不会因为某一段缺报价消失。

期间管理费在最终余额扣除；初次到账是刚汇入时的余额，尚未发生未来持有期费用。先算原币单价×笔数／月数，再折合人民币。内部按完整精度计算，显示到分时分项可能有四舍五入尾差。

### 兴业报价与五折算法

公开数据地址为 `https://personalbank.cib.com.cn/pers/main/pubinfo/ifxQuotationQuery/list`，入口及单位定义来自[官网牌价页](https://personalbank.cib.com.cn/pers/main/pubinfo/ifxQuotationQuery.do)。原始快照保存普通现汇买卖价；优惠在模型按日期应用一次。

`中间价=(普通现汇买入价+普通现汇卖出价)/2`；`卡片购汇价=中间价+(普通卖出价−中间价)×0.5`。结汇方向相反。五折是点差五折，不是汇率乘0.5。例：普通USD买入668.27、卖出670.81 CNY/100 USD，卡片购汇价为6.70175 CNY/USD。优惠结束或已有实际成交价时不再叠加折扣。未来结汇日期超过优惠期也不沿用五折。

## 税款、用途与验证

默认交易盈亏0。税款以正的净交易利润折人民币估算，或以用户已核算的人民币应税所得覆盖，减有依据的境外抵免；不对本金征税，不产生负税额。境外财产转让所得税依据见[税务总局说明](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)。真实成本、汇率、允许费用及股息税须按对应事实处理。

大陆个人便利化购汇不得用于境外证券投资；银行免汇款费不代表资金用途获得许可。同名香港账户不改变这一限制。页面保留一句适用提示，细则放详情；不编造消费、留学等用途绕过审核。

报价刷新脚本对单行失败保留原价和时间，全失败不改文件，拒绝未来时间、异常买卖方向和倒退时间。静态费用核对日期不随市场报价自动更新。
