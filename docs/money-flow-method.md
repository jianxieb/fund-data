## 报价来源与可复现采集

本节是采集入口：**先查已保存报价及本节，不因页面修改重新寻找、覆盖或清空来源。** 采集器为[`scripts/refresh_money_flow_quotes.py`](../scripts/refresh_money_flow_quotes.py)，现行价格保存于[`data/money-flow-quotes.js`](../data/money-flow-quotes.js)。文末的[逐源抓取配方](#逐源抓取配方)列出全部15个采集源的页面、接口、请求方式、字段、单位、时间和落盘位置；[收费及规则来源全索引](#收费及规则来源全索引)对应数据目录全部来源ID。现行界面只使用目录中的部分机构，旧报价保留供历史规则和回归复现，不因菜单移除而丢弃。

```sh
# 先检查已有数据；查看 Git 历史可找回旧价格，不能把刷新失败当成旧价不存在。
rtk proxy git log -5 --oneline -- data/money-flow-quotes.js
rtk proxy git diff -- data/money-flow-quotes.js

# 只补缺少的 IBKR，不重抓已有银行报价。默认写入生产快照。
rtk proxy python3 scripts/refresh_money_flow_quotes.py --banks ibkr

# 研究时输出到临时文件；未批准用于页面的报价不要覆盖生产文件。
rtk proxy python3 scripts/refresh_money_flow_quotes.py --banks hsbchk --output /tmp/hsbc-reference.js

# 常规数据更新使用全部来源；既有 refresh-data 工作流调用同一个脚本。
rtk proxy python3 scripts/refresh_money_flow_quotes.py
rtk proxy python3 -m unittest tests.test_money_flow_quotes
```

所有银行报价使用机构自己的现汇买卖价：买外币用银行卖出价，卖外币用银行买入价。`banks.*.quotes`单位为CNY／1外币；`offshoreUsd.*.quotes`及`brokerUsd.*.quotes`单位为目标币／1 USD。`bidPerUsd`是客户卖USD所得目标币，`askPerUsd`是客户买USD所付目标币；不能反用、混入现钞价、中间价或其他银行的价格。香港人民币记CNH，即使上游字段写CNY。`capturedAt`只表示采集批次，逐币种`asOf`才是记录的时点；`timeBasis`与`timePrecision`说明该时点的含义，不能改写成“今天发布”。

共同请求头为`User-Agent: Mozilla/5.0`、来源页`Referer`和`Content-Type: application/json`，超时25秒；除工行中国POST `{}`及兴业会话预取外均GET。保留服务器TLS证书校验。返回值须通过`0 < buy ≤ sell`、卖买比不超过1.15、时间不得早于2025或超前本机15分钟的校验。失败源保留**原数值、原时间及原来源**，成功源只合并本机构本币种；旧时间不得覆盖新时间。全部失败则退出且不写文件，有成功才用临时文件原子替换。页面只读保存的JS快照，打开详情或切换方案不发网络请求。个人成交覆盖值优先于公开参考，换路线按既有规则清理不适用的个人值，不能清掉公共快照。

### IBKR：已抓到的直接USD/CNH买卖盘

[官网Global Access](https://portal.interactivebrokers.com/en/whyib/global-access.php)加载[`/lib/fxquotes/index.js`](https://portal.interactivebrokers.com/lib/fxquotes/index.js)。该组件的`conidData`直接声明USD.CNH合约为`113342317`，`mdFields`为84、86、6509；以页面实际声明为准，不猜合约ID。公开接口无需本次账户登录，URL及整组合约参数保存在逐源配方与生产快照的`endpoint`。首次响应可能只有合约ID；采集器按[官方快照接口说明](https://www.interactivebrokers.eu/campus/ibkr-api-page/web-api-trading/)只重试一次初始化响应，不轮询到成功，也不在失败时制造报价。

[官方字段文档](https://www.interactivebrokers.com/docs/web-api/v1/endpoints/market-data/market-data-fields)定义84=bid、86=ask、6509=行情可用性。首字符R=实时，D=延迟，Z=冻结，Y=冻结延迟；N/i等未订阅／不完整状态不接收为有效报价。`_updated`为毫秒快照时间，转北京时间写`asOf`和`timeBasis: snapshot`，**不能当作最后成交或休市收盘时间**。冻结／延迟标识随价格保存，详情明确显示；价格用于费用参考，不宣称账户可执行。

实际取得的[2026-10-25原始JSON](../tests/fixtures/ibkr-public-fx-20261025.json)含USD.CNH bid=6.66889、ask=6.67006，状态ZB，快照21:36:33.432。CNH入金买USD用ask，USD卖出换CNH用bid；手动佣金另按0.20基点、每单最低2 USD。公开盘不含AutoFX通常0.03%的加价，自动情景另计一次；个人AutoFX执行价已含加价时不再叠加。HKD/USD未接入，不借中银香港价格冒充IBKR执行价。

人民币原币刷卡按同额人民币扣账。消费终点用CNY面值；CNH统一估值与面值之间的差额在消费阶段结转，不把CNH估值溢价算成多买到的内地商品，也不改写各段成交价或凭空增加银行手续费。

### 汇丰直接兑换与经授权的参考估算

汇丰香港公开API已保存USD/HKD和CNY/HKD现汇买卖价。由这些数值计算的CNH行保留`path: via-HKD`和四个原始腿价：`bid=usdBuy/cnhSell`，`ask=usdSell/cnhBuy`，时间取两腿较早者。这能复现两笔兑换的参考金额；**没有证据时不能改名为One账户直接USD/CNH报价，更不能强迫用户走两笔兑换。** 原存值继续保留，不删除、不跨行替代。

[官方换算器页面](https://www.hsbc.com.hk/investments/currency-exchange-rate-calculator/)本次实际浏览只呈现说明和登录入口，没有可用的兑换表单／数值。另找到[官方旧外汇组件](https://mkdlc.ebanking.hsbc.com.hk/hsbcfxwidget/hsbc/ui/fx.html)：`../js/fx.js`请求`../../data/getFXList`，`../js/calculator.js`请求`../../data/calculate`；JSONP参数含`token`，计算参数为`buy_cur`、`sell_cur`、`buy_amt`、`sell_amt`、`compet_rate`和`compet_name`。无token访问`getFXList?callback=quoteCallback`实际返回HTTP 401；这是具体受阻入口，不声称已取得直接价，也不记录或构造私人凭证。后续若官方恢复公开组件，沿上述入口验证来源、买卖方向、金额档位和时间后再接入；个人账户实际询价只覆盖相应路线，不能公开用户凭证。

IBKR美元出金中转费与中银快汇USD返内地的额外处理费不是可从市场行情接口抓出的价格。IBKR[官方费表](https://www.interactivebrokers.com/en/pricing/other-fees.php)明确本方免费提款不包含银行／中转行费；中银[费表](https://www.bochk.com/sc/crossborder/remittance/charges.html)的160 HKD美元代理费明确排除内地，[快汇说明](https://its.bochk.com/banking/remit/help/ibs_rem_helpApp_s.html)仍列收款行与本行额外处理费。没有对应汇路的完整资费或回单时，不能称为银行确定收费。2026-10-26用户接受有来源的估算后，采用下面限定范围的参考情景；不填160，也不把旧1万HKD以内回款记录外推美元大额返程。Wise两段各10 HKD属于用户提供的收费情景，来源范围及实际Quote入口见下文，不写成官网通用价。

## 现行目录与资金流

按R105，出发银行只有中行、兴业寰宇人生、招行、工行；内地收款按R138／R154为这四家加建行。香港收款为中银香港、汇丰One、ZA、恒生、渣打、工银亚洲，取回银行另含建行亚洲；买股账户为IBKR、汇丰证券、ZA、致富、盈立，以及R156新增的Firstrade第一证券、嘉信国际。各角色独立，顺序稳定，不因应用某一优选隐藏其余机构。工银亚洲个人银行账户与券商企业工银亚洲收款账户分开。

Firstrade和嘉信国际按既有证券账户的美国USD电汇路径测算：先在香港银行备妥美元，再按券商美国收款指示汇入；不套香港本地CHATS收费。Firstrade出金25 USD，嘉信网上15／人工25 USD；实际代理费与香港银行收款费独立。美国上市股票／ETF网上佣金及平台费均为0，监管费另计。Firstrade按合资格碎股订单5 USD起、0.00001股精度且每笔超过0.00001股建模；嘉信明确使用整股情景，其Industry Fee按SEC／FINRA基准标注参考值。优惠、开户申请资格、其他币种自动兑换及其他证券类别不由这个目录选项承诺。来源及核查边界见需求清单R156。

四个节点连续展示机构和该账户金额，设置放在所属节点。各过渡先显示损耗，再显示动作与必要费用；完整原币、计算依据和来源在同一明细入口。汇往香港在第一、第二节点之间；股票入金在第二、第三节点之间；买卖及券商出金在第三、第四节点之间；第四节点是取回银行，其后才发生该银行换汇、消费或汇回内地。保留美元时第四节点已是终点，不再重复展示同一银行和余额。全程汇总位于流程底部，并以底部悬浮方式在滚动时保持可见。账户金额与机构主内容垂直居中；各账户及过渡使用统一列边界，左侧方向线与阶段总损耗连续贯穿，动作、设置及可读的明细入口在右侧。

本金默认10万元，修改入口和汇出笔数在第一节点。汇出币种按人民币原币、美元、港币排列。月数是银行期间费的输入，单独可改，不推算交易时间。页面按核算当天的已公布资费计算买入和卖出；主流程与买卖设置不再要求填写买入／卖出日期。优惠详情保留费用券到期日以及当次两笔订单的适用判断。

## 固定优选与费用资格

优选是独立维护的完整策略目录，不随下方银行、券商、资金用途、管理费资格、费用券或本金变化。人民币原币经汇丰、FPS入IBKR Pro后手动换USD的费用情景置首，直接显示各段币种及换汇地点；保留兴业寰宇人生经汇丰香港至Trade25、同一上游至ZA、中行至中银香港再入IBKR的美元路径，并补充兴业购USD→汇丰→Wise→IBKR。没有固定数量配额。每条方案横向显示各步产品名及参考费用百分比，各账户角色使用等宽列、统一行高，名称、币种说明和费用居中；Wise与内地银行保持独立节点。按R189–R192，主卡片不再列具体人民币金额或重复本金分母，方案限制与比较口径在右侧悬浮窗，鼠标或键盘可查看，Esc可关闭。不重复整条路线标题，说明窗不占行、不撑高卡片。人民币支付通方案按本次豁免测算，仍需符合银行的获准用途和额度；IBKR USD/CNH现采用已保存的公开买卖盘参考。确实缺价或缺费用的路线只列已计费用，不保证最低价。共同参考为10万元、1笔汇出、买卖各1笔、股价100 USD、12个月银行期间、银行管理费条件满足；含公开到账实录的代理费按参考费标记，不能宣称官网保证或全市场最低。

应用方案替换整套方案账户、渠道、标准交易假设和对应资格，保留用户本金，清除上一条路线的个人报价与费用券启用状态。Trade25方案明确使用Trade25，其余方案使用本身标出的收费模式。方案卡只显示按既定10万元情景计算的参考费率，比较本金与假设放在悬浮窗；正文具体费用按用户本金核算。该展示调整不重新采集报价、不变更既有路线或费用计算。应用后其他账户和设置仍可改，不能把当前未办理账户或未勾选条件作为隐藏方案的理由。

银行管理费默认按本持有期满足豁免条件，取消后按月收费，刷新保留明确选择。这个默认是用户指定测算情景，不代表银行对所有客户无条件免费，也不免汇款、存票和证券收费。收款、交收、中转、取回实际使用的银行去重计费；额外One账户的费用必须标明银行身份。银行条件与券商优惠分别放在各自节点。

费用券只抵适用的佣金或平台费，第三方监管／清算费独立；既不改变银行费，也不把银行价目改成缺失。逐单与总抵扣显示统一到4位USD小数，并分配展示尾差；原始费用、订单现金和净余额保持完整精度。具体券商账单如何取整仍须实际资费证据，不能将显示分配当成收费规则。过期、不足资料或无适用费用时明确不抵扣。

长收费条款、报价采集时间、完整报价表和核查过程放详情。机构图标来自官网现有资源，来源记录在assets/institutions/sources.json。弹窗保留外点、关闭按钮、Esc和焦点返回。后文的早期大范围枚举及动态候选记录属于历史研究，不能当成现行优选规则、现实汇路数量或整页完成证明。

## Wise美元桥接

香港银行已有USD可经本人Wise余额，再从IBKR的Transfer from Wise Balance关联入口入金。Pro与Lite均保留该可选费用情景，实际可用性由本人账户入口和Wise收款资料决定；美元入金仍按对应账户的USD收款指示；CNH／HKD原币FPS不按Pro／Lite名称区分。CNH／HKD原币入IBKR换汇仍走原本支持渠道；若用户主动先在香港银行换USD，再可选Wise。其他券商不套该合作路径。

## 实际动作与资金用途

IBKR现金账户自动换汇发生在买入外币资产时，HKD／CNH原币入金不会先变成美元。因此入金节点保留原币余额，自动加价及成交点差计入买入段；手动换汇与在香港银行先换美元仍各按自己的顺序。人民币原币资金的CNY／CNH估值差随实际换汇时点结转，不在未换汇的入金段制造损耗。

IBKR实际AutoFX成交价已经包含自动加价，不再另乘1.0003；实际价与统一基准的差额在买入段计一次。尚缺实际价时，参考汇率场景仍按官网通常0.03%的加价估算，不能把估算称为实际成交。手动兑换的成交价与另收的佣金独立，银行兑换也不另套AutoFX加价。

依据为[当前IBUK协议中IBLLC的G3／G4条款](https://gdcdyn.interactivebrokers.com/Universal/servlet/Registration_v2.formSampleView?formdb=6207)物理第45页和[2026年6月成本摘要](https://ndcdyn.interactivebrokers.com/Universal/servlet/Registration_v2.formSampleView?formdb=4378)第5–6页；协议身份不冒充直接美国客户合同。[IBKR现行资费](https://www.interactivebrokers.com/en/pricing/commissions-spot-currencies.php)的自动兑换通常加减0.03%、不另收佣金，并未提供具体成交买卖价。自动选项明确为现金账户，不把保证金借款利息场景当作免费自动兑换。原件与范围见[核查记录](../tests/fixtures/money-flow-ibkr-autofx-timing-20261012.json)。

汇款预算内扣公式：`每笔汇出主金额CNY + 本笔手续费 + 电讯费 + 全额到账附加费 = 人民币本金 / 汇出笔数`。手续费按实际主金额逐笔应用最低、最高费。兴业Go历史资费50 CNY为每笔，当前没有匹配的开通依据，不计入主界面可选渠道；农行25 USD旧模型仅保留历史测试，不在可选目录。

买入佣金从可用美元内求解。2026-10-26 R185纠正“负数参考损耗”：主流程、优选与汇总统一使用`transaction-cost`，只合计手续费与同机构、同币对买卖中间价的非负点差。各行自身点差不能与跨银行、跨币种或不同时点的估值差额混算。报价仍按实际买卖方向执行，点差只是成本分析，不从原币余额再扣一次。

    内地购汇点差 = max(0, 实付人民币 − 实得外币 × 本行同币对中间价)
    内地结汇点差 = max(0, 实兑外币 × 本行同币对中间价 − 实收人民币)
    买USD点差 = max(0, 来源币余额 / 本机构币对中间价 − 成交毛USD) × USD人民币参考值
    卖USD点差 = max(0, USD金额 × (本机构币对中间价 − 成交价)) × 目标币人民币参考值
    本步／全程费用率 = 对应手续费及点差CNY / 人民币本金
    估值变化 = 点差成本 − (换汇前人民币估值 − 换汇后人民币估值)
    最终余额折合CNY + 成本CNY + 税款 = 人民币本金 + 交易费前盈亏折合CNY + 估值变化

### 兴业报价与五折算法

## 税款、用途与验证

每一动作必须有足够资金支付其费用。小额余额低于买入最低费时不能用0买入额规避收费；亏损不得超过实际投入，税款预留不得超过卖出后的可用资金。局部错误保留之前已算余额和资费，未完成的后续余额不生成负数。出金错误下的最后可计美元余额已扣实际预留税款；无法支付的税款不记作已预留。输入相关错误同时显示在其编辑器，避免被弹窗遮挡。

## IBKR入金渠道与收费方案的边界

2026-10-25核实：[Lite官方说明](https://www.interactivebrokers.com/en/trading/why-ibkr-lite.php)将Pro／Lite区分为收费方案，Lite限合资格美国居民。FPS可用性不能只由方案名推导，须区分居住地、服务实体、币种及本人账户的存款指示。尤其不能推断美国居民把Lite切换为Pro后便获得香港FPS。

**国籍与居住地必须分开。** 上述美国居民条件不等于美国国籍条件；中国国籍本身不排除Lite。[官方开户帮助](https://gdcdyn.interactivebrokers.com/Universal/servlet/Registration_v3.formHelp)的Country of Legal Residence/Formation说明，法律居住地可与国籍、纳税地不同，并列出永久或不定期在当地工作、就学等情况。符合其美国居住及账户条件的中国籍留学生可以适用Lite；不能据“留学生”称谓推断每个人均符合，也不能把开户居住地直接等同美国税务居民身份。

以下`colr=CHN/USA`是法律居住地参数，不是第一国籍。若中国籍申请人的账户法律居住地是美国，不能因其国籍选用CHN结果；Lite资格与FPS资格仍须分开。用户反馈、实际页面修复与剩余问题统一维护于需求清单R181–R184。
