# 跨境资金：内地人民币出发、美股投资、内地人民币消费

## 流程及交互

图中节点依次为：内地CNY本金 → 香港原币到账 → 交易账户买入前现金 → 交易账户卖出后现金（税后）→ 香港本人回款账户 → 内地结汇并扣除账户及额外支出后的CNY消费预算。审计账额外保留结汇后、扣除期间成本前的余额；主图将结汇及期间支出合在末段，只在终点显示最终CNY。

- 起点仅标为“起始本金 · 汇出前”，不把尚未开始流转的累计损耗0与首段费用并排。后续节点写明账户、币种、情景余额和截至该节点的累计损耗；外币余额同时显示参考折合CNY。未知费用尚未扣除的余额明确标为上限。
- 每段箭头展示本段损耗率、逐项费用及合计；所有费用以非负CNY金额显示。汇出手续费、电讯费、全额到账费分别列示，买卖两侧佣金、平台费、清算、SEC、TAF、CAT以及证券账户月费分别列示。券抵扣分配到对应佣金/平台费后显示实收，不冲减监管费或月费。
- 人民币原币汇出到港为CNH，第一段换汇费为0；香港银行先换USD时显示银行换汇后余额，原币入券商时显示券商先收到的HKD/CNH余额。USD直达不经过HKD。
- 首段“汇出币种”只描述内地至香港这一步：人民币原币汇出，或内地购入美元／港币后汇出；到港后换美元的地点和方式在第二段选择，不混入首段选项。下方“换汇路径”比较仍描述截至交易账户入金的完整范围。
- 资金图的选择器在文档流内展开限高、可滚动的选项列表，后续内容顺次下移。银行名称与费用使用同一个控件正常排版，不在原生选择框上叠放白色内容层；选中后收起并返回焦点，支持方向键、Home／End、Enter、Escape和Tab。
- 每段按“费用明细 → 费用合计 → 税款／参考汇率折算增减值 → 本段损耗金额及损耗率”显示，折算增值明确标为抵减损耗、非返费，避免费用与损耗率无法核对。原始牌价、采集时间及完整守恒式保存在详情。
- 顶部只有人民币本金与使用月数，默认盈亏为0；盈亏、税款和其他情景在高级设置。非零盈亏情景有短提示，损耗率剔除该投资盈亏。

## 费用情景与出境资格分开

从内地人民币起算完整费用，不把起点偷换成已有境外美元，也不以用途限制阻止显示数值。**费用情景不是实际汇款资格、证券投资许可或银行执行承诺。**

大陆个人便利化购汇不能用于境外证券投资；转到香港同名账户不改变用途限制。跨境人民币仍受真实用途、资本项目和银行准入规则约束，不能把香港居民人民币汇款安排或跨境理财通闭环资金套用到内地居民普通美股券商账户。界面保留会影响结果解释的短提示，详细依据放在详情中，不提供虚构用途。

## 公开基准比较与渠道覆盖限制

遍历已收录的10家内地出发行、5家香港入金行、3个汇出币种、可支持的换汇方法、5家交易账户、5家香港回款行及有新鲜买入价的内地结汇行，比较整条路线。银行证券账户强制使用本行直接交收。FPS/eDDA、CHATS及SWIFT按币种和交易账户约束选择。

- 2026-10-09复核发现尚未完整覆盖中行手机银行同名优惠、跨境支付通等渠道，因此撤下“推荐·已知损耗低”和银行推荐徽标，只保留**公开报价基准**。已收录且关键收费齐备的路线内部按已知损耗排序，但不再把此局部结果称为最低损耗推荐。具体未知项始终保留，不当作已确认0元。全程损耗按相同参考值计算的 `本金 + 投资盈亏折合 − 最终CNY` 排序，不能只按点差费用合计排序。
- 未核对出发行手续费/电讯费、银行入金/汇入/回款/月费等关键收费的方案不参与排名；缺少实际IBKR HKD/USD或CNH/USD成交价的中间价模拟也不参与公开基准排序。公开银行买卖价仍是测算时点的报价，不是未来成交承诺。
- 兴业指定卡、恒生两地账户、汇丰卓越理财/适用豁免及渣打优先理财方案，出发或回款任一方向使用专用服务，都只有勾选已具备资格才纳入公开基准比较；更便宜但有资格条件的路线在图前显示差额和原因。资产占用另由实际另留资金与收益差计入，资格复选框表示已达标或已有适用豁免，不会凭空免去资产条件。
- 另列只用一个香港账户的USD路线；与公开基准不同就显示人民币差额。香港入金、回款可以使用不同账户，月费分别计入，相同账户只算一次。不因银行有未来收费调整就无理由将其排除。
- 回款银行汇出手续费使用预计卖出月份并纳入已公布收费变更；例如ZA 2026年11月起的70HKD不能被十月限时免收覆盖。未公布的未来常规收费按当前基准测算。
- 完整路线卡按公开基准重新计算，清除当前银行自填报价；该限制避免把某银行客户专属优惠带到另一银行。自填价格与费用用于自选路线并在详情标明。

本次纠错区分三件事：普通电汇标准收费、手机银行集团内汇款优惠、人民币跨境支付通。上版把标准价作为主要比较依据，却未完整覆盖优惠渠道，证据不足以支持“推荐·损耗低”。转账本身零收费，也不表示之前购汇或之后换USD、交易、回款全程零成本。

## 同一笔人民币内扣费及守恒

汇出主金额满足：

`每笔汇出主金额CNY + 本笔汇出费 + 全额到账附加费 = 人民币本金 / 汇出笔数`

百分比手续费按实际主金额计算，分别应用每笔最低与最高费，再购汇、中转、汇入。HKD/CNH入金后换USD或银行先换USD后入金，根据顺序在当时实际币种余额扣费。

- 手动：佣金=max(USD2, 净成交USD×0.00002)，净成交美元+佣金=换汇前美元等值。
- 自动：净美元=换汇前美元等值/(1+0.0003)，不另叠加手动佣金。
- 银行先换USD：有该行卖价时优先使用；缺报价时只保留明确标记的参考情景，换汇点差不伪装成0，不再加IBKR换汇佣金。
- 点差仅解释实际余额与银行自身买卖中间价的差额，不重复从余额扣第二次点差。购汇、结汇与银行换汇点差均为非负成本。
- 人民币原币汇出不进行换汇，这一步的换汇成本为0。CNY/CNH参考折算及不同银行、时点报价相对统一参考价的差额，作为有正负方向的 `fxImpactCny` 在主图与详情单列，正值不表示银行倒贴费用。
- 每个换汇项目满足：`原参考价差 = 非负点差成本 − 汇率折算影响`。自填价格优于参考中间价时，将超额部分记为折算影响，不制造负的手续费。

`最终可用CNY + 全部已知流转／交易成本／点差／账户／额外成本 + 税款 = 人民币本金 + 交易费前卖出盈亏USD×USD/CNY参照 + 汇率折算影响`

额外成本为实际开户／赴港支出，以及额外占用资产×年收益差×月数/12。另留资产本金不整笔当损耗；已全部投入券商的资金不能同时计银行保留资产。消费端最终是内地CNY，不添加香港外币卡签账费。

## 逐段损耗率与守恒

`flowLedger` 将同一参考向量 `refs = { CNY:1, USD, HKD, CNH }` 用于每段两端币值。不能用USD数量除CNY数量，也不能用出发行执行价格重新估值美元以掩盖其点差。

- `流入币值 = 流入数量 × refs[流入币种]`
- `流出币值 = 流出数量 × refs[流出币种]`
- `本段损耗 = 流入币值 + 本段交易费前盈亏折合 − 流出币值`
- `本段损耗率 = (流入币值 + 本段交易费前盈亏折合 − 流出币值) / 流入币值`
- 页面只展示损耗率，移除重复的保留系数。
- `累计损耗 = CNY本金 + 已发生投资盈亏折合 − 当前余额折合`
- 每一段都满足 `流入币值 + 投资盈亏折合 + 参考估值差 = 流出币值 + 费用合计 + 税款`。

费用合计包含对执行价格的非负点差拆解，并非全部都是另扣的现金手续费。因此费用合计可能与损耗金额不同，差额在各段费用下及详情中的参考估值账核对。若不同参考报价使某段损耗为负，保留真实负值，不取绝对值、不截成0，也不称银行补贴。未知费用存在时损耗仅为已知部分；连汇出服务费都未确认时，首段不显示数值损耗率。缺少真实成交价的参考模拟另有明确标记。

截图回归例：100,000 CNY从中行普通电汇、人民币原币到中银香港，汇出费99.82017982＋电讯费80＝179.82017982 CNY。同一快照中USD/CNY参考6.70035、USD/CNH参考6.697095，使99,820.17982018 CNH折为99,868.69558490 CNY；折算增值48.51576472 CNY。因此首段已知损耗为131.30441510 CNY、损耗率0.1313044%。193.22087982 CNY是加上下一段13.4007 CNY换USD佣金后的费用，不得放在首段香港银行选择框。固定快照写入回归测试；不把这组数字当作未来报价。

买入前节点为交易账户入金后的现金；买入/卖出两侧交易费全部归交易段，买入费用先在现金内求解，不重复扣。卖出后节点扣税后再出金。证券月费归交易段，银行月费及开户/资产机会成本最后作为消费预算扣除，不伪称其在最后一天实际被银行集中收费。额外成本可以是用户已支付的费用或机会成本，最终节点表示扣除此类支出的可消费预算，而非银行对账单金额。金额内部使用完整精度，显示到分时逐项之和可能存在分差。
