# 跨境资金：美股投资与人民币消费

核对日期：2026-10-08。界面默认一张连续资金图，已知费用自动比较；本文保存口径、边界和计算细节。

## 默认路径与自动推荐

目的固定为美股投资、内地CNY消费。默认10万元CNY等值的**已有合法境外USD**，并假设用户已有可使用的IBKR直接账户；这是费用示例，不推定用户实际拥有账户、资金或开户资格。其他资金选项为已有境外CNH、HKD及仅有内地CNY。

流程：香港同名银行 → IBKR以USD投资 → 卖出结算及税款预留 → USD返回香港银行 → USD汇回本人内地账户并结汇 → CNY消费。内地人民币出境用途核验入口在同一张图内，不能画成所有大陆居民都可自由进入普通美股券商的资金通道。

- **默认推荐**：从已收录的同名、同香港银行往返方案中，比较已知总费用；优先没有最低资产/月费且不依赖尚未结束的短期SWIFT优惠的方案。当前USD情景为恒生优进，不要求维持50万元资产。
- **最低费用**：包含当天生效的短期优惠，比较已知总费用。ZA截至2026年10月底SWIFT汇出免收，11月1日起70港元，日期跨过生效日自动改算。
- 每个银行均自动比较适用的IBKR手动/自动换汇。只在获得该银行的美元卖价时，计算银行先换USD再入金；目前限中银香港。不能把中银香港卖价套给其他银行。
- 内地结汇默认选中行、招行公开USD现汇买入价较高者；切换结汇银行保持原始资金金额和参照汇率不变。
- 银行手动选择可覆盖自动推荐；该银行的优惠只影响其自身，不能静默豁免所有竞品费用。页面输入优惠费后自动固定当前银行。

这是5家香港银行、2家内地银行、同银行往返及已知收费范围内的自动比较。不同银行组合、其他客户级别、未报价中转费及实际App报价可能改变结果，不能称作全市场绝对最优。未知费用未扣除时，结果明示为人民币到账上限。

## 必须在内地换汇吗，为什么不绕道HKD

**不要求一律在内地换汇，买美股也不需要HKD作为中间币种。**已有合法境外CNH且账户接受该币种时，可以按入金指示同币种入金，直接CNH→USD；已有USD直接原币入金。香港人民币为CNH，与内地CNY分别定价。

但是资金能否出境与在哪换汇是不同问题。大陆个人便利化购汇不能用于境外证券投资；同名香港账户不改变用途。跨境人民币经常与资本项目各有规则，不能将跨境理财通闭环资金转入普通券商，或把港人每日8万元汇款安排直接套给大陆身份证客户。仅有内地CNY时保留整张图、停止金额推演，并链接境内投资渠道。

来源：[外汇局](https://www.safe.gov.cn/shanghai/2019/1213/1198.html)、[人民银行跨境人民币规定](https://www.pbc.gov.cn/chubanwu/114566/114579/4356052/4356380/2021100915525242238.pdf)、[渣打境外转账条款](https://www.sc.com/cn/electronic-banking-overseas-transfer-service-terms/)、[IBKR支持CNH入金](https://www.interactivebrokers.com/campus/glossary-terms/chinese-offshore-renminbi-cnh/)。

## 汇率、单位与守恒

内地中行、招行每100外币公开报价转换为每1USD的CNY金额，结汇用现汇买入 `buy`。中银香港美元报价**每1USD的外币金额**直接保留为 `bidPerUsd / askPerUsd`，香港人民币字段映射为CNH；独立放在 `offshoreUsd`，不与内地CNY字段混用。买USD用ask；卖USD用bid。

成本折算参照：USD/CNY取中行公开USD买卖价中间值（中行缺失时取另一已收录行），USD/HKD及USD/CNH取中银香港公开买卖价中间值。不是市场中间价，也不是IBKR成交价。用户可覆盖券商换汇价、结汇价与三组参照。

CNH/HKD券商换USD仅作公开中间参考价情景；实际成交可能改变排名。中银香港银行换USD使用该行真实公开ask，但公开参考牌价也不是客户App最终成交价。不同银行报价时间单独保留，不能假设同步撮合。

起始原币金额 = CNY等值预算 / 该币种参照CNY价。手续费在资金内扣除，不额外假定另一笔钱支付。手动与自动按扣费后金额比较：

- 自动USD余额 = 原币金额 / 每USD原币价 / (1 + 0.0003)。无第二笔手动佣金。
- 手动佣金 = max(USD2, 净成交USD × 0.00002)，净成交USD + 佣金 = 换汇前美元等值。
- 银行先换USD入金：银行卖价已含价差，不再加券商换汇费。

成交价已含价差；只把其与参照折算值的差额列成损耗，不重复扣一个点差百分比。相对参照的差额可为负，并不代表无风险获利。消费端使用内地CNY，不再加香港卡片的外币签账附加费。

守恒式：

`最终可用CNY + 已知流转及交易成本 + 税款 + 额外成本 = 起始CNY等值 + 交易费前卖出盈亏USD × USD/CNY参照`

额外成本：开户/赴港自填支出 + 额外占用资产 × 年收益差 × 使用月数 / 12。保留资产本金不整笔当损耗。本次全部投入的资金不能同时视作银行内持续维持月费豁免的资产。

## 税款与未知费用

大陆税收居民境外财产转让所得通常20%，按人民币处置收入、成本及允许费用核算；不是对本金或整笔提现征20%。可抵免境外税额有凭证及限额规则，境外股息等所得另行核算。[税务总局](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)。

默认盈亏0，不预测美股收益。卖出盈亏输入为交易费前，买卖交易费另扣。未填已核算应税所得时，仅以正的净交易利润USD×USD/CNY参照估税，**假定买入卖出汇率相同**；不推定真实人民币成本、汇率损益、可扣汇款费用及税务抵免。已核算人民币应税所得优先，税率和抵免可改，亏损无负税款。

买卖交易费、券商出金中转费、回内地中转/收款费没有统一可用报价，默认留空并明确标为未计。确认免收才填0；不以虚构0证明真正最低费用。无效金额、负费用、非整数出金次数、零/负汇率拒绝出具金额。

公开牌价自动更新覆盖中国银行、招商银行、工商银行、建设银行、农业银行、交通银行、汇丰中国，以及中银香港的USD/HKD和USD/CNH报价。工行、农行与交行按每100外币报价；建行按每1外币报价；汇丰中国原始API给出倒数，按官网算法取倒数后比较。汇丰仅给日期，保留日期精度，不能写成当日某个虚构时刻。
