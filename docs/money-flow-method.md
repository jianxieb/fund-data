# 跨境资金：内地人民币出发、美股投资、内地人民币消费

核对日期：2026-10-09。首页固定以**内地本人银行卡的人民币本金**起算，所有流程放在同一张可切换的图中。本文保存计算口径和证据边界。

## 流程及交互

内地人民币本金 → 内地购汇或人民币原币汇出 → 香港本人银行 → IBKR直接账户 → USD投资及卖出 → 税款预留 → 香港本人银行 → 内地本人银行结汇 → CNY消费。

- 图中可以分别选出发银行、换汇路径、内地汇款方式、香港入金银行、券商入金方式、换USD方式、香港回款银行、内地收款银行及回款渠道。
- 每个环节显示资金余额、该步已知费用、具体待确认费用；汇率折算影响与银行、券商、中转费及换汇点差独立列示。
- 下方银行基准表比较只更换出发银行、香港入金银行或换汇路径后的全程结果。切换银行不重置本金、盈亏、账户使用月数、交易费或税率。
- 银行专属报价及收费覆盖只绑定当前银行和方式；切换不匹配的账户或渠道后清除该项覆盖，不传给其他银行。
- 调整本金和费用只重绘图、汇总及比较表。输入框、光标位置和展开状态不重建。
- 券商只收录已核对的IBKR直接客户费率，不能套用给转介券商。

## 费用情景与出境资格分开

从内地人民币起算完整费用，不把起点偷换成已有境外美元，也不以用途限制阻止显示数值。**费用情景不是实际汇款资格、证券投资许可或银行执行承诺。**

大陆个人便利化购汇不能用于境外证券投资；转到香港同名账户不改变用途限制。跨境人民币仍受真实用途、资本项目和银行准入规则约束，不能把香港居民人民币汇款安排或跨境理财通闭环资金套用到内地居民普通美股券商账户。界面保留会影响结果解释的短提示，详细依据放在详情中，不提供虚构用途。

来源：[外汇局](https://www.safe.gov.cn/shanghai/2019/1213/1198.html)、[人民银行跨境人民币规定](https://www.pbc.gov.cn/chubanwu/114566/114579/4356052/4356380/2021100915525242238.pdf)、[渣打境外转账条款](https://www.sc.com/cn/electronic-banking-overseas-transfer-service-terms/)。

## 默认推荐与最低已知费用

- **最佳实践**：公开报价和关键银行收费齐备，购汇不超过3天，优先内地直接换USD、无需验资或指定卡、香港账户免月费且不依赖即将结束的汇出优惠。不强制绕经港币。

## 牌价基准及单位

自动刷新：中行、招行、工行、建行、农行、交行、汇丰中国，以及中银香港USD/HKD、USD/CNH。每行独立保留官方链接与时间；汇丰只给日期，不能补一个虚构时刻。

- 工行、农行、交行、中行、招行按每100外币报价，归一化成每1外币。
- 建行接口直接给每1外币结售汇报价，不使用银行间交易价或现钞价。
- 汇丰中国接口给倒数，按官网算法取倒数；不能原样作为USD/CNY。
- 中银香港是每1USD的外币金额，直接保留，不除100；“人民币”在香港映射CNH，与内地CNY分开。
- 购汇用出发银行现汇卖出，结汇用收款銀行现汇买入。不能借另一银行报价填补缺口。
- 兴业公开接口本次返回空牌价，恒生中国、渣打中国需账户询价，手动输入本行成交价后计算。
- 参照USD/CNY取中行买卖中间值，缺失时取另一行；USD/HKD及USD/CNH取中银香港中间值。券商换USD使用这个公开参考价情景，**不是可执行IBKR报价**。
- 只有中银香港具有公开换USD卖价的银行先换方案，其他银行须手填自己的价格；不会套用中银价。
- 自填成交价及收费绑定选定银行，推荐比较不会拿客户专属优惠豁免所有竞品收费。

## 同一笔人民币内扣费及守恒

汇出主金额满足：

`每笔汇出主金额CNY + 本笔汇出费 + 全额到账附加费 = 人民币本金 / 汇出笔数`

百分比手续费按实际主金额计算，分别应用每笔最低与最高费，再购汇、中转、汇入。HKD/CNH入金后换USD或银行先换USD后入金，根据顺序在当时实际币种余额扣费。

- 手动：佣金=max(USD2, 净成交USD×0.00002)，净成交美元+佣金=换汇前美元等值。
- 自动：净美元=换汇前美元等值/(1+0.0003)，不另叠加手动佣金。
- 银行先换USD：使用该行卖价，不再加券商换汇佣金。
- 点差仅解释实际余额与银行自身买卖中间价的差额，不重复从余额扣第二次点差。购汇、结汇与银行换汇点差均为非负成本。
- 人民币原币汇出不进行换汇，这一步的换汇成本为0。CNY/CNH参考折算及不同银行、时点报价相对统一参考价的差额，作为有正负方向的 `fxImpactCny` 单列，正值不表示银行倒贴费用。
- 每个换汇项目满足：`原参考价差 = 非负点差成本 − 汇率折算影响`。自填价格优于参考中间价时，将超额部分记为折算影响，不制造负的手续费。

`最终可用CNY + 全部已知流转／交易成本／点差／账户／额外成本 + 税款 = 人民币本金 + 交易费前卖出盈亏USD×USD/CNY参照 + 汇率折算影响`

额外成本为实际开户／赴港支出，以及额外占用资产×年收益差×月数/12。另留资产本金不整笔当损耗；已全部投入券商的资金不能同时计银行保留资产。消费端最终是内地CNY，不添加香港外币卡签账费。

## 税款及未知费用

中国大陆税收居民境外财产转让所得通常20%，按人民币收入减成本及允许费用核算，股息另行核算。[税务总局](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)。

未填已核算应税所得时，以正的净交易利润USD×参考USD/CNY估税，假定买卖汇率相同。真实人民币成本、汇率损益及允许费用另核。已核算应税所得优先；有依据的境外税抵免再扣。本金不征此税，亏损不产生负税额。

默认盈亏0、交易费0是无交易成本的流转情景，买卖费用可填。SWIFT中转、代理、收款行未知则留空并逐项标示；客户确认免收才填0。无效数字、負手续费、零或负汇率、非整数笔数不出具数值结果。
