# 跨境资金费用测算

核对日期：2026-10-11。需求、原始截图和验收记录以[跨境资金需求清单](money-flow-requirements.md)为准。资料在data/money-flow.js，牌价在data/money-flow-quotes.js，模型和界面分别在assets/money-flow-model.js、assets/money-flow.js。

## 账户选择与报价分别处理

银行目录固定为中行、兴业、招行、工行、建行、交行、汇丰中国、恒生中国、渣打中国；香港银行为中银香港、汇丰、ZA、恒生、渣打；买股账户为IBKR、汇丰证券、ZA、致富、盈立。农业银行按用户明确要求移除，历史数据只留研究测试。

选项顺序不随当前选择或报价变化，不隐藏、不禁用其他银行与券商。渠道的适用条件只作用于对应步骤：例如同名集团渠道须配对账户，FPS不能汇USD；这些条件不能取消用户更换账户的权利。缺少成交报价不表示账户不可选，也不能成为删除银行的理由。

## 连续资金流与方案

主界面按实际资金流连续展示四个节点，每个节点包含已选账户、所处时点的余额和币种，节点之间先显示动作和本段损耗，再显示主要费用。没有逐步翻页、独立编辑页或只有名称的侧栏。全程损耗、账户期间费和最终余额固定在底部汇总。

本金默认10万元，在第一节点只保留一个“修改”入口；汇出笔数也在第一节点。银行期间费和HSBC One条件放香港银行节点，Trade25和证券优惠放买股节点。费用券按实际抵扣额显示，留空、过期或不适用时不声称已经抵扣，也不影响其他步骤。

主界面按五个买股账户各展示一条较低全程费用路线，按总损耗排序；每张卡直接包含出发银行、香港收款银行、买股账户、币种、汇款方式、资金终点、损耗率和金额。它们来自目录组合计算，替代原来六条固定预填方案。中行→中银香港→ZA仍是默认状态；兴业等九家内地银行、五家香港银行及五个买股账户的选择器不减少、不联动锁定。

比较保持相同本金、笔数、月份、交易假设、已勾选优惠资格和资金用途；不自动增加笔数、开启Trade25、假设管理费减免或继承另一家银行的手填价。逐项比较目录内的汇出银行、币种、已收录渠道、香港银行、入金方式、换汇位置及出金终点。先排除汇入前即缺报价的路线，再展开后续组合，只有全程科目有数值、必要报价未过期的结果参与排名。每个买股账户选择总费用较低的一条，同价时优先少用香港账户、少换一次汇。某买股账户没有完整结果时保留可选的常用途径并列出缺项，残缺小计不参与最低比较。

排名包含明确标记的公开操作记录与参考费用；它是已收录报价条件下的费用比较，不是官方保证或全市场最低声明。普通兴业汇款的代理收费不因“低汇差”就自动设为0；全额到账渠道只有在当前笔数与单笔上限相符时进入比较。数据缺项继续记入A01，R69的计算与交互实现不代表A01完成。

点击方案不增加笔数、不自动勾选优惠，保留上述用户条件；只有对应路线和原来绑定的个人报价会替换。兴业默认普通汇款，50元全额到账服务另选。选择器稳定，不展开占正文；只有一个有效渠道时直接显示文本。长收费条款、采集时间、完整报价表和证据放详情，主要费用始终在正文。弹窗支持外点、关闭按钮、Esc和焦点返回。

## 实际动作与资金用途

收款银行与买股账户分开。中银香港→本人ZA或汇丰银行USD账户使用本地转账，再由银行证券服务内部交收；换券商不会改收款银行。独立券商使用其公布的收款账户及支持渠道。

| 终点 | 实际动作 |
| --- | --- |
| 留在买股账户 | 卖出后保留USD；不发生出金、香港回款或内地结汇 |
| 取回香港银行、保留美元 | 出金至所选本人银行，保留USD |
| 美元原币消费 | 出金至支持USD扣账的银行，以足额USD直接刷卡 |
| 换人民币后消费 | 使用所选消费银行自己的USD/CNH报价；中银香港直接兑换，汇丰／恒生按公开牌价经HKD分两段兑换 |
| 汇回内地结汇 | 所选香港银行汇回所选内地银行，按其USD买入价结汇 |

ZA卡不适用USD原币扣账，其他消费账户可重新选择。香港银行没有公开的CNH兑换报价时，不能自动借用中银香港的价。CNY、CNH和USD始终保留真实币种。

## 中行、兴业与集团优惠的证据

- [中银香港同名汇款官网](https://www.bochk.com/tc/crossborder/personal/financialservicehk/remittance.html)确认同名内地中行的基本汇入费豁免；香港方向的网上／手机同名汇出基本费亦免。条款第3项不包含代理行费用。
- [中行2025年手机银行公告](https://www.boc.cn/big5/ebanking/bi3/bi31/202504/t20250430_25339098.html)只覆盖2025年5–12月。[2026年公开报道](https://www.sohu.com/a/1028992119_121123789)和[2026-02-09美元／港币操作记录](https://www.huigeblog.com/news/operational-guide-for-cross-border-remittance-via-bank-of-china-hong-kong.html)支持手机银行向同名境外中行汇款的0汇出费、0电讯费及同行SHA路径0代理费情景。证据标记为公开报道／操作记录，不能当成全国无条件保证，不扩展到人民币、其他收款行或普通SWIFT。[Linux.do记录](https://linux.do/t/topic/2632770?tl=zh_CN)使用人民币跨境支付通，不能当成美元电汇免代理费证据。
- [兴业寰宇人生权益](https://mobile.cib.com.cn/netbank/cn/personal/debit/index.html)提供2026-07-01至2027-06-30购结汇点差五折、前30笔电讯费免及汇款手续费免。普通汇款不另加50元。
- [兴业小额全额到账](https://www.cib.com.cn/cn/aboutCIB/about/charges/zfNotices/20240204.html)是另外的50 CNY/笔服务，限等值10,000 USD以内且App须提供该收款账户服务；含境外行费用。超限只在本步报错，不偷偷拆笔或换服务。
- [恒生两地同名跨域转账](https://www.hangseng.com/zh-cn/personal/banking/cross-border-view-and-transfer/)明确指定渠道免费；人民币由内地到港若发生人民币清算费，官网说明当天退回。
- [汇丰环球转账](https://internationalservices.hsbc.com/zh-cn/international-banking/global-view-global-transfers/)按已登记同名账户渠道；[渣打境外汇款](https://www.sc.com/cn/bank-with-us/overseas-remittance/)区分客户等级，同名三费豁免采用优先理财的指定渠道，不能泛化为所有普通客户和外部银行免费。
- [盈立中银香港入金指引](https://hk.usmartglobal.com/zh-hk/helpframe/42/detail/10139)明确支持USD同行收款并免费，已新增为独立于跨行CHATS的入金方式。该证据不自动扩展成其所有跨行出金都免费。
- [兴业外汇汇入说明](https://mobile.cib.com.cn/netbank/cn/personal/wealth-management/foreign/inward.html)明确免收入账费，不含国外中间行费用。[汇丰中国2026-09-29生效价目表](https://www.hsbc.com.cn/content/dam/hsbc/cn/docs/document-download/tariff-of-accouts-and-services.pdf)第16页2.2.9.1确认个人海外汇款存入汇丰中国账户免费；第14页卓越理财普通电汇为1‰、最低100元、最高500元，另120元电报费。普通电汇与第15页免费的同名环球转账分别计算。

跨境支付通与普通电汇不是一项服务，研究模型保留其资格与历史实例，不把受用途限制的便利化支付渠道当作美股入金的推荐。中行→中银香港的原币转账费豁免也不等于所有人民币购汇差额为0。

## 组合检查与真实边界

运行node scripts/audit_money_flow.cjs --write，结果见[money-flow-combinations.json](money-flow-combinations.json)。9×5×5×5×9×3×5＝151,875个目录状态全部经过检查，包括未使用取回账户、内地收款账户的重复状态。每一状态须能选择；模型返回可核金额或具体步骤问题。已算余额全部校验本金、盈亏、费用与税款等式；不允许NaN、不允许缺项却标“完整”。

2026-10-11公开快照检查中：3,949条状态费用科目齐全（去重369条），117,551条有具体报价缺项，30,375条存在不支持的刷卡币种、支票出金至ZA、未确认的渣打人民币账户资格或渣打中国购汇价缺失。121,500条有最终余额的状态均通过金额守恒检查。这里的“完整”表示模型所列科目有数值，仍可能含有已标明的公开实测或参考费率，**不表示官方承诺全额到账，也不是“所有费用已经查齐”**。模型检查覆盖所有目录状态，不把每个笛卡尔积组合宣称为真实可办理汇路，不把未知项改成0或删掉账户。

附加服务与个人报价在独立边界测试覆盖，不含在上述普通默认渠道计数中。测试涵盖金额不足、GO单笔边界、优惠第30／31笔、过期、0／1／12个月、佣金、券、买卖订单、利润和报价失效。真实无法统一定价的项目仍是需求清单中的开放事项，不能将自动检查写成用户验收通过。

依据：[中银香港汇款收费](https://www.bochk.com/sc/crossborder/remittance/charges.html)、[ZA现行收费](https://bank.za.group/hk/notice-detail/979ca80f-2fb4-4add-b30c-18144d3a757f)、[ZA官方本地USD指南及直连名单](https://cdn.zaticdn.com/if/ipage/prd/data/blog/a1e7a724-9c51-421a-936a-a339d6d18c4e/en/USD-local-bank-transfers.html?v=1758617552695)。其他银行官方来源见数据源清单。ZA直连名单包括中银香港、汇丰、恒生和渣打；其2026年11月SWIFT收费变更不改变本地CHATS零收费。

收款、证券结算、取回三类实际使用的银行账户按银行去重计管理费。选择“留在买股账户”时，不计未使用的取回银行；银行证券本身需要的结算账户仍计费。每月单价×持有月数先得到原币期间金额，再折人民币。例如100 HKD/月×12个月=1,200 HKD，人民币金额为1,200×当次HKD/CNY参考价。HSBC One的银行管理费与Trade25证券月费是两项。证券市值可计入该行全面理财总值，但不能假定所有资金在整个期间都满足其平均结存要求；页面提供已满足条件的选择。

中银快汇和网上SWIFT到内地同名中行的基本汇出费均为0；SWIFT须按官网要求以BKCH开头的11位BIC或CNAPS指定收款行。汇至其他银行的普通SWIFT保留65 HKD标准价，代理费用均另列。普通电汇从外部券商汇入中银香港超过500 HKD等值时基本汇入费60 HKD；不能套到本地美元支票或个人CHATS。

[盈立本地美元出金规则](https://hk.usmartglobal.com/zh-hk/help-centre/42/detail/12115)：传统香港银行按支票存款，费用0、没有旧500 HKD起点；数字银行须超过20 USD，银行费公布为“约7.5 USD”。后者在费用行、本段及总额都标参考费用，不能写成固定保证价。致富本地美元支票存入汇丰、中银香港、恒生香港按各银行本地支票规则为0；[恒生2026年7月收费表B.5](https://www.hangseng.com/content/dam/hase/config/bde/pws/personal/servicecharges/pdfs/zh_HK/tariff_personal_sc.pdf)明确本地美元交换票存入美电账户免费。不能把海外支票托收价套到香港本地支票；渣打本地美元支票收费尚缺对应证据。

[HSBC One官方FAQ](https://www.hsbc.com.hk/content/dam/hsbc/hk/vam/pdf/HSBC_One_FAQ.pdf)规定全面理财总值包含证券市值。2026年新开非香港身份证账户按过去三个月平均总值判断1万港元门槛；旧账户、香港身份证及其他豁免须按实际资格选择。不能仅凭本次本金大于1万港元就自动认定整个持有期免费，也不能把证券市值排除后算贵。

## 牌价、费用及人民币核对

- 自动牌价覆盖中行、招行、工行、建行、交行、兴业、汇丰中国、恒生中国，以及中银香港、汇丰香港、恒生香港USD/HKD、USD/CNH。历史农行抓取保留，但不进入产品目录与比较基准。每行保留官网链接与时间；缺失不借用其他银行成交价。
- 工、农、交、中、招报价按每100外币归一；兴业使用接口货币单位归一；建行接口直接每1外币；汇丰中国按官网算法取倒数。中银香港的每1USD外币金额不再除100，人民币归类CNH。
- 购汇用所选出发行现汇卖出价；内地结汇用收款行现汇买入价；香港换汇只使用所选银行的报价。汇丰／恒生香港通过HKD的实际两段交易分别列示金额和差额：CNH→HKD用CNH买入，HKD→USD用USD卖出；反向USD→HKD用USD买入，再用CNH卖出兑换。两个差额之和等于该换汇步骤差额。
- 当前页面以目录内最低有效USD卖出价确定USD/CNY参考值，以最低有效HKD卖出价确定HKD/CNY参考值。CNH仍用中银香港USD/CNH参考中间价折算，不能借作其他银行成交价。
- IBKR手动换汇佣金0.002%、最低2 USD；自动兑换0.03%加价，二者不叠加。实时买卖价不是静态佣金表；没有该笔成交价时保留已知费用，不把参考中间价标成实盘报价。
- 兴业公开页面通过jqGrid接口加载数据，不能把初始HTML没有价格行当成银行没有报价。请求须含 `dataSet.page=1`、`dataSet.rows=80` 等官网脚本中的分页字段；缺少参数返回520。接口不提供牌价发布时间，`timeBasis=observed`明确记录采集时间，不拿页面时钟冒充发布时间。

汇款预算内扣公式：`每笔汇出主金额CNY + 本笔手续费 + 电讯费 + 全额到账附加费 = 人民币本金 / 汇出笔数`。手续费按实际主金额逐笔应用最低、最高费。兴业GO附加50 CNY为每笔；农行25 USD旧模型仅保留历史测试，不在可选目录。

买入佣金从可用美元内求解。损耗分析只解释余额变化，不再扣一次换汇差额。新版页面使用相同参考值计入所有实际换汇差额，保留正负方向，避免把有利价差藏到另一套指标。

    内地购汇差额 = 扣汇出费后的人民币 × (1 − 最低有效卖出价 / 实际所选卖出价)
    本步损耗率 = 本步换汇差额及手续费CNY / 人民币本金
    全程损耗率 = 所有步骤差额及手续费CNY / 人民币本金
    最终余额折合CNY + 成本CNY + 税款 = 人民币本金 + 交易费前盈亏折合CNY

CNY原币到港成为CNH时第一步没有换汇差额；该人民币基准差异在真正兑换USD的步骤计入。原有研究API保留历史“各行自身中间价点差”计算，用于旧测试；当前页面统一走best-quote计算，不并列显示两套损耗。

未知银行费用不当作0。费用缺项时展示已核费用及具体缺少的科目，不使用“上限／下限”掩饰未收集数据，不把小计包装成全程损耗。余额明确已扣除哪些已核费用；缺换汇价时保留最后可核对币种的余额。仍保留账户选择、已有收费与对应科目，不因末段换汇缺项清空前段。

出发行购汇价缺失时也保留人民币本金、可独立计算的汇出费、明确豁免的中转／汇入费和银行期间费；只留空需要该汇率的外币余额。没有任何已报价科目的步骤显示“—”，不能把空集合相加得到的0当成免费；缺价和牌价过期分别标识。手续费重复提示只保留一次。

期间管理费在最终余额扣除；初次到账是刚汇入时的余额，尚未发生未来持有期费用。先算原币单价×笔数／月数，再折合人民币。内部按完整精度计算，显示到分时分项可能有四舍五入尾差。

### 兴业报价与五折算法

公开数据地址为 `https://personalbank.cib.com.cn/pers/main/pubinfo/ifxQuotationQuery/list`，入口及单位定义来自[官网牌价页](https://personalbank.cib.com.cn/pers/main/pubinfo/ifxQuotationQuery.do)。原始快照保存普通现汇买卖价；优惠在模型按日期应用一次。

`中间价=(普通现汇买入价+普通现汇卖出价)/2`；`卡片购汇价=中间价+(普通卖出价−中间价)×0.5`。结汇方向相反。五折是点差五折，不是汇率乘0.5。例：普通USD买入668.27、卖出670.81 CNY/100 USD，卡片购汇价为6.70175 CNY/USD。优惠结束或已有实际成交价时不再叠加折扣。未来结汇日期超过优惠期也不沿用五折。

## 税款、用途与验证

- 兴业普通跨境人民币按[综合服务价目表000302／000305](https://www.cib.com.cn/cn/aboutCIB/about/charges/adjustment/combined.html)：零售客户汇出1‰、最低50元、最高200元，另加100元电讯费。000302服务内容明确包括跨境人民币；寰宇人生的免手续费及前30笔免电讯费明确限于“跨境外汇汇款”，因此人民币路径不继承这两项优惠及其到期日。默认10万元含费本金、1笔时，汇出99,800.20 CNH，本行手续费99.80元及电讯费100元。境外代理费仍单独计算；未假设其他VIP级别减免。

含费本金按每笔实际汇款额所属档位反算。对阶梯跳升导致无法恰好用尽本金的情况，取可支付的最大汇款额，差额留在内地账户，单独展示并纳入总资产核对，不计作损耗。例如2,004元按恒生普通人民币渠道汇出2,000元、手续费2元、内地账户保留2元。对渣打百万档位之后手续费略降的情况，逐档求解，不依赖全域单调假设。
