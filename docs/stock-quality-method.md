# 长期优质企业与高质成长股的研究方法


## 2026-09-30：长期定位与成长阶段分开

“优质企业”更名为**长期优质企业**，保留原v4全部20项财务与当前增长检查，并增加：连续5个完整财年归母/扣非利润与经营现金流均为正；5年平均年度ROE≥15%且各年为正；逐公司记录业务持续性、再投资方向与失效信号。不是只把最近一年的高ROE改叫长期质量。

新增**高质成长股**：非ST/非金融、市值≥100亿元；最新累计营收增长≥20%，归母及扣非均≥30%；连续两个可比单季也满足这三项；扣非/归母≥80%、当期ROE为正；两年完整财年正利润、正扣非和正经营现金流；上年ROE≥10%；TTM经营现金流为正；最后核对当前报告期的主营增长来源。负/零基数、一次性款项、并表和周期涨价不能仅凭增速自动入选。

参数用于清晰定义本项目研究范围，未按收益或名单数量优化。与原stock-research中报初筛相比，取消净利≥5亿元及中报ROE≥7%的直接套用，增加经常性利润、季度连续性和现金质量。业务证据未更新到最新报告期时，不能继续沿用旧成长标签。

本次范围：原初筛10家、原个股报告10家与本项目12家去重后26家。结果为长期优质12家、高质成长6家，重叠4家：工业富联、宁德时代、中际旭创、沪电股份；成长新增生益科技、长川科技。主名单共14家公司，红利价值23家独立保留，产品行去重后37家。高质成长并非要求长期条件已经全部成立，生益与长川的历史ROE/现金低谷保留为风险；长期优质也不强行标高成长，例如天孚Q2收入减速、盛弘Q1利润增速不足。

[逐公司复核记录](research/growth-review-2026-09-30.json)保留全部26家计算与具体判断，未入选公司不占主表行。利通电子的财务增长虽然可过初筛，但中报第13页显示净额经销与租赁必须分拆，本次在主营质量审查中排除。

## 当前财务与报告条件

参数在 `stock_fundamentals.py:QUALITY_LIMITS`，均为项目研究参数，不是市场共识，不按目标名单数量或未来收益调参。全部20项检查同时成立才显示：

- 非金融、非ST，总市值≥100亿元，有至少5年实际可观察价格历史。缺价格历史不能等同于上市不足5年。
- 最近三个完整财年归母及扣非利润均为正，且两项利润**逐年增长**；同期经营现金流每年为正。
- 三年平均年度加权ROE≥15%，任何一年≥10%，最新完整年度≥15%。
- 以相距三年的完整年报计算CAGR：营收≥5%，归母及扣非利润均≥10%；各项起终值须为正。
- 最新完整年报的营收、归母及扣非利润同比均≥10%。利润仍然为正但同比下降80%，或仅增长3%，均不能靠“连续盈利”入选。
- 收录最新应披露报告；当前为2026中报。最新报告归母及扣非利润为正，营收、归母及扣非利润同比均≥10%。扭亏、零基数及缺可比数据不能作为普通高增速通过。
- 最新报告ROE为正，相对上年**同一报告期**下降不超过20%。中报ROE不乘2，也不与年度15%门槛混用。
- 有证券身份匹配的人工报告研究记录、具名报告链接、具体业务依据及风险；报告和核对日期不得在未来，研究记录一年内须更新。

最新财报截止约束：4月30日起要求本年一季报，8月31日起要求中报，10月31日起要求三季报；此前允许上一年三季报。季度财务更新不自动改写人工业务结论，业务依据保留其报告期和研究日期；公司报告研究过期后停止展示。

现金流判断：年度经营现金流为正是硬条件；三年经营现金流/归母利润<1倍、最新报告现金流/利润<50%会显示具体金额与比例风险。没有把增长率、ROE或经营现金流等同于自由现金流，也没有声称高增长自动抵消营运资金风险。

## 数据字段与界面

- 财报：东方财富 `RPT_F10_FINANCE_MAINFINADATA` 的 `TOTALOPERATEREVE` / `TOTALOPERATEREVETZ`、`PARENTNETPROFIT` / `PARENTNETPROFITTZ`、`KCFJCXSYJLR` / `KCFJCXSYJLRTZ`，及 `ROEJQ`、`NETCASH_OPERATE_PK`。保存证券代码、报告期、公告日，拒绝未来公告。
- 累计财报只与上年同期比，不用 `DJD_*` 单季度同比替代。优先披露同比；缺失时只在同报告期且正基数下复算。CAGR用2022至2025四个年度端点的三年间隔，不能将三份年报的两个间隔冒充三年。
- 估值：`RPT_VALUEANALYSIS_DET` 具名PE、PB、市值、股价独立带日期；缺财务不从行情别的字段推测。原始响应缓存于 `.tmp-snap/stocks/fundamentals/`。
- 公司只显示一个名称、一条具体主营业务。入选理由为业务事实和增长证据；风险独立成列；每行能打开报告。三年平均ROE放在历史详情，主表显示最新报告ROE及同期值。
- 日常刷新按清单逐家复评；下载失败保留旧数据时，仍用本次日期判断报告是否过期。未达到条件的已研究公司只保留后台复评记录，不进入质量页。原32家无充分依据的人工候选已经删除，不借“未通过”继续陈列。

## 动态PE和5/10年PE分位

- PE-TTM直接使用供应商最近12个月归母利润口径；静态PE使用 `PE_LAR`（上一完整年度）。
- 动态PE = 估值日总市值 /（当时已公告的最新累计归母净利润 × 12 / 报告月数）。例如中报利润乘2、一季报乘4。保存报告期、公告日、实际利润、年化利润和估值日期；不能使用估值日之后公告的利润。本期利润非正不显示动态PE。此口径不是分析师预测PE，季节性和一次性损益会影响年化结果。
- 5年和10年分位分别截取以估值日为终点的自然年窗口，按每日PE-TTM统计。分位 =（低于当前PE的正PE记录数 + 相同PE记录数 × 0.5）/ 正PE记录数。统一保留2位小数后比较，重复交易日期去重；非正或缺失PE剔除并记录数量。因此分位是在盈利期样本中的相对位置。
- 主源为东方财富 `RPT_VALUEANALYSIS_DET` 日历史，该接口当前最早到2018-01-02。对更早的窗口使用亿牛网公开的 `/chart/pea/{股票代码}/t/all` 历史PE-TTM，只接入2016—2017年部分；从2018年起始终使用主源。亿牛近期数据存在财报更新滞后，本项目不使用其近期报价。
- 早期补充记录接入前，用2018—2019年相同交易日的两源正PE交叉核对，至少100个重叠样本、相对差异中位数≤0.5%、90分位≤5%才接受。此检验是接源条件，不代表逐日审计了2016—2017年原始财报。历史重述、资产重组和财报入库时点可能造成供应商差异；不通过的公司显示“早期估值来源有差异”，不计算缺前段的10年分位。
- 必须有窗口起点当日或此前14日内的记录，末日记录须对应估值日，每年平均至少180条观察且相邻记录不存在超过45天的长缺口。长期停牌也可能使窗口不能通过这一保守检查。历史不足不能被当作完整5/10年；没有用当前利润回推旧PE，也不插值补齐。
- 补充档案在 `data/stock-pe-legacy.json`，包含原始PE片段、取数URL、响应哈希、获取时间和核对结果。重建命令为 `python3 scripts/build_stock_pe_legacy.py`；加 `--cached` 可使用 `.tmp-snap/stocks/valuation-history/` 的原始响应复现。日常刷新直接使用固定早期档案，并重新获取主源每日历史、重算分位，不依赖本地缓存才能运行。
- 定时发布检查估值日、财报期不能倒退，已可用的分位不能因历史源截断或缺失而静默消失；真实亏损导致PE不适用允许发布。

## 2026-09-29 基线验证

35家产品数据 = 12家完成报告研究且满足当前条件的企业 + 原23家红利公司。两组无重叠；新增8家公司已取得实际行情及分红历史。12家均有5年PE分位；10年分位缺失时保留“历史不足”或“早期估值来源有差异”，不降低来源一致性要求去拼接。
