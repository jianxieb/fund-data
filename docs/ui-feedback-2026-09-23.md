# 信息架构、基金表与策略曲线修订

当前界面验收：2026-09-23。本文件承接[初轮公开研究验收](public-research-revision.md)。桌面布局使用原有1510px内容上限；27英寸桌面是开发验收优先级，并不要求把界面拉宽到显示器边缘。

## 本轮反馈的落点

| 反馈 | 当前界面 |
| --- | --- |
| 总览不需要周期选择 | 总览的THE BENCHMARK始终直接列出1/2/3/5/10年；年化/累计切换移入参照卡。基金、指数、个股仍可选择多个周期。 |
| 01–04的EXPLORE重复 | 仅总览四张入口卡保留01–04；侧边导航与内页不再编号。 |
| 研究顺序 | 总览卡依次为海外指数、长期主动权益基金（海内外）、红利/债券/固收、投入策略。指数页默认同表列出全部价格指数，海外在前、国内在后；产品ETF独立页签。 |
| 主导航混合 | 研究总览独立；研究对象依次为指数观察、基金研究、个股深入；投入策略归入研究方法。基金内页从11个重叠页签收敛为4个，细分类放在完整研究池筛选器。 |
| 基金表太高、重复信息多 | 主表仅在首列显示名称；代码、场内/场外、跟踪策略及经理上任日保留在详情和CSV。经理与任期在表格中合写，完整逐人记录保留在详情。 |
| 收益和风险日期重复 | 同日只显示一次；不同日分别标注。缺日期的表格单元格用—，表尾统一解释缺失；详情继续保留各字段原始状态。 |
| 列序与费率 | 申购状态、日限额拆成两列，连同规模放在持续费率前。管理、托管、销售服务费合为“持续费率/年”；悬浮看分项，点击看完整资料。缺项时只显示已知下限，不当成完整总费用。买入与卖出费率仍各有一列。 |
| 表头与对齐 | 改为“基金”“现任经理”；基金表头、单元格、经理和基金名称统一居中。 |
| 排序无法恢复 | 指数表和基金表的可排序列均为降序→升序→默认的三态循环；排序时另提供“恢复默认顺序”。默认指数顺序仍是海外在前、国内在后。 |
| 策略结果被图挤到下方 | 投入策略拆成“结果表”“曲线对比”两页签。结果表默认打开，六种方式及主要指标在桌面首屏可见；资产选择收为一个按普通/杠杆分组的下拉框，计算规则收进折叠区。 |
| 策略比较缺同图曲线 | 曲线页默认把SPY、QQQ、SOXX叠在同一坐标系；主动勾选后，六只杠杆ETF追加在同一图上，用虚线和独立图例分组区分。点击图例可隐藏或恢复单条曲线。 |

“长期主动权益”入口默认27只：现有24只精简权益候选，再补入通过相同长期门槛、且未在候选内的海外主动基金。完整主动权益池仍可从完整研究池检索，避免把1023只历史研究池直接当成“优先研究”。红利、债券与固收合并的是**研究入口**，各只仍有原分类；不把红利和债券当作同一种风险资产。

## 曲线数据与更新方法

`strategy_backtest.py`使用对齐后的ETF日度复权行情与逐日现金账户产生资金流中性单位净值，首日定为100。生成快照时只保留首日、每月最后一个实际交易日和末日，绝不从几个1/3/5年收益点拼曲线，也不插值。图的横轴是这些真实交易日；纵轴为明确标记的对数刻度。`STRATEGY_CURVES`与108组`STRATEGY_RESULTS`存放在同一份`data/snapshot.js`，更新脚本一次性原子替换。质量检查核对起止日期、时间顺序、每组长度、正值和首日100。XIRR、实际投入金额和回撤仍另列，不与曲线口径混用。

新电脑拉取仓库后能直接浏览已提交快照及曲线。若要重算，需联网运行`python3 strategy_backtest.py`取得或刷新原始ETF日线，再运行`python3 data_quality.py --strict`；仅在本机已有相应原始缓存时可用`python3 strategy_backtest.py --offline`。完整跨数据集流程、缓存限制、失败状态和发布步骤见[维护指南](maintenance.md)。

## 验收证据与边界

- 2560×1440桌面预览中主内容仍以1510px为上限；策略结果表底部约746px，首屏无需向下滚动。基金表在自身容器内横向滚动，申购状态与日限额分列，整页无横向溢出。
- 曲线页默认绘制3条普通ETF曲线，主动叠加杠杆后同图共9条。回测脚本已离线重跑108组结果并更新快照；图和结果使用同一份已提交数据。
- 浏览器交互已核对指数与基金表头三态排序、排序后详情匹配、基金表各列居中、策略双页签与同图九条曲线。自动化测试与质量检查命令见下方维护指南；严格质量结果为0错误、5类限制、3类待核验，这不代表上游数据都已独立审计。
- 策略行情缓存可回放至2026-09-18；部分国内指数为2026-09-21，跨标的比较时各行明确显示真实截至日。人民币海外指数的完整日度风险因缺真实汇率观测仍留空。扩展基金池仍有未逐只复算、规模日期未独立收录等限制，详情和质量页继续呈现。
