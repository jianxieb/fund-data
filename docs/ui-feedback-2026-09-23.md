## 曲线数据与更新方法

`strategy_backtest.py`使用对齐后的ETF日度复权行情与逐日现金账户产生资金流中性单位净值，首日定为100。生成快照时只保留首日、每月最后一个实际交易日和末日，绝不从几个1/3/5年收益点拼曲线，也不插值。图的横轴是这些真实交易日；纵轴为明确标记的对数刻度。`STRATEGY_CURVES`与108组`STRATEGY_RESULTS`存放在同一份`data/snapshot.js`，更新脚本一次性原子替换。质量检查核对起止日期、时间顺序、每组长度、正值和首日100。XIRR、实际投入金额和回撤仍另列，不与曲线口径混用。

新电脑拉取仓库后能直接浏览已提交快照及曲线。若要重算，需联网运行`python3 strategy_backtest.py`取得或刷新原始ETF日线，再运行`python3 data_quality.py --strict`；仅在本机已有相应原始缓存时可用`python3 strategy_backtest.py --offline`。完整跨数据集流程、缓存限制、失败状态和发布步骤见[维护指南](maintenance.md)。
