# 研究证据标签修正（2026-10-15）

本轮全站评审检查了已发布数据结构与实际页面。修正只改变证据说明，不重写行情、规模值、收益或研究名单。

- 数据状态从 `DATA_QUALITY.datasets[].issues[].code` 生成，未知问题保留原问题文字。扩展基金收益已复算，不能因为费率、规模日期或经理资料待核就统一称为“旧池收益待复算”。海外个股明确标出本期经营复核缺口，不显示未经解释的英文状态。
- 基金表与详情显示规模观察日期；缺少日期时明确标为“规模日期未核验”。默认主动权益筛选保留这些研究候选，并明确不能据此确认当前规模符合门槛。2026-10-15本地快照中，91只结果有65只存在此缺口；这不是已补全规模证据，也没有据此静默删去候选。
- 美股预测PE保留来源值，旁注“预测期间未提供”。供应商 `epsForward` 字段没有随结果提供目标财年/NTM、分析师数量及调整口径，不能从PE-TTM与它的差值直接推断盈利增幅。采集日期不等于预测期间；季度年化PE仍与Forward PE分别展示。

验证：应用及美股模块语法检查、本地实际页面核对。后续工作应从有日期的原始规模报告及明确预测期间的盈利预期补证据，而非仅去掉警示标签。
