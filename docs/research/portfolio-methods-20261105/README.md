# 组合投入方法研究：2026-11-05

本目录记录本轮实际运行的试验、参数、全部结果及复现材料。每日现金缺口补仓是一个固定的资金管理规则：原现金在股票低于用户目标仓位后参与投资，没有回撤阈值、冷却参数、卖出或额外注资。它提高了历史终值，也提高了股票暴露；不能称作已找到预测买点的 alpha。

系统已接入 `现金补足目标仓位`（cash_topup）与 `QQQ深熊确认调仓`（qqq_bear_confirm）。两者用途不同：前者会动用原现金，后者只让 TQQQ 对应资金池在持有与现金之间切换，不挪用原 40% 现金配置，也不替其他股票择时。

30/30/40 税后账户中，十年中位累计股票买入为 63.9220（一次性 59.9640），十五年为 67.7234；对应中位使用原现金 3.9620 和 7.7672。十年平均股票暴露 87.70% 对一次性 85.66%；十五年 91.04% 对 88.62%。这些是长期自然涨跌后的实际仓位，补仓成交后本身不超过用户 60% 目标。

回撤有代价：30/30/40 十年中位 MDD -72.85% 对一次性 -71.95%，十五年 -76.50% 对 -76.38%；逐户 MDD 差的中位数分别恶化 0.3014 和 0.2211 个百分点。96 个 ETF 评估格中未出现相对一次性终值更低的起点，但这是 2010–2016 入场的重叠历史窗口，不是未来不亏或普遍有效的证明。50/50 无原现金时全部持平。

费用升至 0.5% 且额外延迟一共同交易日后，30/30/40 税后十年、十五年差仍为 +1.0018、+1.1214 pp。全部费用、权重、税率与延迟条件均保留；未按结果换参数。

资本利得税采用系统的估值准备金：每日/期末从正的未实现收益扣除潜在税负，而非已实际缴税。该规则没有卖出，已缴资本利得税为 0；实际分红税与准备金分别列在 CSV 中。基准使用相同口径。

真实 SMPIX/UOPIX 基金的 77 个二十年窗口另列：默认税前年等权 CAGR 差 +3.4119 pp、77 胜，然而最坏 MDD 达 -89.67%，一次性最坏为 -66.80%；中位多买入 21.4793/100。其分红明细税证据不完整，因此只报税前，且绝不冒称 USD/TQQQ ETF 的二十年历史。

## 文件与核验

- `cash-results.json`：固定现金规则的紧凑概览、全部 96 个 ETF 格及 4 个不同基金外部格；试验台账明确列出候选数。
- `cash-results.csv`：5204 个配对账户（4896 个 ETF、308 个外部基金），逐行列出相同起止日的规则/一次性净值、年化、回撤、现金、实际买入、税及费用。没有删去平局。
- `reproduction.tar.gz`：共享行情/税输入、原冻结协议、代码、选择记录、全部结果及必要审计账本各存一份。大账本保留压缩，不在目录复制展开版本。
- `manifest.json`：归档及每个成员的字节数、SHA256、CSV 行数/哈希。
原 risk/evaluation.json 内指向的 91,455,214 字节逐日决策账本没有重复打包；所有逐账户结果、参数及逐日曲线 SHA256 均已保留，可用 `replay.py risk` 从相同代码/行情重建完整结果。manifest 记录被省略原压缩账本的哈希；这是明确省略可重建的明细，未删除任何候选的收益结果。

独立 Python 核验覆盖 96 格、9792 条规则/基准账户记录，以及四条完整日路径：现金恒等式、税前解析基准、分红成本基础、利得税准备金、t−1/t−2 完整快照、成交仓位上限、未来价格扰动均通过，最大误差小于 4e-12。另以随包冻结的真实 production 模型逐一复算未额外延迟的 4896 条规则/基准账户；终值最大误差 7.28e-12，税额最大误差 1.37e-12。延迟一日敏感性不伪称经过当前生产模型路径复算。

QQQ 方法另有 408 个配对账户（816 条策略/基准记录）的生产核验：终值、CAGR、MDD、已缴总税/资本利得税/分红税、税准备金及交易费均与归一化研究账本一致，408 组 TQQQ 信号/成交日期也一致。原研究分池扣初始手续费，生产则整体扣费，核验仅用 g=(1+fee)/(1+fee×股票目标合计) 归一化初始资金，不改用户权重或规则。两份 production 审计及其对应模型 SHA256 完整保留在 risk-confirm/。

## 相对路径复现

要求 Python 3 与 Node.js，无第三方运行库；无需抓取新行情。先在本目录解压，再用包内启动器创建新的输出目录，避免改写冻结产物：

```sh
tar -xzf reproduction.tar.gz
python3 research/replay.py cash
```

已实际从压缩包解压后执行 `cash`；税前/税后结果、轨迹、自检、外部扩展、汇总及生产模型审计共七个输出与原冻结结果逐字节一致（验证记录与当时模型 SHA256 在 manifest）。最终生产快照若有新增策略，原 cash 核验记录的模型 SHA256 仍单独保留，避免混称同一版本。
`cash` 重算全部费税/权重/延迟格、不同基金税前二十年扩展、自检与生产账本核验，输出在 `research/rerun/cash/`。目录已经存在时拒绝覆盖，可加 `--destination research/rerun/cash-again`。

其余完整阶段分别运行：

```sh
python3 research/replay.py buy
python3 research/replay.py rebalance
python3 research/replay.py risk
python3 research/replay.py risk-daily
python3 research/replay.py external-risk
python3 research/replay.py risk-confirm
```

也可使用 `python3 research/replay.py all`。原研究脚本与原结果保持字节不变；运行器仅在新副本中把生产审计脚本原机器绝对 import/模型读取路径适配为随包模型的相对路径。某些历史选择记录带运行时间戳，重新执行后的输出哈希可能不同，数值及冻结规则应一致。原结果真实性以 manifest 内哈希为准。
