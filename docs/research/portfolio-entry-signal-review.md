# 五日入场研究之后：新信息来源核查

目前仍没有通过验证的加仓指标。四轮价格研究的失败不改变，[机会诊断](portfolio-entry-opportunity.md)也只是事后上界。本轮寻找具有独立机制、能够在交易前取得的新信息，没有登记或试跑第五个候选。

## 值得继续核对的是月度份额需求

Davies的SSI使用六只杠杆ETF：SSO、QLD、DDM的月度份额增长率之和，减去SDS、QID、DXD的对应增长率。它提供份额需求信息，区别于现有价格特征。发表论文Table 5中，前月SSI与下月前五个交易日累计S&P 500收益负相关：系数−0.96个百分点／标准差，t=−2.92，158个月。这是五日研究的独立动机，不能因它是月度输入而说只支持长期预测。[发表论文](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/846E44374D60D2760DFE5CE4B291F4EA/S0022109022000291a.pdf/speculation_sentiment.pdf)

该五日结果是样本内回归；Table 8另做的是月度收益样本外预测，不是五日交易验证。本文据此判断SSI值得核查数据，尚未判断它能改善本组合。原论文的宽基指数、月末到下月第五日窗口，与USD／TQQQ人民币组合、到账收盘后再等五日的资金差并不相同。发表系数也不能直接移植成当前买入阈值。[论文Table 5、Table 8](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/846E44374D60D2760DFE5CE4B291F4EA/S0022109022000291a.pdf/speculation_sentiment.pdf)

补充材料IA.3指出两种不同延迟：份额会计可在T或T+1之间变化，规则变化未公开；授权参与者还可能延迟到T+6才创建份额，使观察值反映更早的交易活动。**后者不是官方CSV必须晚六天公布的证明。** 交易发生、份额记账、网页首次公开是三个不同时间，必须分别核对。月度指标不能直接改成日频追踪。[正式补充材料](https://static.cambridge.org/content/id/urn:cambridge.org:id:article:S0022109022000291/resource/name/S0022109022000291sup001.pdf)

## 数据已经取得，但还不等于历史实时数据

[来源与质量证据](../evidence/portfolio-entry-signal-feasibility-v1.json)保存具体URL、字段、单位、覆盖、文件指纹和未解决项。原始文件只用于研究核对，未替换生产行情，也没有用来计算候选收益。

- 六只基金的官方历史CSV均已取得；三只多头产品各5125行，自2006-06-19起，三只反向产品各5110行，自2006-07-11起，均至2026-10-30。它们包含NAV、份额和资产规模，不能当作市场成交价、历史官方溢折价或买卖盘口。
- 官方拆股表中的六只基金共25个事件已定位，尚需逐事件对账。不能看见份额翻倍或缩小就直接当作资金申赎。
- 份额字段以千份显示，早期反向产品尤其容易受精度影响。QID最小显示0.09千份；用显示NAV和份额相乘重建资产规模时，最大相对差约4%。完整日期、正数及无重复并不能解决这一问题。
- 作者公开工作簿已通过正常公开下载取得，不需要登录。`Series From Paper`含123个月，2006-10至2016-12；`Current Series`含149个月，2006-10至2019-02。两者都经过标准化，不能把Current解释为更新到了2026年，也不能把文件当作覆盖最终发表样本的全部原始数据。[作者研究页](https://www.shaunwdavies.com/research)

两张表按月份重叠123期，几乎精确满足 `Current = −0.00103604040203196 + 1.0914956307564814 × Paper`，最大绝对残差为9.33×10⁻¹⁵。这与标准化窗口变化相容，不能凭数值不同断言底层份额修订，也没有因此证明具体变化原因。2010年5月、2013年3月的原始日期标签分别相差一个交易日；按精确日期只能配到121期，按月份并未缺期。

后续对账须区分原始定义、数据修订和标准化窗口，不能用全样本标准化值假装当时可用的输入。HTTP修改时间、下载时间和作者日期标签也不等于每一历史观测的首次公布时间。

## 其他方向暂不作为下一候选

普通ETF的申赎信息研究确实报告次日收益预测，但其样本明确排除杠杆与反向ETF，且使用更细的成交／申赎信息分解。直接把原始份额变化代入该结论会改变变量含义，也不能据此宣称USD／TQQQ有效。[Xu、Yin、Zhao](https://onlinelibrary.wiley.com/doi/10.1111/fima.12396)

日内或隔夜反转也不能自动移植到五日买入。纽约联储原作者的2026年复查指出，过去发现的隔夜漂移及订单失衡关联在2021—2025年明显减弱；这提醒本项目检查机制在更新样本中的延续性，而不是把旧论文中的收益当作现在可实现的收益。[纽约联储复查](https://libertystreeteconomics.newyorkfed.org/2026/07/the-disappearing-overnight-drift/)

仓库中另有成交量／OHLC和多个期限的隐含波动率原始缓存，具体覆盖见数据证据。它们没有因此自动成为有效预测变量。隐含波动率期限不是VX期货曲线，日成交量不是签名订单流，也不是基金申赎份额。

## 下一步的具体工作

先对原文六基金做数据定义核验：逐一检查25个拆股事件，量化显示份额精度对月度增长率的影响，与作者两个序列核对定义及标准化，并调查当时首次可用时点。该工作不读取未来收益来挑选数据处理方案。

数据可以可信重建后，再冻结唯一的月频SSI试验，明确它与现有到账日、五日等待和年度资金差的映射，以及保守信息滞后和缺失处理。它仍须通过相同资金供给、费用、风险、分阶段与集中度检查。不能同时筛选单对基金、多个阈值或日频版本；不能把数据核验通过写成预测验证通过。

持有期和最长等待偏好仍未得到用户确认，一年／五个共同交易日继续只作研究假设。这个缺口不妨碍上述数据核查，也不是否定SSI机制的理由。目标保持为验证出真实改善并集成，而非以文献、数据下载或事后机会诊断替代完成。
