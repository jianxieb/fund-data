# 长期优质复核：Adobe、高通与利润口径

复核日：2026-10-23。本记录承接用户对 Adobe 的 AI 替代风险、高通经营趋势、两个单季利润指标差异的质疑。本次规则从复核日起生效，不回写此前日期的入选结论。

## 原判断哪里失效

实际生效的 `company_selection.assess` 以具名决定、五年正利润和正经营现金为质量底线。旧量化规则中的增长条件已经被具名决定覆盖；风险备注本身没有否决力。因此，“历史上赚钱”“有订阅或专利”可以与当前经营恶化、未解的竞争质疑同时存在，仍显示入选。这不足以支持“长期优质”的明确标签。

本次不以股价下跌、PE低或历史涨幅作为入选条件，也不认定一个演示产品已经完整替代专业工作流。免费及AI原生工具降低替代成本是需要回答的经营质疑；原评审缺验证资料时，应撤回确定性标签。

## 新的共同否决条件

在既有日期、原始来源、具名业务评审、五年利润现金及TTM正值检查之外，A股和美股长期优质增加：

1. 最近两个相邻单季及其各自上年同季的核心盈利、营业收入必须齐备且为正。缺项逐季度具名列出，不拿累计中报、净利润或非GAAP调整值填补营业利润。
2. 两个单季都出现核心盈利同比下降、且核心盈利/收入比率也同比下降时，撤回质量资格。比较同季控制季节性；低于10%的正增长或仅一季波动不自动触发此否决。零/负基数和缺项不能当作通过。
3. 已登记的重大竞争或经营质疑必须有本期来源、关闭说明及不晚于核对日的关闭日期。只把状态改成“已解决”、沿用历史护城河叙述，不能恢复资格。重新纳入仍需新的具名入选评审。

A股核心盈利是税后扣非归母净利润，美股是税前报表营业利润，ADR按自身准则。新规则检验各自同口径趋势，不把两者作为同一种利润直接横比。两季条件是审慎的暂停规则，没有完成收益优化或因果验证；未触发也不证明竞争风险不存在。

`decisionHistory`保留此次更改前的具名决定；按评审日选择版本。新财报仍会使旧决定和旧利润衔接失效。已登记的竞争质疑不等于对全部企业所有风险的穷尽式审计。

## 两种利润的差异

营业利润是税前经营结果，通常已扣销售成本、研发、营销、管理及股份支付等经营费用；其中仍可能有重组或减值等一次性经营费用，所以也不等于扣非利润或现金流。净利润在此基础上加减利息、投资等非经营损益、所得税，以及终止经营和归属调整（如有）。页面净利润优先母公司口径；普通股EPS另受优先股等调整影响。

本期金额衔接，单位为亿美元：

| 项目 | Adobe | 高通 |
| --- | ---: | ---: |
| 营业利润（税前） | 23.54 | 16.26 |
| 利息费用 | −0.66 | −1.78 |
| 投资净收益 | +0.21 | +10.14（含其他收益） |
| 其他净收益 | +0.48 | 已计入上项 |
| 所得税费用 | −5.30 | −4.60 |
| 净利润（税后） | 18.27 | 20.02 |

上述金额分别取自两份10-Q合并利润表，页面会检验带符号调整之和能否闭合到当前币种、当前报告期的净利润。只有报告期、金额、币种、日期与衔接全部匹配才显示“已核对”的拆分。

Adobe上年同季税费4.15亿美元，本季5.30亿；净利润同比+3.10%，低于营业利润+8.33%。高通本季投资及其他收益由3.58亿升至10.14亿，使净利润降幅约24.91%，小于营业利润降幅41.13%；上季另有约57亿美元递延税项收益，不能当成主营经营利润。

其他公司暂未逐项完成的利润差额标为“尚未拆分”，明确缺利息、投资及其他损益、所得税与归属调整金额，不把净差额全部归因于税或投资。完整说明放在详情和深入报告；主表只改为“单季净利润同比 / 税后”“单季营业利润同比 / 税前”，并显示营业利润率。年度和季度详情补充营业利润及利润率，方便直接检查趋势。
