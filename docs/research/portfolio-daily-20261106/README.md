## 每天可以使用的数值

| 方法 | 每日指标 | 分母 | 对已有持仓的作用 |
|---|---|---|---|
| VIX恐慌恢复调仓 | TQQQ对应预算投入率，0%或100% | 原本分给TQQQ的新增预算 | 状态切换时退出或用其专属现金买回TQQQ |
| 三批相对强弱轮动 | USD、TQQQ两个分配百分比，合计100% | 两只ETF合计股票预算 | 复核后联合目标变化才调仓；保留三个批次的记忆 |
| 双重风险门调仓 | TQQQ对应预算投入率，0%或100% | 原本分给TQQQ的新增预算 | VIX、QQQ任一门退出便退出；两者恢复才买回 |

这些比例直接来自实际模拟状态，含义不是盈利概率或便宜程度。用户可修改原权重；新增预算试算同时列明买入额、买入费、策略待投资金和原配置现金。试算不改变历史资金流。旧持仓订单另列。

每日记录对应实际共同收盘，保留每项来源日期；无新订单的日期也有状态。缺数据时不产生比例或预算；轮动预热时比例尚未形成，预算明确回退原配置；期末清仓后不产生下一笔投入。首次建仓方式沿用原研究，不把新增预算指标反过来改写首次交易。

使用“延续到最新行情”会保留原跟踪起点、配置与轮动批次演变，只延长结束日期。修改参数后须先重新模拟。CSV保留每个共同交易日的原始数值、完整元数据和预算；组合PDF冻结导出时所选日期与预算。

## 验证与复算

[verification.json](verification.json)保存最终源码指纹、冻结输入指纹和逐账户结果。[verify-daily.cjs](verify-daily.cjs)从原长期研究的固定归档读取旧引擎和相同真实行情，再与本次引擎比较：

```sh
node docs/research/portfolio-daily-20261106/verify-daily.cjs /tmp/daily-verification.json
```

核验包括63个实际十年、十五年账户：三种方法、30/30、50/50、20/40权重，零追加与每月追加，以及年度再平衡、零初始本金、期末清仓。原引擎所有非策略元数据结果逐项完全相等，包括187,893个估值点和7,729笔交易；不是采用误差容忍后判定通过。

181,233个每日快照中，181,230个可生成预算的日期都通过10,000元含费资金守恒，3个清仓日不生成预算。固定起点延长结束日期的20,331行历史快照完全相同，包含原先末日已经形成的待执行订单。

这项验证确认新增显示与既有模拟一致，不能代替原报告中的历史效果和选择偏差分析。规则的实际贡献、失败情景、参数敏感性仍以原研究为准。
