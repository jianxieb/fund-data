# USD 与 TQQQ 三种长期调仓方法研究

本目录保留 2026-11-06 研究的结果与复算证据。三个最终方法是 **VIX恐慌恢复调仓、三批相对强弱轮动、双重风险门调仓**。默认 USD 30% / TQQQ 30% / 现金 40%，每侧费 0.10%，资本利得税和股息税各 20%，不新增本金、不借贷、现金零息。

| 方法 | 全部十年年化差 | 全部十五年年化差 | 主要限制 |
|---|---:|---:|---|
| VIX恐慌恢复调仓 | +2.622708 个百分点 | +1.584713 个百分点 | 中心规则仅有 2020 年一个完整事件，27 格参数邻域的十五年结果 13 正 14 负 |
| 三批相对强弱轮动 | +1.641920 个百分点 | +4.422921 个百分点 | 40 / 20 权重的后段十年平均为负，回撤较一次性更深 |
| 双重风险门调仓 | +3.255824 个百分点 | +2.173665 个百分点 | 两个主要事件，组合是在看到父规则结果后提出；本轮仅运行 20% 税 |

年化差为逐起点配对差值，先在入场年份内平均，再对入场年份等权。绝对 CAGR、税后终值及回撤在报告和 CSV 内，不能把“两个中位数之差”当成年等权差。

## 文件

- `report.pdf`、`report.docx`：十页正式报告。包括三方法定义、默认和满仓、四权重／费率／延迟压力、绝对收益、税后风险、参数和日期依赖及失败结果。
- `summary.json`：240 个评价格。VIX 和轮动各 96 格，双重风险门 48 格；包含默认条件和压力条件，不能当成 240 个独立市场样本。
- `results.csv`：10,960 条配对账户记录，54 列，逐字段回读已核对。每行含策略和同日同权重一次性对照的终值、CAGR、回撤、已付税、准备金、费用、成交数量、实际股票资产占比和未成交订单。
- `results-columns.json`：CSV 字段、单位和重复子集说明。
- `development-summary.json`：全部 187 个主阶段候选的开发结果，含失败。
- `collect.py`：从解压后的冻结原始结果重建 summary、CSV、字段表和开发汇总；不运行或改选交易规则。
- `reproduction.tar.gz`：真实输入、冻结参数、原始运行脚本、选择记录、全部正负结果、诊断、旧引擎草稿和独立账本核验。
- `manifest.json`：本次交付和研究源的字节数／SHA256；用于检查报告与证据是否来自同一版。
- `report-qa.json`：页数、跨格式数值与表格核对、字体及视觉检查记录。
- `validation.json`：合并远端定时数据刷新后的本地检查、9组浏览器结果与正式模型审计摘要。

## 研究范围

真实 ETF 数据截至 2026-11-02。十年共 81 个起点（2010-03 至 2016-11），十五年共 21 个起点（2010-03 至 2011-11）。开发段为 2011-09 至 2013-12 的 28 个十年起点；后段为 2014-01 至 2016-11 的 35 个十年起点。

`later35` 是 `all10_81` 的子集，CSV 为方便审阅重复列出，不能重复累计为新账户或新历史。十年和十五年窗口大量重叠。跟随探索已见过部分后段结果，因此“后段”不表示无污染样本外，也不是未来验证。

主阶段计数为波动率／VIX 72、相对强弱 96、获利了结 16、VIX 邻域均值 1、三批轮动 1、双重风险门 1，共 187。另列 27 格 VIX 参数邻域（3 格与原网格重复、24 格新参数）、9 格原单批季度相位／日期、3 格三批月初偏移诊断。引擎机械修正前的草稿只作历史记录，不重复计数，也不作为正式结果。

本轮没有实际 USD/TQQQ 二十年持有证据，未拼接上市前 ETF。VIX 来自标普 500 期权隐含波动；QQQ 为真实底层 ETF；SOXX 为行业 ETF 代理而非道琼斯半导体指数。每个来源身份、端点、读取日期和哈希均保存在归档中。

## 执行与税账本

研究首日按用户权重同时买入，初始交易费与一次性对照完全相同。各方法仅调整已有股票资金，保留原始现金。前一共同收盘固定卖出份额与买入金额，下一共同收盘成交；压力 `delay=1` 再多等一个共同交易日。买入金额只能由计划时已存在的现金支付，卖出回款到账后才可用于下一次决策。

正资本利得按设定税率扣税，亏损不抵扣；股息税由复权份额调整反映；每日估值和期末未实现正收益计税款准备金。报告终值和回撤都基于扣除准备金后的账户价值。未强制期末清仓。`maxStockFraction` 是实际股票／ETF／基金市值占总资产的比例；`maxDailyLeverageExposure` 是以 USD 2 倍、TQQQ 3 倍每日目标加权的名义暴露指标，不是组合实际长期杠杆或固定收益倍数。

三批轮动在一个实际账户和每资产一个成本账本上执行，并没有通过三套税批次制造收益。VIX 和双风险方法只动用 TQQQ 退出净回款，不吃掉原始现金。

## 干净目录复算

需要 Python 3 和 Node.js 18 或更新版本，无网络及第三方 Python 包依赖。冻结原始文件不会被覆盖。任选新的空目录：

```sh
mkdir -p /tmp/methods-repro
tar -xzf reproduction.tar.gz -C /tmp/methods-repro
python3 /tmp/methods-repro/portfolio-methods-20261106/replay.py /tmp/methods-repro/replayed --diagnostics
```

入口先验证冻结文件哈希，再在独立目录运行三种最终方法及诊断；输出 `replay-proof.json`。本次实际干净复算核对了 115 份冻结文件，13 份重算输出与冻结输出逐字节相同。原有完整开发、选择与失败脚本也均保留，可按各文件协议重跑；开发选择记录含时间字段，重新创建时间戳不会成为新候选或新收益结果。

将本目录 `collect.py` 复制到另一个新的导出目录，传入上述解压根目录即可重建便捷结果，输出写入脚本所在目录：

```sh
mkdir -p /tmp/methods-export
cp collect.py /tmp/methods-export/collect.py
python3 /tmp/methods-export/collect.py /tmp/methods-repro/portfolio-methods-20261106
```

独立 Python 账本重建验证了费用、税、准备金和成交时序，含现金不重复承诺的核验；“独立”指另一个计算实现，不表示独立市场历史或第三方认证。生产集成核验及其准确版本另由归档中的生产审计记录约束，不改变本研究冻结规则。

本目录与 2026-11-05 的旧研究并列保留，旧 reproduction 及其历史结果没有被新结果覆盖。


## 正式模型集成核验

使用真实USD／TQQQ／QQQ美元复权文件与实际人民币汇率，4,207个共同日价格逐值重建研究输入。正式组合模型核对4,080个账户、39,633笔成交与11,325,560个共同日估值，税后终值最大差4.37×10⁻¹¹，税款最大差6.82×10⁻¹³，共同日回撤差不超过2.85×10⁻¹⁴个百分点。生产联合估值日历相对研究共同日的回撤差最大0.04909个百分点，单列保留，没有将两种日历伪称相同。

生产模块、三份实际ETF文件、汇率、VIX源身份和catalog快照全部封入归档。可在上述复算命令加 `--production`，于独立输出目录重跑全部4,080账户，无需访问当前仓库或联网。4080是账户配置数，不是独立市场历史数。

正式JavaScript测试892项通过；数据刷新及发布相关19项Python测试通过；本地浏览器3方法×3权重共9组、VIX缺数据时保留旧结果及恢复均通过。
