# Toast：获客回收能否转成持续每股利润

研究截至2026-10-18，第四轮。承接[第三轮](potential-stocks-us-round3-2026-10-18.md)已明确的成本定义、新市场回报和现金缺口；沿用当时价格及股数，不重新核对旧基线。三个子代理分别研究回收公式、资本回报、客户采用，汇总后互相检验解释边界。数值桥见[证据JSON](potential-stocks-tost-evidence-2026-10-18.json)。

## 本轮改变了哪些判断

**核心餐饮业务的扩张假说得到加强，但新市场复制完整回报尚未证明，当前价格下的五年十倍也未建立。** 不能继续怀疑Toast的获客公式完全漏掉硬件、安装和支持；这些成本明确包含。与此同时，该公式使用估计的早期队列贡献，不能当作所有股东成本均已收回的现金记录。新增自留贷款需要真实资金，也使集团现金与核心餐饮获客回收成为两个不同的问题。

| 上轮待验证事项 | 本轮取得的证据 | 更新后的判断 |
| --- | --- | --- |
| 硬件补贴、实施、支持是否进入回收期 | 2024原始定义明确计入 | 撤销“可能完全漏算这些成本”的疑虑；其分摊及估计仍需辨认 |
| 14个月是否代表全部成本和已实现现金回收 | 按上线及增购队列、早期收入与估计成本计算；历史脚注明确排除SBC | 只能作所定义范围内的获客效率指标；最新SBC及完整共享成本调节尚未取得 |
| 新市场是否已有真实使用 | 英国Le Bab有持续关系和多店集成；美国服饰店有具体工作流使用自报 | 支持客户价值可以迁移；未证明续约净收费及供应商单位回报相同 |
| 公司FCF是否可直接作为股东现金 | 上半年正常贷款购入80、回收30百万美元，净占用50百万 | 应单列这一资金用途；不能使用期末46百万账面额代替现金流 |
| 净利增长是否意味着资本回报同步提高 | H1净利增长但贷款调整后现金下降；TTM现金仍高于净利 | 收紧“无资本负担扩张”的解释，尚不能判定商业模式失效 |

## 获客回收公式：已包含什么，尚不能证明什么

2024投资者日的定义以某月新上线地点及产品增购组成队列：投入包含上线月硬件和专业服务净成本，以及提前两个月的销售营销费用；后者对应签约至上线的中位时长。月贡献包含订阅MRR减估计服务成本，加各新地点**上线后的前三个完整月**平均支付MRR减估计支持成本。它依赖期间归集和成本估计，不是对每位客户实际累计现金的逐月追踪；没有队列输入，也不能拿季度报表机械复算。[2024投资者日第135页](https://investors.toasttab.com/files/doc_presentations/TOST-Investor-Day-2024-Final-for-Web.pdf#page=135)

2021招股书明确说明相关CAC及成本估计不含股权薪酬；2024定义没有重述这一脚注。因而，历史排除已核实，2026究竟逐项沿用还是调整，不能仅凭沉默定性。最新完整调节表，以及后续流失、季节性和共享费用如何处理，仍未取得。[2021招股书第96页注20](https://www.sec.gov/Archives/edgar/data/1650164/000119312521279379/d166297d424b4.htm)

2025Q4管理层报告核心回收期由2019年的22个月降至2023年的14个月，此后维持；2025组合仍为十几个月。新市场高于核心，各自低于20个月是目标。2026Q1仍未给各新市场实际回收月份，不能把“健康”“改善”视为已达目标。本轮未取得2026Q2预备稿的确切原始下载地址，不声称覆盖全部后续会议。[2025Q4稿第9–10页](https://s28.q4cdn.com/141746709/files/doc_financials/2025/q4/Q4-25-Prepared-Remarks.pdf#page=9)、[2026Q1稿](https://s28.q4cdn.com/141746709/files/doc_financials/2026/q1/TOST-1Q26-Prepared-Remarks.pdf)

**指标范围需要对齐。** 最新MRR定义不含Toast Capital费用及相关成本，也不扣SaaS credits。资本业务在该指标之外，不代表核心餐饮回收期虚假；应分别验证核心获客效率与贷款业务回报，再合并到股东现金。2024材料中的“Booked ARR Contribution Margin”、payback贡献利润及调整后EBITDA又是三种不同指标，不能互换。[Q2 10-Q的ARR/MRR定义](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000164/tost-20260630.htm)、[投资者日第112、125、135页](https://investors.toasttab.com/files/doc_presentations/TOST-Investor-Day-2024-Final-for-Web.pdf#page=112)

## 利润与现金：增长有效，但需要继续投入

单位：百万美元。TTM为2025全年加2026H1减2025H1，未将支付旺季的单季乘四。

| 指标 | 2025全年 | 2025H1 | 2026H1 | TTM至2026年6月 |
| --- | ---: | ---: | ---: | ---: |
| 集团毛利 | 1,593 | 738 | 963 | 1,818 |
| 订阅＋支付GAAP毛利 | 1,818 | 841 | 1,105 | 2,082 |
| 营业利润 | 292 | 123 | 262 | 431 |
| 净利润 | 342 | 136 | 280 | 486 |
| 公司定义FCF | 608 | 277 | 245 | 576 |
| 正常贷款购入减回收 | 0 | 0 | 50 | 50 |
| FCF减上述净投入 | 608 | 277 | 195 | 526 |

来源：[2025 10-K](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000057/tost-20251231.htm)、[2026Q2 10-Q](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000164/tost-20260630.htm)。公司FCF为经营现金减固定资产及内部软件现金资本支出，上表最后一行仅补入新增正常贷款现金占用，不是最终可分配股东现金。

正常贷款购入时未逾期，拟持有至到期或偿付；这是新增资金用途，不能称仅有会计分类变化。本期净投入50百万与期末净账面额46百万不同。未来自留比例、回收和资金安排未充分披露，既不能认定一次性，也不能每半年机械重复50百万。原有信用担保损失等已进入利润或CFO，不能再次整笔扣除。[10-Q贷款及现金流附注](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000164/tost-20260630.htm)

**本轮反证是H1盈利与现金增长分化，不能泛化为TTM现金少于净利。** H1净利136→280，公司FCF277→245，补贷款净投入后为195；但TTM的526仍高于净利486。库存、信贷组合建立及季节性可能解释部分差别，未来毛利增长能否覆盖持续占用仍待验证。

回购也有成本。H1回购现金486百万、发股现金17百万，净流出469百万，高于同期贷款调整后现金195百万；它可以使用既有资金，不等于经营资金必然不足。TTM损益SBC为231百万。正常使用已扣SBC的GAAP利润及相应稀释股数没有问题，不能再额外扣同一报酬的现金代理。若从加回SBC的现金流估值，应选用一致的报酬成本或未来股份/回购处理，不能把全部SBC、全部回购和同一稀释重复扣减。全部回购也不全是维持股数不变的必要费用。[两期现金流与股权附注](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000164/tost-20260630.htm)

净利润质量另有约束：TTM的486百万来自营业利润431、净利息52、认股权估值收益15，再减税12，实际税率约2.4%。这些不能全部当核心餐饮利润持续外推；报表还包含上轮已核实的10百万关税退款，上表没有将其改成正常化预测。公司仍对美国递延税资产计提全额估值准备，并提示未来可能释放；潜在账面税益不应被认作经营爆发。[税务及其他收益附注](https://www.sec.gov/Archives/edgar/data/1650164/000165016426000164/tost-20260630.htm)

## 新市场：实际使用增强了证据，回报复制仍缺环节

**英国Le Bab。** 2023年发行人稿件中的客户自报称桌边收款已在使用、经理结账更快；2026年其联合创始人进入Toast国际客户顾问委员会，另一实施供应商Leat又描述其多店Toast POS与积分、优惠券集成。这比一次签约更支持跨年关系和集成使用，但不证明中间连续付费，三者也没有提供续约净价格或供应商成本。Leat案例无发布日期，不能由现在时确定扩店发生时间，更不能据此认定Toast售出了忠诚度模块或留存率已提高；共同开发客户也未必代表普通客户服务成本。[2023上线及客户自报](https://pos.toasttab.com/es-us/news/toast-brings-digital-restaurant-technology-platform-to-uk)、[2026顾问委员会](https://pos.toasttab.com/news/2026-2027-toast-international-customer-advisory-board)、[Leat实施案例](https://www.leat.com/customer-stories/le-bab)

**美国District 34服饰店。** 客户在Toast案例中描述营销邮件、快闪活动的库存查询、积分与结账，证明有具体工作流使用自报，未证明净增利润。其自身网站近期搜索存档仍标Shopify，是两种系统可能并存的线索，不是实时支付路由检查；不能据此认定Toast已经取代全部系统，或反向认定Toast已被替换。并存可能降低采用阻力，同时限制Toast可获得的支付和软件收入，需由实际业务份额验证。[Toast具名客户案例](https://pos.toasttab.com/customers/district-34-boutique-pos)、[客户官网](https://www.district34boutique.com/)

Toast、Square和Shopify的官方报价证明存在具体替代方案，但套餐、设备、支付费率、服务和账期不同，本轮不作等价总成本排名。也不能由公开“低前期费用”方案推定某个客户实际获得补贴。[Toast UK](https://pos.toasttab.com/uk/pricing)、[Square UK](https://squareup.com/gb/en/point-of-sale/restaurants/pricing)、[Shopify POS](https://www.shopify.com/pos/pricing)

本轮支持的是客户价值可以跨市场迁移。要证明回报复制，仍需分市场12/24个月存续、折扣后净收费、支付份额、安装投入和持续服务成本；不要求公开每张发票，也不把拿不到客户成本表视作模式失败。

## 当前价格究竟要求多大的利润变化

沿用第三轮31.62美元、约578百万股的有日期概算，权益规模约182.76亿美元；与TTM净利相对应的参考利润倍数约37.6。它不是精确同日加权EPS估值，低税和非经营收益也影响该比例。

如果终点估值倍数和股份数量都不变，股价十倍要求可比年净利十倍，约48.6亿美元。这是条件尺度，不是唯一必要利润或2031预测；该数已是当前集团全部毛利的2.67倍，因此单靠压低现有费用不够，还需增加真实支付净毛利、软件付费及其他贡献。

营收仍无须十倍。例如，若订阅支付毛利扩大四倍，保持上述估值和股数条件，净利占该毛利的比例还需提高2.5倍，约由23.3%到58.4%。这只揭示假设压力，不认可58.4%可实现。公司40%+长期目标是**调整后EBITDA／公司定义的经常性毛利**，分母还使用其调整后订阅及支付毛利口径，与上表GAAP毛利不可直接互换；2024脚注又限定现有业务、不含潜在未来举措，不能填成总收入净利率或上述净利兑现比例。[2024投资者日第125页](https://investors.toasttab.com/files/doc_presentations/TOST-Investor-Day-2024-Final-for-Web.pdf#page=125)

**最强正向路径仍然存在：**国际与新零售扩大有效客户数，同一客户增加有利润的软件和支付服务，成熟客户的服务成本下降，共享研发及组织费用增长较慢。若这些因素共同发生，净利润可以明显快于营收增长。估值上升也可以贡献股价回报，但需要届时持续增长和现金回报支持；不能因为经营路径不足就免费填入倍数扩张。现有采用案例与回收期支持这条假说的一部分，尚不足以量化全部路径。

BLS当前披露美国私人餐饮和饮品服务场所2026Q1暂定727,892个。Toast约18万地点是跨市场口径，两者地区、范围与时点不同，不能直接相除为精确份额，更不能把美国餐饮数量当国际和零售扩展的永久天花板。[BLS行业表，提取2026-10-16](https://www.bls.gov/iag/tgs/iag722.htm)

## 本轮结束后如何分配研究资源

汇总后的交叉审阅实际修正了三项判断：将“上线前三个月”消歧义为“上线后的前三个完整月”；将现金反证限定为H1增长分化，保留TTM现金仍高于净利这一事实；将核心获客回收与Capital贷款资金分列，避免因范围不同就否定指标。客户集成与竞争报价的表述也已收窄，既不推定独占全部流水，也不把软件并存当失败。

本轮完成了可以由现有公开资料回答的关键问题。Toast继续保留为有经营杠杆的研究对象，**尚不升级为当前价格下已验证的五年十倍候选**。继续反复寻找同样的客户宣传或财报数字，不能补上分市场成熟队列回报；主动研究资源转向其他具备可验证利润扩张机制的美股，Toast等待能改变判断的新披露。

已完成的回收定义、TTM、贷款现金、客户案例和价格基线关闭。后续仅由最新成本调节、分市场成熟队列回报、贷款组合实际回收与资金变化等新证据触发相关更新；不以重算相同门槛或重读同一财报充当进展。
