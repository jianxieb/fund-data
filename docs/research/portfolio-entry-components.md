# 两只资产分别择时：第四轮固定研究

本轮检验一个联合方法：USD、TQQQ各用自身人民币价格状态，判断自己的固定预算是否延后五个共同交易日。两次预测共同组成一个策略，最终只按合并账户是否优于相同到账日定投判断。不能在结果出来后只保留较好的资产，也不能把四种行动组合当成四个候选来选。

[协议](portfolio-entry-components-protocol-v4.json)已在生成本轮真实标签、拟合预测和资金结果之前，以 `ab482eaf` 提交并推送。原 v1、v2、v3 及持有期审计的失败保持原样；全部行情早已在研究中接触，本轮不是未见过的留出样本。

用户明确优先改善“每月新增资金，比固定日期定投更有效”。持有期限、最长可接受等待时间尚未确认；一年持有、五个共同交易日等待仍是暂定研究范围，不能解释为用户接受跨月持币或确认这些期限最适合自己。

首次真实结果：**联合策略失败，不集成。** 开发阶段行动次数已经达到规定的覆盖要求，但平均资金差为负，12次行动只有4次更好。后续阶段的小幅正均值没有满足改善幅度、行动覆盖与集中度要求。

## 固定预算与学习目标

每笔100元仍有40元战略现金，USD和TQQQ各30元，买入费包含在各自30元内。两腿只决定各自买入日期，不互相借款或转移额度，不使用未来月供，也不再平衡已买入的持仓。

资产 `j` 的年度标签为：

```text
y[j,s] = (1 - 0.001) / (1 + 0.001)
         × 0.3 × P[j,H(s)] × (1/P[j,s+5] - 1/P[j,s])
```

`s` 是到账共同交易日，`H(s)` 是到账一周年及之后首个共同收盘，最多允许晚14个日历日。标签表示这一腿延后与立即投入的年度终值差，分母是**完整入金**；0.3不能重新归一化成0.5或1。

两腿各使用自身人民币复权价格的MA200偏离、历史回撤、5日收益、21日收益和21日简单收益样本标准差。没有40%现金的波动稀释，也不扩展USD更早的单独历史。两腿从同一共同日历开始，只用各自五项特征，各拟合固定 `lambda=1` 的扩展岭回归。

两模型共享训练日期池。预测到账 `t` 时，特征取 `t−1`；训练日期 `s` 必须两腿特征和标签完整，而且 `H(s)≤t−1`。至少756个共同成熟日期后才允许两腿共同出预测。当前 `t` 自身的未来年度标签不必已经存在；那只影响回测结局是否可评价，不能成为实时预测的输入或可用条件。

每腿预测值大于 `1e−12` 整笔入金比例时，该腿延后五个共同交易日，否则立即买入。一次到账只决定一次。压力情景保留相同预测及行动，仅重新计算现金利息和费用。

## 为什么拆开，以及它不能保证什么

固定预算、共同终点和比例费用使两腿的资金增量可以相加。在已知同一信息集下两个真实条件均值的理想情形，分别选择是否延后拥有比强制同一动作更大的行动空间。

实际模型不知道这些真实均值，并且两模型分别只看到自身价格特征。拆开会增加估计误差，也可能漏掉跨资产信息。因此本轮只检验一个结构假设，不预先声称拆开更好。特征表达、模型分工与行动自由同时变化，结果也不能单独归因于其中一项。

## 合并账户与通过条件

设 `A[j]` 表示第 `j` 腿是否延后，主情景下每笔入金 `C` 的终值改善应满足：

```text
资金差 = C × Σ A[j] × y[j]
资金差占入金的百分点 = 100 × Σ A[j] × y[j]
```

两腿标签之和对应“两腿都延后”的反事实，不是仅延后一腿时的实际资金差。报告以 `legOffsets` 记录两腿动作；`anyDelay` 仅表示至少一腿延后，不能被解释为全部风险预算等待。

一笔月供只计一个行动月。胜负按两腿**合并资金差**判断，不按“至少一腿赚钱”判断。回撤来自完整持仓、战略现金、待买现金和费用构成的账户净值，不能平均两腿回撤。删除年份、连续12个月区间和块重采样均保留同月两腿在一起。

完整继承 v3 门槛：总体平均改善至少0.5个百分点、中位差不为负；行动月份至少12个、跨3个到账年份及3个严格不重叠年度窗口；行动中位改善至少0.5个百分点、严格改善比例至少60%。删除任一年或任一连续12个月到账区间后，剩余总体平均改善仍须为正，风险约束保持。

开发段先通过，之后两个阶段分别确认，并检查固定等待、分批买入、现金利息、较高费用、10／20日到账和完整12笔月供账户。所有108组均报告，不能挑另一日期或期限代替主目标。主评价使用12月块区间；完整12笔月供账户的24月块区间不足另作限制披露，不改变预先规定的门槛。

历史检验即使通过，也还需要独立复算、生产费用／分红／个人税处理、范围及未来重算行为核对。模型预测值不是概率或0—100分，未验证的结果不会进入生产页面。

开发段的12次行动跨4个到账年份，含3个严格不重叠的一年窗口，**行动覆盖已够，资金改善仍明确失败**；这次不能把失败归结为行动样本不足。行动中位差为−0.715338个百分点，严格改善比例为33.33%，均没有达到事前门槛。尾部收益及回撤约束通过，但这些风险结果不能替代用户要求的新增资金收益改善。

验证段的7次行动集中在2020和2021年，仅有2个不重叠年度行动窗口；行动中位差为−0.638251个百分点。2020-09-01延后TQQQ贡献了+14.291615个百分点，而该阶段全部月份的差额之和只有+7.557394个百分点，其余月份合计为负。

删除这一个月后，其余35个月平均差为−0.192406个百分点。这是解释贡献来源的描述核对，不是新增筛选条件。其他到账日也未保持一致改善：名义10日验证段为−0.532125个百分点，名义20日后期段为−0.444751个百分点。

后期只有2023-07-03及2023-08-01两次延后USD，分别改善+1.987143、+5.908793个百分点。它们属于同一年、同一不重叠窗口计数，不能用“2／2”宣传100%预测准确率。删除2023年后所有剩余月份差额为零，未证明跨阶段稳定改善。

三个阶段的集中度检查全部失败。12月块描述区间依次为[−0.507320, +0.115575]、[−0.215756, +0.968007]、[0, +0.696700]个百分点；后两段没有正的下界。开发段已失败，后段全部结果只作诊断，不能越过开发门槛确认。

单腿预测误差有局部改善：USD对同成熟池均值基准的MSE相对R²为−0.028535、+0.004171、+0.011463；TQQQ为−0.047138、−0.000108、+0.008623。预测误差改善并没有转化为满足要求的联合资金效果，不能据此挑出一只资产恢复指标。

全部108组、657个基础情景窗口及四类行动分布保留。最终状态为 `development_failed_research_only`，`historicalConfirmationPassed=false`，`integrationEligible=false`。本轮没有调整权重、参数、阈值、等待期限、持有期或门槛，也没有在结果后只保留较好的腿。

## 本候选的结束条件

本轮完成了“分别判断两只资产”的唯一注册检验，结论为不具备集成资格。不能从2020年9月或2023年7／8月的有利结果倒推新阈值，不能换一条腿、日期或期限宣布成功。它也不证明所有基于价格的方法永远无效。

当前证据没有提供继续微调同一组价格特征的独立依据。后续研究若引入新的信号或等待期限，应先明确其作用机制、实际可用时点及与月供执行范围的对应，再单独预先登记。原目标“验证并集成真正改善加仓效果的指标”仍未完成；研究归档不能替代这一目标。
