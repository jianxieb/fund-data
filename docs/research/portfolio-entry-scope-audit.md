## 审计的问题

原来“一年账户”的结算日在第一笔入金满一年时，窗口最后几笔钱只持有数日或数周；它不等于每笔钱都持有一年。第二轮模型学习的是五日等待差，也不能自动视为长期买入优势：组合中两只资产后来的涨跌会改变各自份额差对终值的贡献。

为区别这些范围，本轮同时保留两个口径：

- **逐笔相同资金年龄：** 每笔100单独到账，从到账日起满1年或3年，在共同日期清仓比较；等待时间包含在持有期内。这是逐笔诊断，不是连续月供账户收益。
- **完整12笔月供账户：** 恰好连续12个日历月各到账100，之后停止入金，全部持仓与现金继续持有至最后一笔实际到账满1年或3年。早期入金持有更久，不能称所有12笔资金年龄相等。

名义到账日固定为每月1、10、20日，全部报告，1日保留原研究的主要日历假设。资金实际可用日是该月名义日期及之后第一个共同收盘；休市自然日不假设提前到账，利息和周年日从实际到账起计算。不同日历不是建议的发薪日，也不能挑最有利的一组作为新主结论。用户尚未明确主要持有期限，因此1年和3年只是事先固定的诊断范围，不依据结果替用户选择期限。

每笔仍留40作为战略现金，60覆盖两只产品及买入费；这不是持续保持实际账户现金比例40%，战略现金也没有作为择时储备动用。对照为到账即投、固定延后5个共同交易日，以及第0／21／42日分三批。所有账户的到账、金额、终点一致，不提前花未来月供。

沿用原来的真实USD、TQQQ复权价格、人民币汇率、三个费用／现金情景及个人税前核算。终点为对应周年日及之后第一个共同收盘，最多延后14个自然日。全部入金及终值必须在同一历史阶段；未成熟、跨阶段和缺数据的窗口明确排除，不能为增加样本而改变边界。风险指标只属于新增资金账户，不代表用户的完整持仓。

## 结果

**改变评估口径没有建立这个旧模型优于固定日期投入的证据，失败状态不变，不集成。** 共输出108组结果，包括空组；主情景797个窗口均保留全部四种策略。

| 每笔持有1年 | 开发，结局截至2018年 | 48 | −0.1343 | 0 |
| 每笔持有1年 | 2019—2022年 | 36 | +0.5982 | 0 |
| 每笔持有1年 | 2023—2026年 | 34 | 0 | 0 |

| 12笔月供后再持有1年 | 2023—2026年 | 23 | 0 | 0 |

2019—2022年名义1日到账的正差仍只来自**2020-09-01这一次延后决定**。逐笔检验计一次；在12笔月供的滚动账户里，它重复出现12次，不能变成12个独立成功信号。2023年以后这些到账日没有触发延后，资金结果与立即投入相同。

到账日迁移性也不稳定：12笔月供后再持有1年的验证阶段，名义10日的平均差为−0.1895个百分点；名义20日为+2.0775个百分点。但20日的正差仅来自2020-02-20一次延后，仍重复进入12个账户。不能根据这一项选20日、换基准或恢复模型。三个名义日期在开发阶段的该口径平均差均为负。

3年诊断没有补足证据。名义1日到账的开发阶段，逐笔平均差−0.3531个百分点，12笔月供账户平均差−0.4110个百分点。后一口径在开发／验证／后期分别只有13／1／0个完整窗口；后期没有结果，不能以0收益差代替缺失。所有3年口径的分段样本均不足以形成事先规定的重采样区间。

逐笔口径采用12或36个连续月起点为块，12笔账户采用24或48个月起点为块；窗口数不大于块长即标为`insufficient_blocks`，空组为`no_samples`。这些描述性区间不代表未来成功概率，也不能消除研究者此前已查看历史的问题。

18项研究引擎合成测试通过，覆盖日期顺延、缺月、恰好12笔入金、末笔周年、完整阶段边界、费用与逐笔归因、订单锁定、未来价格扰动、108组完整输出及块长。这里的未来扰动检查针对固定预测的订单执行；原预测器本身的因果核对沿用第二轮独立证据，不把重放测试说成重新验证了预测能力。

[独立审计](../evidence/portfolio-entry-scope-v1-audit.json)从源行情和冻结预测另算日历、逐笔份额、清仓现金及流量中性回撤，没有调用本轮研究账本。797个主情景窗口的3188个账户、55672笔成交及16432笔账户内入金一致；终值最大绝对差1.36×10⁻¹²，回撤差4.62×10⁻¹⁴个百分点。432个主情景配对统计及区间独立复算一致，全部108组的日历、去重决定、块长和空／不足样本状态通过检查；其中9组为零样本。核对器25项手算及错误拒绝检查通过。压力情景仅覆盖合成手算，没有宣称所有压力情景历史账簿都完成独立重算。

本轮只补齐长期月供目标的评估范围。尚未验证新的、能改善月供结果的指标；后续试验须根据用户的主要持有期固定学习目标和完整资金比较，并保留当前失败记录，不能继续通过改日期或终点来救回旧模型。
