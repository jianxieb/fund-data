# Portfolio entry research · 2026-11-05

本包保存本次研究的冻结输入、选择过程和结果。它复算的是**相同本金、真实组合持有 10／15／20 年的账户收益**，不以多买份额替代收益评价；数据截至 2026-11-02。

## 撤回上线结论

本次研究未找到平均胜过同本金一次性投入的买入方法，原三项评分及综合分数不应作为有效加仓指标上线。此前突出“胜过12个月分批”，没有用一次性投入作为主要成功门槛；固定30%／30%持仓限制也是人工范围校验，并非计算所必需。把限制删除后沿用旧分数，同样不能补足改变权重后的收益证据。

新增 `audit-lump-sum.cjs` 不调用原研究程序，直接从冻结日价与因子重新构建5,136条规则的买入计划。每条规则的13／17／23／35个有效起点分别与同日起、同到期日的一次性账户配对：**0／5,136条的买入年等权平均年化增量为正**，最接近者仍为−0.4416个百分点。3,588条在至少一个起点胜过一次性，因此“平均全负”不等于“每个起点都输”，也不证明其他尚未研究的方法不可能有效。

审计包含原六种方式及已撤回三项／综合的同35户比较，逐条记录见 `lump-sum-audit.json`。此补充不改写原冻结归档或其校验值。离线复核：

```sh
node docs/research/portfolio-entry-20261105/audit-lump-sum.cjs --check
```

```sh
node docs/research/portfolio-entry-20261105/reproduce.cjs --out /tmp/portfolio-entry-replay

node docs/research/portfolio-entry-20261105/reproduce.cjs --out /tmp/portfolio-entry-full --full-grid
```

输出目录必须为空且在此冻结包之外；`--extract` 可另展开原始证据。程序先验证 SHA-256，再在只读归档中执行保留原字节的研究程序，历史绝对路径仅是档案标识。复算输出须与冻结文件逐字节相同，否则失败。另独立复核 28 个开发信号计算的固定加速系数，并用实际日价重估六种系统方法的买卖账本。

## 文件与指标

- `buy-method-results.csv`：完整 5,136 行（2,568 个线性／几何组合 × 两个执行模板），按开发排名排列；UTF-8 BOM，可直接用 Excel 打开。`后段比纯回撤年化差pp` 对照**该行自身回撤基底**，不是一律 D21。不同规则的缺数覆盖不同，不能用不同分母偷换共同样本。
- `evidence.json.gz`：冻结的原 ETF 人民币日价、独立旧基金美元净值、月末因子、系统交易账本、两轮协议、324 条非线性开发结果、冻结选择及最终逐户结果。`manifest.json` 给出每份原件 SHA-256。另含 `numeric-evidence.json`（PDF 表格取数）、`qa.json`、10bp 压力账本、线性家族／风险结果及生产集成核验。仅保留本次复算需要的研究代码；原系统引擎生成的交易日历及输入哈希随账本保留。
- 复算生成的 `comparison-35.json`：三类候选与等权综合在相同 35 个十年起点上的 `vs12`、`vsD21`、`vsOwnD`、`vsMatchedAcceleration`、`vsLump`。`yearEqualCAGRpp` 先在买入年内平均年化收益差，再对 2014／2015／2016 三年等权；胜／平／负分母均为 35（12／12／11），平局容差 1e-9 个百分点。
- 原结果路径：`qualifying-target-results.json.results[].periods.reused2014to2016`；完整交易见 `rows` 与 `controls`。三均值的自身回撤是 `(D_mix + 2 × D_21) / 3`，不同于 `D_21`。外部基金证据单独在 `qualifying-external-results.json`；不与原 ETF 混合。

## 执行与证据边界

本金 100 在起点已到位；目标两腿各 30、现金 40，无新增资金、无再平衡、未扣交易费及个人税。月末信号在下一共同收盘成交，累计释放比例为 `max(上期比例, 第几月/12, 当期分数)`；缺分只按 12 月最低进度买齐。最终三类均为 `S = D + (2/3)(1−D)max(0,2F−1)`：期权期限结构用 `D_mix + VIX/VIX3M`，实际波动用 `D21 + VOL`，下跌广度用 `D21 + BREADTH`；三类分数等权，任一缺失则综合缺分。分数是买入执行强度，**不是盈利概率**。固定加速只匹配开发起点平均加分，未匹配整段资金占用。

开发为 2011–2013 的事后十年标签；最终三类的纳入及新综合又使用了 2014–2016 结果，因此同 35 户属于重复使用历史的描述，不能称新的独立验证。35 条十年路径大量重叠；原 ETF 全区间只有 1 个不重叠十年窗口，没有二十年实盘史。三个候选平均均输一次性投入；比 12 月分批好不能全部归因于新增因子。旧基金是实际 SMPIX 1.5 倍／UOPIX 2 倍，美元口径、不同杠杆；二十年窗口的期权因子缺失，综合退回 12 月分批，不构成综合分数有效性证据。

复算边界始于**冻结月度因子与系统买卖日历**，不重新抓取或重建发行人原始数据。清洁 PE 缺失保持缺失；每份因子快照自带来源日期与版本说明。`qualifying` 逐户结果的回撤按共同实际收盘日；报告主表已另外用归档中的独立风险账本重建为 ETF＋汇率联合估值日历。两个字段不可混作同口径。源 NAV／复权价含基金费用及分配再投资，未代表可成交报价或不可修订的历史发布版本。
