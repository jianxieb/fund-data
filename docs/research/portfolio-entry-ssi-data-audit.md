# SSI份额数据：定义、调整与可得时点

本研究服务于“每月新增资金优于固定日期投入”的目标。以下核验只判断SSI输入是否可以可信重建；不计算组合收益，不证明择时有效，也不产生加仓评分。既有四轮失败结果保持不变。

## 数据与时间必须分别验证

原始文件来源、覆盖、SHA256及作者旧工作簿见[输入可行性证据](../evidence/portfolio-entry-signal-feasibility-v1.json)。六只基金固定为SSO、QLD、DDM和SDS、QID、DXD。按每只基金每月最后实际记录计算相邻月末份额增长率，再作三多头之和减三反向之和；不得按组合收益挑基金、月内日期或数据处理方式。

作者主研究使用Bloomberg月度份额数据，ProShares用于交叉核对及日频检查。用今日ProShares下载与旧作者序列对账，是定义与数据源复现；不能宣称拿到了作者当年的原始数据版本。[发表论文](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/846E44374D60D2760DFE5CE4B291F4EA/S0022109022000291a.pdf/speculation_sentiment.pdf)

## 拆股和显示精度的实际核验

[逐事件及逐月证据](../evidence/portfolio-entry-ssi-input-audit-v1.json)覆盖25次拆股、30,705条基金日记录。2006-07至2026-10共244个共同月份，六只基金各自最后记录日均与共同月末一致，没有缺失整月。每只得到243个月度增长率；首月只作基线。

22次拆股的前／当／后三条NAV链接，均在预先写定的打印精度区间内与连续复权口径相容。其余3次是QLD的2012-05-11、DDM的2015-05-20和2018-05-24：差异约6.25×10⁻⁶或1.67×10⁻⁵美元，超出该精度假设，也不符合未调整拆股比例。它们保留为异常，未事后放宽阈值；不能把它们说成未复权，更不能把25次都记作通过。所有事件都保留原始字段、相邻日期和两种口径残差。

全部日记录的显示份额与AUM／NAV隐含份额，在“份额按0.01千份、NAV与AUM按末位打印精度四舍五入”的假设区间内相容。这个舍入规则是审计假设，不是发行方明确保证；同源字段符合会计恒等式也不是独立来源证明。对月度增长率，两种份额口径的最大绝对差如下，单位为增长率百分点：

| 基金 | 最大绝对差 | 对应月份 |
| --- | ---: | --- |
| SSO | 0.0000156 | 2006-08 |
| QLD | 0.00000146 | 2006-09 |
| DDM | 0.00000926 | 2006-08 |
| SDS | 0.297103 | 2006-09 |
| QID | 0.378141 | 2006-08 |
| DXD | 0.119221 | 2006-08 |

所有月度差异均落在预设的显示份额舍入界限内。研究没有据此把AUM／NAV自动替换为正式输入。未来一次拆股若对两个历史端点同时乘相同常数，精确份额增长率不变；缩放后再取整会改变增长率。已经调整的两端再套一次拆股因子则会制造假申赎。合成检查分别覆盖这些情况，不把共同缩放、量化误差与真实历史修订混为一谈。

## 作者旧系列的复现程度

[独立复现证据](../evidence/portfolio-entry-ssi-replication-v1.json)仅重建作者公布的2006-10至2019-02范围，未读取组合收益或训练择时模型。每个固定窗口拟合一次描述性线性换算，以比较原始SSI和作者标准化输出；该全窗口换算只用于对账，不能进入历史交易决策。

| 作者工作表 | 月数 | 显示份额SSI与作者值的相关系数 | 换算后RMSE（作者标准单位） |
| --- | ---: | ---: | ---: |
| Series From Paper | 123 | 0.994022 | 0.108737 |
| Current Series | 149 | 0.992315 | 0.123318 |

两者高度相关，但未精确复现。以AUM／NAV作精度敏感性重建，RMSE分别为0.108754和0.123334，几乎不变；这一精度敏感性检验未消除主要差异，AUM／NAV也未获证为真实未舍入份额。最大偏差都出现在2007-08／09，后一个窗口还出现2017-09／10的偏差；这些异常月份没有表内拆股事件。所有月份均保留，没有为了拟合作者值挑日期、删异常或选择另一套公式。数据源、记录时点或版本差异的具体贡献尚不能区分。

作者两张表自身重叠123个月，仍几乎精确互为线性换算；这一发现与当前官方重建对作者值的非零残差是两件事。相关系数不是择时准确率，RMSE也不是组合收益误差。

## 历史发布时间的证据边界

初始多头基金文件与反向基金最终批准文件均描述每日通过CTA/CQ分发近期NAV和流通份额，并提供前一营业日NAV。前一文件仅批准初始八只基金，反向基金须结合后一份最终批准文件。这支持每日公开分发的制度依据，未保证目前历史CSV每一行的首次公开时刻。[SEC 34-54026，第9页](https://www.sec.gov/files/rules/sro/nysearca/2006/34-54026.pdf)、[SEC 34-54040，第9—10页](https://www.sec.gov/files/rules/sro/amex/2006/34-54040.pdf)

官方产品页给出的NAV计算时间通常为美东16:00，不能把计价时刻当作发布时刻。官方FAQ说明每日NAV与历史下载用途；未在已核对页面发现NAV／份额CSV的具体更新时刻、逐行修订记录或历史调整承诺。网页中市场价格图表的nightly说明不能外推为这些CSV的发布保证。[SSO产品页](https://www.proshares.com/our-etfs/leveraged-and-inverse/sso)、[价格FAQ](https://www.proshares.com/faqs/performance-pricing-faqs)

会计T／T+1记账差异与AP可能延迟到T+6创建份额，属于经济行为和测量滞后，均不是CSV统一延后一天或六天发布的证据。保留来源记录日期，不根据该讨论把日期人为回拨。[论文补充材料IA.3](https://static.cambridge.org/content/id/urn:cambridge.org:id:article:S0022109022000291/resource/name/S0022109022000291sup001.pdf)

可以提出“月末记录值在下一共同交易日固定收盘前决策截止之前可得”的研究假设；每日分发机制为其提供依据。这仍是当前版本重建加明确可得性假设，不能称为逐行历史实时验证。若进入候选研究，必须先固定决策时刻、额外一共同交易日的数据延迟压力、缺失值处理及版本指纹，再计算收益；不得按结果选择延迟。缺失或尚未到达的输入沿用原基准行动，并单列覆盖，不能用后取数据回填过去决策。

历史首次公开时间、补录更正与完整旧版本仍无法逐日追证；HTTP修改时间只描述当前整份文件。未来真实运行必须保存抓取时间和当时文件，以便之后核对。无需因为没有全部旧快照而完全停止透明的历史研究，也不能把这种研究直接升级为已验证的实时交易规则。

## 复现与后续研究

两个脚本均只读取归档原件，核对文件指纹。原件路径记录在证据中，默认位于`/tmp/portfolio-entry-signal-inputs-20261101`；换目录时传`--input-dir`。下载新版本不能冒充本次归档。

```sh
rtk proxy python3 scripts/check_portfolio_entry_ssi_inputs.py --self-test
rtk proxy python3 scripts/check_portfolio_entry_ssi_inputs.py
rtk proxy python3 scripts/check_portfolio_entry_ssi_replication.py --self-test
rtk proxy python3 scripts/check_portfolio_entry_ssi_replication.py --write
```

本轮完成输入关系审计，尚未验证SSI能提高加仓收益。下一候选若采用它，应明确称为按固定月末口径重建的ProShares份额指标，保留上述异常和可得性假设；不得冒称作者原始实时序列。须在看候选收益前冻结唯一规则，并继续与相同每月到账资金的固定日期投入比较，纳入费用、风险、等待成本和跨时期检验。持有一年与最长等五个共同交易日仍是未获用户确认的研究假设。
