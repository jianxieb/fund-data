# A股与美股入选规则复核 · 2026-10-17

## 发现与修复

本次复核针对实际判断链路，而非按市场数量调参。前次公司重新选择保留了三个不一致：A股成长传入累计扣非增长，美股传入单季营业利润增长；A股红利名单直接按旧标签入选；A股旧红利标签阻止了其他经营方向的评审。现在经营方向共用 `company_selection.assess`，红利方向共用 `stock_income.income_review`，前端优先使用本期完整结论。旧日期报告保留原日期结果。

| 方向 | 两市场共同检查 |
| --- | --- |
| 经营企业共同项 | 对应当前财报的具名公司决定、来源、定量证据、风险与失效条件；已公告；非特殊行业；TTM正利润与正经营现金 |
| 长期优质 | 最近五个连续完整财年正利润与正经营现金，另有当前业务持续性判断 |
| 成长/爆发 | 最新单季核心盈利同比为正，上年同期基数为正；另有各公司实际扩张或快速释放的证据；爆发与质量/成长重叠时归前两组 |
| 红利 | 最新财报对应的分红承受能力复核、近12月现金股息率≥3%、最近五个完整日历年均实施现金分红、派息比率≤85%；一般企业正TTM经营现金，特殊行业有当前资本/AFFO复核 |

日期推进不会自动延续业务批准。新财报需重新评审，旧来源不能批准新报告期。`data/stock-income-reviews.json` 保存26家A股的本期分红复核，自动刷新只重算财务条件；美股沿用具名的 `research.incomeReview`，同样校验报告期和公告/复核日期。巨人网络、吉比特没有因为现金收益率过线就从撤回的质量名单自动转入红利名单。

## 保留的实质口径差异

- A股核心盈利为税后扣非归母净利润，美股为税前GAAP营业利润，ADR按其报告准则。两者用于各公司自己的同比与来源分析，不是完全等同的跨市场排名指标。
- A股单季金额用本期累计减前一季度累计，并对上年同期作同样处理；累计中报正增长不再覆盖二季度负增长。年度ROE不因中报而年化。
- A股按法定披露窗口要求最新应披露报告；美股当前报告距研究日不超过155天。两者都必须已经公告，不能把不同披露日历硬设成同一天。
- A股派息覆盖用同股本证据下的近12月每股现金×股数/TTM归母利润；只有连续四季边界及当前股本一致时才能使用该换算。美股普通公司使用已收录TTM EPS与现金每股分红，REIT使用公司披露的本季普通股股息/AFFO。这些分母及期间在详情注明。
- 连续派息按上市证券本身的已实施分红除息日所属日历年计数，不是利润所属财年，也不是银行入账日；A股不能借用H股上市前的历史补年数。原 `divYears` 财年计数仍保留供旧日期资料使用，当前名单及页面使用日历年计数。

统一的是检查流程与条件，不能因此声称主观业务判断绝无偏差、所有会计数据完全同口径，或已穷尽全市场好公司。
