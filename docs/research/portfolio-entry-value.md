# 一年新增资金价值预测：第三轮固定研究

本轮只检验一个目标对齐假设：保持原来的价格特征、回归方法和五日等待动作，改为学习同一笔资金到账满一年后的真实资金差。它没有增加新的预测信息，也不是通过调整参数来恢复旧评分。

[协议](portfolio-entry-value-protocol-v3.json)在生成新模型的标签数值、预测或收益前，以`285e9504`提交并推送。v1七条等待规则、v2短期预测以及后续持有期审计的失败记录保持原样。所有阶段的历史已经接触过，本轮不能称为从未看过的留出验证。

用户已经选择“每月新增资金，比固定日期定投更有效”。主要持有期限尚未得到回复；本轮暂沿用一年为主、三年为辅助的明确假设，不把未回复当作用户确认，也不根据结果挑期限。

首次真实结果：**本轮未通过，不集成。** 开发段平均资金差为负且6次延后全部不利；后两段的正均值仍由极少数事件贡献。下面保留完整协议、结果和独立核验，不调整本版本的参数或门槛。

## 学习目标与时点

研究配置仍是USD半导体杠杆ETF30%、TQQQ 30%、人民币战略现金40%，不表示用户的实际资产。每笔100中40保持战略现金，60用于两只产品及买入费。以相同到账日、相同周年终点和相同交易费，计算两种路径：到账即投，或延后五个共同交易日投入。

设到账共同收盘为`s`，等待买入日为`s+5`，到账日一周年及之后首个共同收盘为`H`，原组合权重为`w=0.3/0.3`。用实际人民币复权价格逐资产计算：

```text
y = (1 - 卖出费率) / (1 + 买入费率)
    × Σ w[j] × P[j,H] × (1 / P[j,s+5] - 1 / P[j,s])
```

标签`y`以**整笔入金**为分母。`100×y`是终值差占入金的百分点，`10000×y`是整笔入金的基点；对1万元入金，后者数值也等于两种路径的人民币差额。正值表示等待有利，负值表示立即投入有利。这是模型尝试学习的量，不表示预测已经可靠。零息主情景下，两个路径的战略现金相同而抵消。

预测某次到账`t`时，特征取`t−1`，只能纳入`H(s)≤t−1`的成熟年度标签。标准化均值、标准差和回归系数也只来自该成熟池。同一天可能成熟多个标签，按终点及原到账先后全部加入；不能用固定252个交易日代替日历年，或沿用旧模型五日成熟的索引。

至少756个成熟标签后，使用原来的五个价格特征、扩展训练池和固定`lambda=1`回归。预测等待差超过`1e−12`整笔入金比例才延后五个共同收盘；每笔只决定一次。现金利率及费率压力情景沿用完全相同的决定，不重新训练或改变阈值。

仅按日历、未看新预测结果的事先核对显示：最早预测日为2014-11-28，首个月初到账为2014-12-01。756条高度重叠的年度日标签不等于756次独立一年经历。

## 如何判断是否有用

主目标是名义1日到账、每笔各持有一年后的资金差。所有没有改变行动的月份都留在总体统计中，改善为零。名义10／20日、三年持有、恰好12笔月供后的共同持有结果全部保留，不选较好的一组替代主目标。

新研究的筛选条件与旧模型的门槛分开登记：

- 全部月份平均资金改善至少0.5个百分点、中位差不为负，原来的较差收益及回撤容忍值保持。
- 真正延后的月份中，中位改善至少0.5个百分点，严格改善比例至少60%。每个阶段至少12个唯一行动月份、覆盖至少3个到账年份，且至少3个完整持有期互不重叠的行动窗口。
- 逐一删除到账年份，以及每个连续12个月到账区间后，剩余月份的平均改善仍须为正；不能由一次事件或一段行情独撑结果。
- 开发段先达标，之后两个阶段分别确认；还要通过固定等待／分批对照、现金利率与费用压力、其他到账日期及完整月供账户的额外检查。

这里把全月份结果与行动子集分开，是因为未行动月份与定投相同，严格胜率不可能超过行动率，过半月份不行动就会使中位差为零。这个结构事实不能撤销旧研究的门槛或失败结论。新规则仍要求所有月份的整体经济改善，并额外限制行动数量和收益集中度；这些数值是事前证据筛查要求，不是统计独立性、足够功效或未来盈利的保证。

完整12笔月供后再持有一年时，前11笔实际持有超过一年，和训练目标不是同一个量。该账户只承担额外的不劣检查；其后期仅23个窗口，少于规定的24月块长，不能声称已经靠这些窗口验证长期连续月供。三年口径样本更少，缺失保持缺失。

空组、非有限值和不足证据不能通过。连续12月删除按日历逐月枚举；内部缺月的区间仍参与检验，至少一个实际12个月齐全的块只作为最低覆盖要求，不能用它过滤掉失败区间。实现审查在首次真实结果之前修正了这一边界，并把旧诊断中“五日成熟标签”的字段名改为年度标签；没有改变预测参数。

## 证据边界

通过历史筛选也不会自动生成0—100分或进入生产页面。还需要独立重建年度标签、训练池、回归和资金账簿，核对未来数据不能改变历史决定，并完成与生产一致的费用、真实分红和个人税处理。当前研究沿用个人税前口径，不作税后改善或所有组合都适用的声明。

原始行情、协议、依赖程序、成熟标签队列和每日预测均记录指纹。全部资金对照保持相同到账日期与金额，不能通过多投入资金、借用未来月供、改权重或改变结算日期获得表面优势。

## 首次真实结果

实际行情截至2026-10-30，首次可用预测为2014-11-28，与事先日历核对一致。源数据中已经观察到3755个完整年度标签，但最后一个历史执行日的预测只能训练到前一收盘，因此使用3754个；当日才结束的标签没有提前纳入。

三个阶段均未满足总体平均改善0.5个百分点及至少12次唯一行动的要求，集中度检查也全部失败。开发段的6次延后中位资金差为−2.399338个百分点，验证段为−1.619375个百分点。后期的单次正差不能作为100%准确率或稳定优势宣传。

验证段的唯一有利延后发生在2020-09-01，一年后的差额为21.533686个百分点，但另5次延后均不利。后期只有2023-08-01一次延后，差额为9.384144个百分点；其他33个月完全沿用立即投入。这解释了为什么正均值仍不能建立稳定择时能力。两后期均值描述区间分别为[−0.465564, 1.225414]和[0, 0.828013]个百分点，下界没有通过要求。

以相同成熟训练池的均值作预测基准，三个阶段的均方误差相对R²为−0.033059、−0.011308、+0.011324。最近阶段误差略有改善，没有带来足够分散、达到经济门槛的资金改善。预测误差与可执行优势分开记录。

最终状态为`development_insufficient_research_only`，`historicalConfirmationPassed=false`。这个状态记录行动覆盖不足；**经济改善为负的开发结果也已明确失败**，不能只用“样本不足”掩盖它。全部108组、657个主情景窗口、其他到账日和持有期结果均保留，没有改选更好的单元格。

## 下一方向的取舍

本轮之后另行核查了现有财政部10年名义利率、10年实际利率和10年减2年利差；[数据可行性记录](../evidence/portfolio-entry-rates-feasibility-v1.json)单独保存覆盖、单位、时间和版本限制，没有用它们训练模型。

目前不登记“加上三个利率变量、仍等待五日”的新版本。最新一手研究对长期利率的月度股票风险溢价预测有一定支持，但预测误差改善没有在其四种简单策略中自动变成战胜持续持股的结果；这也不是本CNY杠杆组合的验证。[Goyal、Welch、Zafirov，2024](https://academic.oup.com/rfs/article/37/11/3490/7749383) 另一项研究的较强股票预测变量是近端远期利差，期限为随后四个季度，不能用现有10年减2年利差代替，也不能直接解释五日买入差。[Engstrom、Sharpe](https://www.federalreserve.gov/econres/feds/files/2018055r1pap.pdf)

从本轮标签可见，一年等待优势包含“五日取得的份额差”与“之后至周年的资产增长”的共同作用。一个变量可能预测长期回报或风险，并不自动说明它能预测这项等待优势。这是本项目对目标的分析，不是文献已经证明该指标无效。

主要持有期及月供到账后最长可接受等待时间已经分别询问，尚未得到回复。后续若研究跨月现金部署，应先明确该动作与用户目标的对应，再事先固定试验；不能仅因找到可取的数据就继续堆变量，或把五日入场检验悄悄改成数季度持币。
