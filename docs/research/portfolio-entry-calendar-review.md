# 日历与月度资金流：候选之前的核查

2026-11-01。**本轮完成机制、日期映射和信息时点核查，没有新增收益试验，也没有得到可集成指标。** 目标仍是同额月度新增资金优于固定日期投入；一年持有、最多等五个共同交易日继续只是研究假设。此前[五轮失败](portfolio-entry-ssi.md)保持原样。

## 月度资金流不能直接变成“月初等五日”

《Dash for Cash》把月度付款和机构流动性需求联系起来。已读的作者学校稿以T表示月末交易日，区分月初T至T+3买压及T+4至T+8随后反转；表6的条件包含完整T至T+3收益。美国主要证据来自T+3制度，不能直接视作现在的窗口。[作者稿正文、表6](https://www.aalto.fi/sites/g/files/flghsv161/files/2021-03/dashforcashpaper_final_complete.pdf)

本项目月首到账在T+1收盘执行；若共同日历与论文交易日一致，等五日比较的是T+1收盘至T+6收盘，包含T+2／+3和T+4／+5／+6。它跨越两个阶段，不是完整反转窗口。T+3才齐全的条件不能用于T+1决策；到账前的反弹也不能用尚未到账的钱捕捉。这是动作与论文的映射判断，尚未计算策略收益。

独立从USD、TQQQ源文件日期交集重建4206个共同日，与第五轮报告日期逐日一致。排除起始不完整月2010-02，2010-03至2026-10共200个已观察月；不按模型暖机、年度成熟或阶段筛选：

| 名义到账日 | 实际月内共同日序号：月数 |
| --- | --- |
| 1号 | 第1日：200 |
| 10号 | 第5／6／7／8日：6／39／74／81 |
| 20号 | 第12／13／14／15／16日：5／44／89／45／17 |

这是历史日期核对，不证明共同价格覆盖等于完整交易所日历，也不证明未来日程当时已知。不能为了贴近论文而把10号或20号换成主比较口径。

较新研究也不能只取有利摘要。2025论文公开正文片段报告2001—2020的月末差异不显著；这不等于收益为负。[出版页](https://www.sciencedirect.com/science/article/abs/pii/S1544612324014909) 2026论文公开片段报告1994—2023国际证据；本轮未取得其全文，不能宣称与前文窗口、条件和成本完全一致。[出版页](https://www.sciencedirect.com/science/article/pii/S1042443126000259) 两篇的完整表格和交易检验均未核实。

## 日历制度与过去可得信息

美股标准结算在2017-09-05由T+3改为T+2，2024-05-28改为T+1。这里取实际实施的成交日，不取更早的规则通过日；机制变化也不授权把全部收益窗口机械平移。[SEC T+2实施说明](https://www.sec.gov/newsroom/press-releases/2017-163)、[SEC T+1问答](https://www.sec.gov/exams/educationhelpguidesfaqs/t1-faq)

若进一步研究付款压力，需分别定义交易日、股票结算日、付款截止和公告时间。完整2010—2026结算日历尚未取得；本轮DTCC具体节日通知只命中搜索索引，直接获取返回404，没有把它们记成全文核验。临时闭市也会改变月末倒数：NYSE保存的CHX通知分别在2012-10-28、10-29宣布次日关闭，不能把后来才知道的安排带回更早决策。[官方历史通知](https://www.nyse.com/markets/nyse-chicago/market-status)

另核对了FOMC周期。Fed 2026-023的表5列出偶数周相对其他周的标普500日超额收益差异：1994—2016为+11.48基点（t=3.83），2017—2021为−12.01基点（t=−1.84，表中仅标10%显著）。方向并不稳定；不能沿用早期正号，也不能事后改用后期负号。该文内部稿日期为2025-08-25，并非检验到2026年。[第6节、表5](https://www.federalreserve.gov/econres/feds/files/2026023pap.pdf)

FOMC历史页本身也不是每个过去时点的已知日程。例如2020-01-29会议纪要在2月19日发布，写的是下次3月17—18日；最终档案则记录3月2日临时会议、3月3日公告、3月15日临时会议及3月17—18日取消。不能提前使用最终替换后的安排。[当时纪要](https://www.federalreserve.gov/monetarypolicy/fomcminutes20200129.htm)、[最终历史档案](https://www.federalreserve.gov/monetarypolicy/fomchistorical2020.htm) 两次声明分别在3月3日10:00 EST、3月15日17:00 EDT发布，事件日与可用时点必须分开。[3月3日声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20200303a.htm)、[3月15日声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20200315a.htm)
