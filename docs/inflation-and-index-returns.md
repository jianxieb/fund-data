# M2、物价与指数真实收益

核对日期：2026-10-01。此文回应“国内指数是否连实际通胀都没跑过、实际通胀是否约6%”。

## M2不能代替消费物价

M2是广义货币供应量，主要由现金和各种存款构成，衡量货币存量。CPI衡量居民消费品和服务价格的变化。存款增加可以伴随信贷扩张、储蓄增加、资产交易和货币流通速度变化，不等于商品服务价格按同样比例上涨；“M2增长率”或“M2增长率减实际GDP增速”都不能直接命名为实际通胀率。[人民银行2024年一季度货币政策执行报告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125227/125957/5347949/4fcccad1c1b342c18c1832aa7469cac1/2024051109091110942.pdf)、[国家统计局CPI统计范围与指标解释](https://www.stats.gov.cn/sj/zxfb/202601/t20260109_1962273.html)。

个人生活成本可能偏离全国CPI；如果主要关心住房购买、教育或医疗，需要自定义消费篮子及权重。房价等资产价格与消费物价不是同一指标，不能凭感觉把两者合成固定6%的通胀率。

## 页面收益不能直接得出“全部国内指数跑输通胀”

国内指数页有上证、沪深300、中证500等不同对象和不同观察窗口。其中价格指数没有计入现金分红再投资；基金总回报则包含分红与持续费用。不能用价格指数走势推断实际含分红投资回报，更不能把不同指数都概括成同一结果。

判断购买力变化需要对齐以下条件：

1. 具体指数或产品，明确价格指数还是含分红总回报。
2. 相同起止时段。页面滚动十年截至2026年9月，与上面的2015—2025年度均值比较不完全匹配。
3. 相同购买力币种。人民币居民持有美股，应先把美元投资回报转换为人民币，再扣中国消费物价；比较美元本地购买力才用美国CPI。
4. 产品费率、交易费和实际税费。定投还需考虑每笔投入日期，不能把期末资产除以投入总额当作统一年化率。

单笔投资的实际购买力累计变化为`(1 + 扣费税后的名义累计回报) / (1 + 同期累计物价涨幅) - 1`。因此目前能够反驳的是“用M2推断全国消费物价年均6%”；不能把这一纠正进一步推断成每个国内指数、每个区间都跑赢CPI。

## 用户截图中的三个口径

截图第一项是用户记得的“M2增速减GDP增速”，但图上“理财圈默认的真实通胀”“最可能”和6.3%没有提供可复算的原始数据及起止年份，不能视为已经证实的价格上涨率。货币数量关系为`M × V = P × Y`，其中V是货币流通速度，Y是实际产出，P是价格水平。对数增长率满足`价格增长 = 货币增长 + 流通速度增长 − 实际产出增长`。只有额外假定流通速度不变，才可以近似省略中间项；即使如此，这也不直接等于居民CPI。若GDP采用名义增速，直接相减的经济含义又不同。[IMF关于货币数量关系与流通速度的说明](https://www.imf.org/external/pubs/ft/fandd/basics/16_monetarism.htm)。

| 图中项目 | 能说明什么 | 图中不能据此推出的结论 |
| --- | --- | --- |
| M2增速−GDP增速，过去20年6.3% | 在说明GDP口径、年份和算法后，可作为货币扩张相对产出的情景参照 | 全国消费物价实际每年上涨6.3%；每项资产都应取得6.3%收益 |
| GDP平减指数，2025年约−1% | 国内生产的最终货物和服务的总体价格变动；指数水平是现价GDP与同基年不变价GDP之比，同比变化另算 | 个人消费篮子下降1%；过去20年通胀是−1% |
| 并入房价的“广义通胀”，2004—2009年均5.7% | 如果有论文、房价序列、篮子权重及计算方法，可以评价那一段时期的自定义资产与消费混合指标 | 这是现时或过去20年的共同物价通胀；美国必须用同样5.7%的扣减 |

GDP平减指数定义参见[国家统计局解释](https://www.stats.gov.cn/zs/tjws/tjzb/202301/t20230101_1903780.html)。即便后两项具体数值有各自来源，截图把20年、2025单年、2004—2009放在一起，也没有形成可比较的同期序列。第三项截图未标研究作者与来源，本次未把5.7%作为事实写入产品。

因此可以把6.3%当作用户自定的投资目标或压力情景，但应标为“目标年回报”或“自定义购买力假设”。研究扣费税后实际购买力时，仍应先明确需要保住的是日常消费、住房购买还是其他具体目标，再选对应的价格序列。
