# 跨境资金产品需求与验收清单

本文件记录本对话截至 2026-10-12 的全部产品要求、用户报告的问题、指定核查的路线和反复出现的退步。后续重构、修复和发布都须逐项对照，不要求用户重新说明已经提出的内容。

**当前结论：整体验收仍未完成，A01研究证据仍有具体缺项。** 2026-10-12新报价快照下，810个上游组合、45个工银亚洲人民币资格组合及五条不同汇路优选已实际操作；本轮再实测540个美元／港币返程组合，页面费用逐条与模型同数。金额、选择与汇总检查无失败，证据范围见末节。16a8d3a、e4e663b曾被用户明确否定：前者删选项，后者拆成逐步表单、隐藏方案和金额。保留这些历史反例，不能用自动检查或截图代替用户的实际使用验收。

本清单记录用户要求，不把用户的金融判断自动写成已核实事实。优惠、费率、汇路和期限要有对应证据；不能以满足文案为由编造免费、成交价或确定性。

## 产品目标和不可重复的错误

用户的目标原话：

> 我要的是清晰、有确定数据、不含糊、不啰里八嗦、不重复的产品，不是他妈的没用的糊弄人的说明书。

> 要注意我说的还有无数个问题，不是只改我提出的，你要全部重新构思。

> 你应该把我这个对话里所有提到的内容都记到一个文档里，我不想再重复任何一个内容，因为你一直重复在漏我说的内容。

据此，交付必须同时满足：

- 用户能看清完整的资金路径、每步动作、已选账户、钱的币种和金额，以及损耗来自什么。
- 银行、汇款渠道、换汇地点、买股账户是不同概念；模型和界面都必须分开。
- 查清数据是开发工作的责任，不能用大批“未计／待确认”把检索任务交还用户。
- 不能通过删掉常用银行、券商、快捷方案、损耗率或锁死选择来制造“数据已经齐全”的假象。
- 不是只修复用户已列出的点：需要检查全部正常操作、默认状态、组合、切换、异常输入、持久化和费用对账。
- 研究说明、采集日志、长篇限制放到详情或仓库文档，主体服务于选择和比较。
- 桌面优先，主要使用环境是 27 英寸 4K 显示器；不能把所有明细纵向堆成长说明书。

## 必须研究并呈现的概念和路径

### 四类账户不能混为一谈

1. 内地出发银行：人民币本金、汇出笔数、购汇报价、实际汇款渠道及汇出收费。
2. 香港收款银行：接收什么币种、汇入收费、账户管理条件；这是收款银行，不是股票交易账户。
3. 买股账户：券商或银行证券服务；可与香港收款银行相同，也可经本地转账进入另一家银行／券商。
4. 资金使用：保留外币、转回本人香港银行、原币消费、换币消费、回内地等；只计所选路径发生的动作。

必须保留并核查的代表路径：

- 中行 → 同名中银香港 → ZA／其他独立买股账户。
- 兴业寰宇人生内地购 USD → 汇丰香港 → 银行证券／独立券商。
- 汇丰中国 → 同名汇丰香港的环球转账。
- 恒生中国 → 同名恒生香港的跨域转账。
- 渣打中国 → 同名渣打香港的指定渠道和客户等级。
- 香港银行 → IBKR、致富、盈立的真实币种及入金方法。
- 同一家香港银行内部交收，与不同银行本地转账分别核算。
- 卖出资金留在境外、USD 原币消费、USD 换 CNH 消费、汇回内地结汇分别核算。

这些是研究与支持范围，不是未经核实的免费承诺。普通电汇、同名优惠、小额全额到账和跨境支付通各有适用条件，不能互相套费。

### 数据和损耗口径

- 原币费用先按原币正确累加，再换成同一人民币参考值；每月价、单笔价与期间总价不得混排。
- 损耗率保留一种明确的展示定义。相对最优购汇损耗按同额人民币可取得外币的差额计算；银行手续费单列并纳入所对应步骤。
- 不把不同银行各自的买卖中间价差与相对最优报价差同时叫同一个“损耗率”。
- 不把“免汇出手续费”“免电讯费”“免基本汇入费”泛化为整条路线零损耗。
- “中行 → 中银香港 0 费用”的核查必须读完豁免范围，而不是只引用标题，也不能因此把确定豁免的基本费用重新写成未知。
- 不用其他银行的报价冒充所选银行的成交价；同时避免一个报价缺失把无关资费、步骤与操作权全部清空。
- 动态汇率可有报价日期和适用范围；采集秒级时间、抓取过程、历史核查放详情或文档。
- 费用券只影响对应订单和费用科目；未填写券信息时不能破坏正常报价。
- 账户管理费、证券托管费、Trade25、交易佣金、平台费、监管费分别归属，避免重复收取。
