# 全站客观评审与实施（2026-10-15—16）

用户要求结合项目全部内容，让子 agent 客观评审值得新增的页面、现有不足，并直接实施高价值改进。

三个子 agent 分别审查研究数据、投入与资金工作流、信息结构；主 agent 交叉核对源码、公开快照，并在本地浏览器检查页面。视觉评审使用 `product-design:audit` 工作流。没有打开生产站核对，也没有把自动测试或截图检查当作用户接受。

## 总体判断

项目已有市场、基金、公司、宏观传导、策略、税费、跨境资金和组合研究，当前最值得补的是研究结果之间的联系，以及直接影响结论的证据和计算边界。继续开设重复的宏观百科、税务中心、ETF目录或普通回测页面，收益不高。

值得保留的基础：证券身份、币种、价格指数与含分红产品已经区分；多数收益能追溯到真实日期与自己的行情；公司研究区分财务更新与经营判断；投资渠道已有独立税务分页签；组合已包含现金、税费、再平衡和持仓贡献。评审没有发现需要因此整体推倒重做的证据。

## 新页面的优先级

| 建议 | 解决的问题 | 决定与数据条件 |
| --- | --- | --- |
| **持有期研究** | 近两年或五年的一个终点不能说明换个月份买入会怎样；少数固定起点也不能体现起点差异 | **本轮已实施**。使用已发布、带哈希的证券自身历史；月末起点、五种期限、美元/人民币、分布、实际路径和CSV |
| 持仓穿透与重叠 | 同时持有SPY、QQQ、行业ETF是否重复集中在少数公司 | 值得做，但须先取得发行人同一观察日的完整持仓、证券身份与权重；当前数据不足以发布精确重叠率。优先作为组合研究中的专用视图 |
| 持续提款与现金流研究 | 积累资产之后，按月取钱遇到早期下跌会怎样 | 后续候选。应以真实历史次序、明确提款与通胀假设展示结果，不直接给“安全提款率”保证；本轮先完成持有期与已有组合结果 |

## 主要发现与实际处理

| 优先级 | 证据和影响 | 本轮处理 | 仍需的工作 |
| --- | --- | --- | --- |
| P1 | 历史分位原来用静态 `data.asOf` 判断过期；整个快照停止刷新时，旧日期可自证为“当前” | 新鲜度改为设备北京时间，统计窗口仍锚定报告日。过期后保留原值、曲线及分位，明确末次观测日和间隔天数 | 设备时间不是来源准确性的证明；仍需维护抓取源 |
| P1 | 默认主动权益91只中65只缺规模观察日，却可通过规模数值门槛 | 表格与详情显示日期或“规模日期未核验”；结果提示不能据此确认当前规模资格，保留研究候选 | **原始日期证据尚未补齐**。后续应从正式报告补证，而非删掉候选或取消提示 |
| P2 | 组合期末清仓可把休市日沿用估值当成成交价 | 要求所有持仓在期末都有真实报价。否则列明缺价对象和最近共同交易日；对照自身缺价时只停止对照 | 沿用报价仍可用于明确的持仓估值，不能变成成交记录 |
| P2 | 定投者实际资金XIRR埋在结果末尾，顶部只有现金流中性的组合年化 | 两种收益并列，区间表、PDF和CSV同步；累计开关不改变XIRR。修复完整365日被当成不足一年隐藏XIRR的问题 | 可继续在现有组合页做收益、汇率、费用贡献拆解 |
| P2 | 基金池已完成收益复算，状态却仍写“旧池收益待复算”；美股直接显示 `unverified` | 根据实际问题代码生成具体缺口标签 | 未映射问题显示问题原文，避免泛化为已核或缺收益 |
| P2 | 美股Forward PE仅有供应商EPS与采集日期，没有目标预测期间 | 数值旁标“预测期间未提供”，详情明确财年/NTM、分析师数量及调整口径缺口，不从PE差值推出盈利增长 | **尚未取得明确的目标期证据**；本轮不猜测或替换数值 |
| P2 | 首页未体现历史分位、全球金融、跨境资金，个股说明只反映A股 | 补齐现有研究方向和新持有期入口；公司数同时包含A股与美股 | 不为同一主题另建重复页面 |
| P2 | 当前单点回报难解释伯克希尔“这两年年化低”的疑问 | 新持有期页把最近区间与全部可用月末完整窗口放在一起；个股/ETF详情可带入对应证券 | 不能把重叠窗口占比解释为未来概率；存续证券偏差保留在说明中 |

具体实现见[历史分位方法](market-history-method.md)、[组合方法](portfolio-method.md)、[证据标签修正](evidence-labels-audit.md)、[持有期方法](holding-period-method.md)。

## 逐步体验评审

| 步骤 / 页面 | 健康度 | 保留的优点 | 主要改进方向 |
| --- | --- | --- | --- |
| 1. 研究总览 | 入口缺失已改善 | 市场概览及主要研究方向有层次 | 本轮补齐入口、纠正公司覆盖说明；首页仍以研究任务组织 |
| 2. 指数观察 | 基础清楚 | 价格指数、公司股票和ETF分组，币种和期间清楚 | 本轮增加持有期衔接；未来产品重叠必须有真实持仓 |
| 3. 历史分位 | 时效问题已修复 | 同轴价格/指标、分位表与年度图已经回应之前的叠图诉求 | 保留现有图表；未来支持带指标和窗口的分享链接 |
| 4. 基金研究 | 数据证据仍有缺口 | 筛选、费用、经理、风险和来源可联合查看 | 补规模日期与经理证据，比再加收益排名更重要 |
| 5. 个股与报告 | 主体结构可保留 | 本期财务、业务判断、特殊损益与风险分开 | 预测PE期间缺口已明确；仍需补真实预测期，而非猜测 |
| 6. 全球金融 | 关系说明较完整 | 传导有前提、条件和反例，知识与实验分开 | 后续将利率、黄金等主题精确连到对应历史数据，保留原选中状态 |
| 7. 投入策略 | 可用但起点有限 | 同资产投入方式对比、现金和XIRR口径明确 | 只有五个预设起点；本轮用独立持有期研究补足起点敏感性，不将不同研究混到一张图里 |
| 8. 投资渠道 | 结构可保留 | 税种、产品实例、账户扣缴独立分页签；模拟基准有说明 | 继续维护真实渠道证据与日期。本轮没有重新独立核验全部法律或银行条款 |
| 9. 跨境资金 | 路径较清楚，缺费项需保留 | 逐步余额、已核费用与未知中转费分别显示 | 涉及既往反复反馈，继续以唯一需求清单记录；本轮只评审，未改该页面 |
| 10. 组合模拟 | 两项核心问题已改善 | 真实交易、现金、税费、持仓贡献和导出已有基础 | 资金XIRR提升到结果首位；清仓不能使用休市日估值 |
| 11. 数据与方法 | 标签问题已修复 | 覆盖、来源、运行记录和逐项缺口齐全 | 状态必须对应真实问题，不因一种缺项贬低已完成的收益复算 |
| 12. 新增持有期研究 | 已完成本地检查 | 一条起点曲线、期限对照表、逐窗口明细与路径相互印证 | 首版仅已收录海外ETF/美股；不拼成立前历史；人民币端点不足单独排除 |

这些健康度来自本次选定路径的截图、实际交互与源码/数据检查，不代表全部状态或完整WCAG审计。新页的选点支持左右键及回车，实测了键盘选点；未宣称完成读屏、全站对比度或所有尺寸的无障碍认证。

## 验证证据

- 全量前端回归 **495项通过、0失败**；JavaScript语法与38项本地资源内容版本检查通过。新增持有期测试14项，另有历史分位及组合/PDF回归覆盖本轮问题。
- 冻结旧快照再推进日期，原值、分位、历史区间和CSV保持一致，新鲜度变为过期；也覆盖北京时间跨日及不同发布频率阈值。
- SPY/贵州茅台各50%，2025-01-02至2025-10-01期末清仓：现在明确拒绝用茅台9月30日沿用估值成交，并提示最近共同交易日2025-09-30。
- 本地组合例子：资金XIRR31.16%，现金流中性组合年化28.05%；切到累计后组合为244.20%，资金XIRR仍31.16%。这两个数回答不同问题，不应互相替换。
- 伯克希尔截至2026-10-13：美元近2年年化6.3444%、历史月末两年窗口341个、中位10.7077%；人民币近2年3.3947%、267个窗口、中位10.7464%。人民币另外74个窗口因端点汇率不足排除，未填造汇率。
- 浏览器实际下载的伯克希尔美元2年CSV有341条样本，从1996-05-31至2024-09-30买入。逐行用导出的股价端点重算累计收益，最大误差为0。
- QQQI的3/5/10年历史不足时留空；XMMO展示2019年的真实策略变更边界，CSV保留策略日期、说明及来源。
- 首页入口、证券详情深链接、币种/期限切换、窗口详情及键盘选点均在本地实际操作。发布通过仓库提交与Pages工作流完成，不访问生产页面核对。
