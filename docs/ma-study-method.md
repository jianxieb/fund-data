# 均线穿越后的历史表现

本研究统计指数收盘上穿、下穿 200 日或 250 日简单移动平均线之后的价格走势。纳斯达克 100 与标普 500 分别使用[收益研究行情目录](../data/return-comparison/catalog.json)中的 `index:^NDX`、`index:^GSPC`，保持两条指数的身份、实际覆盖日期与原始精度；不是 ETF、含息指数或基金净值。来源、文件哈希及最新收盘沿用目录记录。

## 信号与起算

- 均线是截至当日、含当日的最近 200 或 250 个交易日收盘的算术平均值。必须有完整窗口；首个可计算均线的日期只建立指数在均线上方或下方的初始状态，不将此前未知状态当作一次穿越。
- 收盘由均线下方变为上方是上穿，反向是下穿。恰好收在均线上仅算触线，不新增穿越；若先在上方、触线后又回到上方，仍不算上穿。触线后真正转到另一侧才计一次。
- 判断均线位置时使用各交易日自己的均线，不把今天的均线值回填到昨天。模型只用当日及此前价格判定事件，不使用未来行情来确认或排除信号。
- 从穿越日的收盘开始计算后续收益。穿越日自身的涨跌不计入后续回报。收盘信号只有收盘后才完全确定，因此这一统计起点不是承诺可以在已知信号后按同一收盘成交。
- 相邻有效收盘相隔超过 10 个自然日，视为已知长断档；断档后重新累计均线和穿越窗口，不连接两侧状态产生虚假信号。无效日期、重复或倒序日期，以及缺失、非正的收盘值直接报错，不插值或跳过后拼接。

## 窗口内重复穿越

重复穿越筛选使用截至信号日、含当日的最近 X 个交易日，统计上穿和下穿合计次数。X 可为 1–2,520 的整数；次数门槛 N 为 1–X 的整数。筛选条件为至少 N 次，未启用次数筛选时不限制。

窗口为 `[信号日序号 − X + 1, 信号日序号]`，边界包含今天；刚好落在窗口外的上一次穿越不计。只有真实发生穿越的那一天才可能成为事件，之后未再次穿越的日期不会仅因窗口次数仍达标而每天重复入组。上穿或下穿方向筛选决定当前事件的方向，窗口计数始终合计两个方向。

要确认完整窗口内的穿越次数，窗口开始之前必须已经有可核实的均线上下状态。因此均线刚完成暖机时，即使已出现一次穿越，也可能尚无完整的 X 日穿越记录。此时次数记为未知，而非零；启用次数筛选时排除，不限次数时保留事件。

## 期限、收益和风险

后续期限分别为 5、21、63、252 个交易日，近似一周、一月、三月、一年。每期独立判断是否有完整行情，既不把未到期样本记为零，也不拿当前最新点位代替未来目标日。收益区间跨越已知长断档时记为缺行情，不纳入该期统计。

- **累计涨跌幅** = `(期末收盘 / 穿越日收盘 − 1) × 100%`，不年化、不含股息再投资。
- **期间最大回撤**：从穿越日收盘起，逐日更新此前最高收盘，取后续收盘相对这个运行高点的最深跌幅。起算日包含在峰值候选中，起算日前的历史高点不计入。
- **相对起算点最大亏损**：区间最低收盘相对穿越日收盘的涨跌，包含起算点，因此最大值为 0%。它不同于期间最大回撤；先大涨再回落，可能出现较深峰谷回撤但从未亏损初始本金。

收益、两种风险都仅用每日收盘；不代表盘中最深回撤。各事件等权，平均数为算术平均，中位数按排序取中间值，上涨占比只计严格正收益。每期风险与收益使用同一批完整事件，报告有效样本数、尚待到期数和缺行情数。

## 解读与复现

频繁上下穿越可在同一轮震荡中产生多个事件，随后持有区间也可能重叠。样本数不是独立行情次数，历史上涨占比不能直接视为下一次上涨概率。筛选只是对历史事件的条件分类，不证明均线穿越导致回报，也不包含交易成本、融资成本或实际成交约束。

计算实现为 [assets/ma-study-model.js](../assets/ma-study-model.js)。运行 `node --test tests/ma-study-model.test.cjs` 可验证均线暖机、触线与穿越边界、窗口计数、未来数据不改变历史信号、到期分母、断档处理以及两种回撤定义。
