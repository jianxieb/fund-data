# 知识条目与历史数据的连接

本轮本地操作复现：选择纳斯达克100、10年实际国债收益率、10年窗口后，地址仍为 `#market-history`，刷新会回到标普500、PE和20年。知识库的具体条目也不能通过链接恢复。

现在历史分位把指数、指标、窗口写入地址，例如 `#market-history?market=ndx&metric=real10y&years=10`。知识库链接包含具体条目；传导地图包含情景，计算实验包含实际假设。刷新或复制地址可以恢复同一视图。从知识条目进入图表再后退，也会恢复原来的条目和筛选。

页面内调整使用 `history.replaceState`，避免每次选择产生一条后退记录；页面之间的普通链接保留浏览器的前进/后退行为。只有公开研究条件写入链接，不包含组合配置或个人账户信息。基金、股票、投入策略等其它页面的状态规则未在本轮修改。

## 数据与知识边界

- 仅为已经有真实指标历史的知识条目提供叠图入口：TTM PE、名义/实际国债收益率、期限利差、VIX和金融条件。
- 图表仍使用其自身真实指标与原有计算口径。全球金融中的例子、政策情景不生成或替代历史数据。
- 黄金、CPI等尚未对应到本页序列的知识，不伪造其历史图。链接文字明确目标是对应指标与标普500价格；进入后可以切换纳斯达克100。
- 图表可返回相应知识解释；VXN、实际波动和回撤指向解释它们差别的波动率条目，不将它们视为同一种指标。
- 参数按已发布目录验证。未知指标回到该指数默认PE；指数切换时VIX/VXN对应各自指数；窗口只允许5/10/20年。教学计算参数遵守现有滑块范围与步长。

## 验证

自动测试覆盖全量已发布指标链接恢复、无效参数、VIX/VXN对应、中文筛选和教学计算假设往返。交互检查覆盖知识→叠图→后退、刷新保留指数/指标/期限，以及计算实验刷新后保留假设。本轮截图和具体结果见第二轮全站评审。
