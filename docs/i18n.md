# 界面语言：中文默认，可切换英文

Chinese is the source language and the default. English is opt-in through the 中文 / EN switch at the bottom of the sidebar (top right on a phone) or `?lang=en` in the address. The choice is saved in the browser (`changheng.lang`). `?lang=zh` returns to Chinese.

## How it works

`assets/i18n.js` is a translation layer over the rendered page. **While Chinese is active nothing runs**: no observer, no rewriting, byte-identical pages. Every module keeps producing Chinese; in English the layer translates what was rendered:

- text nodes, and the attributes `title`, `aria-label`, `placeholder`, `alt`, `aria-valuetext`, `aria-description`, `data-tooltip`;
- the page `<title>` and meta description;
- a sentence wrapped in inline markup (`共 <b>12</b> 只`) as one unit, reusing the original elements;
- content rendered later (a `MutationObserver` watches the page in English only).

Switching back restores the exact Chinese nodes. Mark an element `translate="no"` (or `data-i18n-skip`) to keep it Chinese. Text that has no entry stays Chinese, so a gap is visible rather than guessed.

Dictionaries are `assets/i18n/en-*.js`, loaded before `app.js` (see `index.html`). Each file exports one object, Chinese text → English text, and registers it with `ChanghengI18n.add('en', …)`.

## Entry syntax

| Key (Chinese) | Value (English) | Meaning |
| --- | --- | --- |
| `研究总览` | `Research overview` | exact text; whitespace is normalised on both sides |
| `已展示 {0} / {1}` | `Showing {0} / {1}` | every number or date in the text is a slot, numbered `{0}`, `{1}`… in order |
| `共 {0} 个交易日` | `{0} trading {0?day:days}` | `{n?one:other}` picks by the number (1 → singular) |
| `规模 {0}亿元` | `AUM CNY {0:yi}` | modifiers: `:yi` ×10⁸, `:wan` ×10⁴, `:wanyi` ×10¹², all printed as K/M/B/T; `:date` ISO date; `:y` year as is (≥ 1000) or `5Y`; `:pad2`; `:abs`; `:plain` |
| `查看{*}研究` | `View {*0} research` | `{*}` matches any text; `{*0}`, `{*1}`… are the captures, and each is translated too |
| `共 <0>{0}</0> 只基金` | `Total <0>{0}</0> funds` | inline markup: `<n>…</n>` is the n-th inline element, `<n/>` a control (input, button, svg, br). Every element must appear once; the value may reorder them |

A date such as `2026年9月16日` or `9月16日` is one slot and, standing alone, becomes `2026-09-16` / `09-16` with no entry. Digits glued to letters (`A500`, `2025Q3`) are not numbers. A sign directly before a number (`+12.5`, `−3`) belongs to the number.

Lookup order: exact → number shape → wildcard patterns (longest literal text first) → a label followed by a sort arrow (`收益 ↓`: the label is translated, the arrow kept) → word by word at `，；：、·/（）` when **every** Chinese word translates or the leftovers are short names (14 characters or fewer). Values are plain text, never HTML.

Keep the English consistent with the glossary below. The tests in `tests/i18n-dictionary.test.cjs` reject keys that cannot match, values that drop a number, capture or element, Chinese left in a value, and Chinese text defined in two files.

## Adding or changing interface text

1. Write the Chinese as usual.
2. Add its English to the nearest `assets/i18n/en-*.js`.
3. `node --test tests/i18n*.test.cjs`, then `npm run version-assets` if a file changed.
4. In English mode, open the page and run `ChanghengI18n.audit()` in the console: it lists the Chinese still on screen, grouped by sentence shape. A text that was only half translated is listed by its original Chinese (`key`), the wording a new entry needs; `current` is what the page shows now.

Output that never reaches the DOM goes through `ChanghengI18n.text(chinese)`, which returns the English in English mode and the original otherwise (PDF canvas text, CSV cells).

## What is not translated

- Names of Chinese funds, fund managers and A-share companies that have no entry stay in Chinese beside their codes. Common fund houses, index names and product types are translated.
- Long research prose generated from datasets (company reports, screening reviews, potential-stock research) stays Chinese.
- The method documents under `docs/` and `README.md` are Chinese.
