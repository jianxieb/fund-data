# 历史事件研究

`#financial-events` 是「全球金融」大类下的独立页面，与「金融传导」分别承载历史案例和机制知识。当前收录15个阶段，覆盖互联网泡沫、全球金融危机、欧债、缩减购债、中国2015年股汇波动、脱欧、两轮特朗普关税、疫情、俄乌战争、美联储加息、地区银行、日元套息平仓，以及2025、2026年的伊朗冲突。

## 读图与计算

- **完整过程**：正文选定的研究起止区间，以各资产均有报价的首个收盘归零。不是声称整个事件已结束；2026年冲突单独标记为持续发展。
- **事件前后**：保留约20个交易日的事件前轨迹，延伸约63个共同交易日；以事件前最后一个共同收盘归零。
- **后续一年**：相同基准，延伸约252个共同交易日。历史不足则显示实际已有日期和未完成状态，不外推。
- **表格**：每种资产以观察交易日前最后一个真实收盘为基准，计算该市场第1、5、21、63、252个交易日的累计回报，并列出每个实际结束日。跨市场假日不同，表格日期可能不同；它与上方完整过程曲线不一定使用相同基准。
- **累计回报**：`终值 / 基准值 - 1`。年化使用实际天数 / 365.2425；不足一年不外推成年化。折线纵轴始终是累计回报，年化仅作附加标签。
- **最大回撤**：在图示完整日期范围内逐个使用各资产自己的日线计算，不因另一市场休市漏掉峰值或低谷。有已知源数据缺口时回撤留空。
- **周末事件**：使用下一个实际交易日作为首个观察交易日；例如2026年2月28日为周六，价格观察从3月2日开始，基准为2月27日收盘。
- **盘后及预期事件**：2025年关税使用4月3日完整交易时段；2018年关税使用事先公布的实施日。互联网泡沫高点、2024年8月5日波动属于事后研究锚点，不能误称不可预见的唯一新闻冲击。

## 行情身份与来源

标普500、纳斯达克综合使用真实价格指数，**不含分红**。上证历史使用Yahoo Finance的`000001.SS`日线，保留人民币价格指数身份；没有用FXI替代A股，也没有声称来自当前仅覆盖近十年的中证接口。

SPY、QQQ、TLT引用已发布组合库及其SHA-256；其他案例资产按标的独立获取。所有基金图采用Yahoo Finance明确的adjusted close字段，包含拆分及分配调整，按分配再投口径解释。费用已进入基金价格；投资者税费、交易成本和个人人民币换汇损益未加入。黄金信托GLD不是带票息的债券；USO是原油期货基金，存在换月和期限结构影响，不是WTI或布伦特现货价格。

EWU、EWJ、VGK、FXI均按美元基金回报展示，分别对应英国、日本、欧洲、香港上市中国大盘股票；它们不是对应国家本币指数。混合币种案例明确按各资产原币计算，不能当作人民币投资组合回报。

数据构建入口：

```sh
python3 scripts/build_financial_events.py
python3 scripts/build_financial_events.py --offline
python3 scripts/build_financial_events.py --check
```

原始补充行情由共享加载器校验标的、明确复权字段、交易所时区与已经收盘的交易日；不使用未收盘实时报价。案例数据存于`data/financial-events-history.json`，逐项带原始来源、币种、回报口径、截至日期、源文件摘要或请求记录。已出版的指数和ETF文件也核对摘要。定时更新在组合与指数更新后重建事件行情，失败则不发布不一致的研究数据。

## 事件事实与解释

`data/financial-events.json`记录34条机构原始来源，每个时间线节点分别引用；主要为央行、BIS、IMF、WHO、USTR、美国国会研究处、FDIC、IEA和IAEA。事实资料复核日为2026-10-17；行情更新日期与正文复核日期分开。对政府政策公告的引用只证明其公布的政策内容，不表示赞同政治论断。

传导分析由项目撰写，界面明确标注。结果属于**事件附近的实际回报**，不是事件的因果效应：未建立反事实、未扣除市场因素，也没有假定其他变量不变。观察窗口、代表资产和锚点均由事后研究选定，存在选择偏差；不得据此形成“发生战争就买黄金”“开始降息就抄底”等确定性交易规则。

2025年伊朗冲突资料描述的是当时的供应风险溢价；2026年IEA资料报告实际能源流量中断，两者分别研究。尚未达到的252交易日数据不填数字；图表更新也不会自动把持续冲突标为结束。

## 验证

自动检查覆盖前收盘与交易日计数、周末锚点、已知缺口、共同日期归一化、独立日线回撤、短期不年化、指数身份及15章全部可复算的期限回报。桌面交互检查覆盖章节与类型切换、完整/事件窗口、柱图、时间游标和2026年未完成区间。证据图片存于`docs/evidence/product-expansion-20261016/`。
