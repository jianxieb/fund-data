# 持续年费与收益口径

核对日期：2026-10-02。产品界面只使用真实扣费后历史，并标注“收益已含年费”；已取消年费扣除切换、扣费前估算及有效年费输入。旧浏览器偏好与导入配置中的估算费率不再改变产品入口的收益口径。

管理费、托管费及适用的销售服务费已经从基金资产计提，体现在公布的净值中。费率资料缺项不等于净值收益缺失；真实净值回报不再依赖费率字段，也不重复扣除或加回年费。产品保留费率资料，并单独处理投资者支付的申赎费、佣金、换汇及所得税。

财通价值动量A当前已收录管理费1.20%、托管费0.20%、销售服务费0，标示持续费率合计1.40%/年。依据：[南粤银行费用及净值说明](https://www.gdnybank.com/jjcs/20260728/40142.html)、[来源费率页](https://fundf10.eastmoney.com/jjfl_720001.html)。标示费率不代表全部历史期间始终采用同一费率，联接及FOF的标示费率也不等于全部资产的实际综合费用。

## 历史方法存档（已退出产品界面）

以下公式、旧实验及对应函数只留作复核，不能据此将产品当前收益解释为扣费前收益。

## 1. 原始收益已经扣过费用

基金公开净值为资产扣除负债后的每份净值，管理、托管和销售服务费等从基金资产计提。ETF的净值与交易价格也反映这些持续费用。供应商分红复权或根据每日涨跌幅、分红、拆分复算的总回报，不会把费用加回来。

因此默认路径直接使用数据源净回报，**不额外减费率**。分红再投、份额拆分、持续费用、投资者税与交易费分别处理。纯指数没有产品年费，切换不改变指数或个股收益。

依据：[SEC，Mutual Fund and ETF Fees and Expenses，2025-07-23](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/mutual-fund-and-etf-fees-and-expenses-investor-bulletin)。该资料说明运营费用从基金资产支付，佣金、买卖溢价等是另一类成本。

## 2. 不扣除是估算情景

没有所有产品每日实际费用及完整历史费率，因此无法宣称还原真实历史毛收益。“不扣除 · 估算”采用现行费率固定的情景：

- 国内普通基金：管理费 + 托管费 + 销售服务费；三个费项均须有值，明确的0有效，缺失不能当作0。不还原其他未收录运营费用、底层基金费用、交易成本与税。
- 海外ETF：发行人现行减免后的净运营费率；不是减免前的gross expense ratio。字段及官方链接见[海外ETF目录](../data/overseas-etf-catalog.json)。按现行费率回算全期间只是统一费用情景，不意味着历史费率始终相同。
- SOXL：发行人披露净费率0.75%，扣除底层基金费用后本基金直接费用为0.71%；仅加回0.71%，不把底层基金费用或掉期融资成本一起撤销。
- ETF联接、FOF：标示管理、托管费可能仅适用于部分资产，底层基金另有费用。缺实际计费资产比例时不直接套用全额标示费率；扣费前留空并列出缺失证据。可以填写研究假设的有效年费率，仍明确为自定义估算。默认真实净收益不受该缺口影响。

联接例证：[广发270042基金合同](https://www.gffunds.com.cn/jjgg/flwj/202501/P020250127545385669645.pdf)明确投资目标ETF的部分不收管理费、托管费。[2025年年度报告](https://www.gffunds.com.cn/jjgg/dqgg/202603/P020260330313889042041.pdf)也披露这一安排。不能对全部联接基金资产再叠加全额管理费和目标ETF费率。

### 公式

年费率百分数为 `f`，日费率 `d = f / 100 / 365.2425`，起止实际相隔 `D` 个自然日：

```
费用还原因子 = (1 - d)^(-D)
扣费前估算累计收益 = (1 + 原净累计收益 / 100) × 费用还原因子 - 1
扣费前估算年化 = (1 + 扣费前估算累计收益)^(365.2425 / D) - 1
```

365.2425是本项目固定计提情景的年长，不声称复制每家合同对平年、闰年或计提基数的实际约定。不能把“年化收益 + 年费率”或“累计收益 + 年费率 × 年数”当作精确还原。实际日期缺失不退回名义年数。USD与CNY采用同一产品费用因子；汇率收益继续使用实际起止汇率。

## 3. 投入策略与投资渠道

先把每个历史价格乘以从共同起日起的费用还原因子，再按原有买入日期和资金流复算。每笔份额从它实际买入日到卖出日才获得对应费用差，期末才投入的资金不被计入整段费用；尚未投入的现金不受产品年费影响。

投入策略保留真实扣费后价格生成的均线、回撤信号和贡献预算，仅改变持仓估值，避免切换费率同时改变策略决策。扣费前账户金额、XIRR、回撤与曲线由模拟重新计算。288组实验的扣费前与扣费后保留相同投入本金、交易次数和共同期间。

投资渠道继续逐笔扣除佣金、最低佣金、换汇价差、美国股息预扣、境内补缴和卖出正收益税。年费情景增厚的估算收益仍按所选税率计税，不把真实净费率再扣一次。费率缺失只影响对应产品的扣费前估算，CSV保留其错误说明。

研究表的风险列始终为真实扣费后日线的风险；切换收益费用情景不会伪装为已重算风险。投入策略的情景风险则实际重新模拟，在页面与本说明中区分。

## 4. 产品分类与分配

海外主表的标普500、纳指100分别列普通、每日2倍和3倍ETF。其他ETF包含信息科技、半导体、期权收益三组，可多选方向与策略。半导体的SOXX、SMH、USD、SOXL须保留各自指数身份，不能把USD当作SOXX收益乘2。

QQQ是被动纳指100跟踪；VGT是美国信息科技行业指数，选股范围不同。QQQI持有纳指100股票并主动买卖NDX看涨期权，目标偏向每月分配，不是纯纳指100跟踪基金。QQQI、SPYI、QYLD、JEPI、JEPQ的分配不等于总回报，资本返还也不能算作额外收益。统一采用明确的分红复权收盘价；没有足够成立历史的3/5/10年区间保留空值。

依据：[Invesco QQQ](https://www.invesco.com/qqq-etf/en/market-outlook/whats-new-about-qqq.html)、[Vanguard VGT](https://advisors.vanguard.com/investments/products/vgt/vanguard-information-technology-etf)、[NEOS QQQI](https://neosfunds.com/qqqi/)、[Direxion SOXL](https://www.direxion.com/product/daily-semiconductor-bull-bear-3x-etfs)。其他产品的策略、费率和成立日逐项记录于目录。

## 5. 验证与维护

`annual_fees.py`与`assets/model.js`使用一致的自然日复利公式。自动测试覆盖重复扣费、销售服务费缺失与明确0、联接豁免、自定义有效费率、闰日、每笔定投持有期、未投现金与所得税。发布质量门禁检查全部5个起点的扣费前曲线端点、组合覆盖、原投入本金和交易次数。

定时更新读取同一ETF目录并重新获取完整复权历史、计算美元/人民币收益及策略费用情景。ETF报价日期独立于国内基金净值日期；节假日不会用国内基金旧净值日截断海外行情。费率目录有单独核对日期；并非自动更新发行人的未来费率变化，调整前应重新核对发行人最新招募文件。
