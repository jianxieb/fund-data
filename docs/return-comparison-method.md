# 跨资产收益对比

2026-10-16。入口：组合研究 → 收益对比。

## 数据身份

使用组合目录中已有的ETF、基金、美股和A股历史，额外发布真实指数点位。标的ID、币种、口径、首末日期以及SHA-256全部检查。价格指数不含分红；境内基金与ETF按净值总回报；海外ETF与个股按供应商含分红复权价格。不把ETF当成指数，不把累计净值比当再投资回报，不重复加分红。

指数目录由`scripts/build_return_indices.py`生成，境内来源为中证/国证历史，海外来源为经过交易时区、已收盘时段检查的Yahoo指数序列。仅使用指数正式发布日期之后的日线，剔除发布前回算。万得微盘未接入授权历史时保留不可选记录与具体原因。定时刷新与同步远端后的重跑均更新此目录，发布前校验所有文件摘要。

## 日期、汇率与收益

- 所选标的共同可用的最后一个日历日期为默认终点。预设区间以该日期回溯自然年；起点采用目标日当日或之前最近的共同观测。若某标的成立较晚，没有完整区间，则使用最早的共同可用观测，并在页面醒目说明缩短后的实际区间。
- 曲线仅使用同一天各标的都有真实观测的日期。跨市场休市日不插值；同日不同交易所收盘并非同一物理时刻。原币模式不包含投资者换汇损益。
- 统一人民币时美元价值乘同日USD/CNY，统一美元时人民币价值除同日USD/CNY。不沿用前值补缺失汇率；有效共同观测仍可绘制，缺失说明保留。涉及缺汇率的回撤不发布。
- 累计收益`(期末/期初−1)×100`。年化为`(期末/期初)^(365.2425/实际天数)−1`，与全站一致；不足约一年（容许3天交易日差）不外推。曲线纵轴始终是累计收益或回撤，年化仅作为整个区间的图例附注/汇总列；柱状图可切换年化或累计。
- 回撤使用每个标的在共同起止日内自身全部有效交易日，保留共同休市差异下的真实峰谷。任一长于21天的内部缺口或同日汇率缺口使该项回撤留空。
- 逐年表以共同的年末观测为分界；首尾部分年度显示实际起止日。逐年数字始终为累计收益。

税前，基金持续年费已经计入；不另扣个人交易费与税。选择当前存续资产有幸存者偏差，重述后的价格历史也不是逐时点无前视的数据。选中资产、筛选与区间存在本地浏览器，不发送持仓或个人配置。

## 验证

纯模型覆盖不同交易日、真实币种转换、汇率缺口、短历史、闰年、亏损与回撤、无共同区间及文件身份不一致。浏览器检查选择、筛选、叠图、柱状图、年度表与原币/人民币切换。`python3 scripts/build_return_indices.py --check`校验已发布指数日线与摘要；`--offline`只使用本机已有原始缓存。
# 2026-10-17 完整标的库修订

原版选择器默认隐藏，资产类别混入公司业务描述，且遗漏了基金页“同方向其他产品”的67个独立证券。本次在已有1,801个可用标的之外补齐这67只基金自己的净值历史：每只独立抓取、复算、校验身份和内容哈希，不借用代表基金的收益。

完整目录共1,869项：16个真实指数（15个可用，Wind授权日线仍缺失并明确标示）、30只海外ETF、192只境内ETF、1,498只场外基金、62只美股、71只A股。1,868项可叠加比较。这里的“全部”指项目已收录证券，包括候选组以外的公司和同方向其他基金，不代表所有全球证券。

选择区默认展开；类型入口始终列出数量。可以组合资产方向、上市/投资市场、策略、指数/基金类别或公司行业、历史长度、数据状态，并按代码、名称、历史或收益排列。搜索覆盖基金经理和发行人。选中资产在切换筛选与分页后保留，最多同时比较8个。

市场与策略标签用于导航：个股按上市市场；基金按已知名称/跟踪指数方向，QDII未披露具体单一市场时归入跨境多地区；不表示当前持仓穿透比例。近1年预览使用各自真实起止日，最终叠图仍按共同区间重算。缺少日线的标的可被搜索到，但不能勾选，不补造回报。

数据生成入口`build_portfolio_data.py --sync-universe`仅刷新元数据并抓取新增证券，保留已发布历史。每日全量刷新同样覆盖其他产品。测试验证完整集合、筛选交集、缺值排序、独立净值文件及新基金叠图。
