# 第二轮全站评审与实施 · 2026-10-16

本轮对应用户“再做一次”：三位子 agent 重新审查研究数据、投资流程、产品结构，主 agent 复现问题、审查修改，并使用 `product-design:audit` 在本地浏览器取新截图。基线为上一轮交付 `9ae6a92`，本报告不把上一轮截图或结论当成本轮新增发现。

## 总体判断

现有页面已覆盖市场、公司、基金、知识、投入、渠道、跨境资金及组合。第二轮最有价值的工作是修复会改变结论的计算错误，并让研究状态可重现。本轮没有增加一级导航：已经完成五组改进，其中包含两处足以影响投资研究判断的 P1 问题。

应保留的基础：指数点位、ETF 与公司股票身份分明；现金流与组合收益已经分别呈现；知识传导有条件、例子和反例；税务内容已经分页；原始日期、缺失项与历史不足大多可以追溯。本轮修改延续这些结构。

## 发现、影响与实施

| 优先级 | 具体问题与证据 | 已完成的改动 |

| P2 | 恰好从100跌至90、80时，浮点误差可能漏触发10%、20%回撤档位 | 阶梯投入、倍数定投统一使用包含边界的比较及1e−12浮点容差；对边界上方仍不触发 |

| P2 | 国内场内ETF卖出费可超过剩余资产，6元投入示例算出−3.90元期末、−164.98%；金额控件还存在 `min=1` 与 `step=100` 的有效性冲突 | 卖出金额不足最低佣金时返回具体原因、不显示负资产收益。金额控件允许范围内的有效数值，维持原金额上限；已在本地操作6元案例 |

### 策略重算的含义

九只ETF采用同一套已发布、可校验哈希的完整美元复权历史，全部截止2026-10-13。432组结果中86组均线相关结果变化，其余346组不变。例如2020起的200日均线择时，SPY资金年化从10.3693%变为11.6034%，QQQ从14.4547%变为18.0615%，SOXL从35.4311%变为26.0188%。修复规则有升有降，没有按收益挑选规则。

独立现金/份额账本核对432/432通过，最大终值差0.004980美元、XIRR差0.000050个百分点，交易次数与最长天数完全一致。[输入哈希与逐行变化](evidence/audit-20261016/strategy-rebuild.json)和[策略方法](strategy-curves.md)可复算。

## 建议新增什么

| 建议 | 用户能回答的新问题 | 优先级与决定 |
| --- | --- | --- |
| **组合方案对照页签** | 同一期间，改变标的权重、投入或再平衡后，收益、回撤、税费差在哪里 | 最近可做的功能，P2。现有模型与历史足够，宜在组合页保存A/B方案并同口径并列；避免另开重复回测页。本轮先修正基础计算 |
| **现金流与提款研究** | 进入支取期后，早期下跌、通胀、分红领取/再投如何影响剩余资产 | 有独立页面价值，P2。须明确真实现金分配、价格、汇率及提款假设；历史回放不等于未来成功概率。目前未做缺数据的精确提款结论 |
| **持仓穿透与重叠** | 买了几只ETF后，实际是否重复集中于相同公司、行业或国家 | 有价值但先补数据。需要有日期的完整发行人持仓及稳定证券映射；不能用前十大持仓推算全部敞口。先做组合内详情，再决定是否独立成页 |

不建议继续新增收益排行榜、另一套估值页、宏观百科或税务中心。现有页面已覆盖这些任务，当前增量来自准确计算和相互连接。
