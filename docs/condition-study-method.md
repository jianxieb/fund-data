# 行情条件后的历史表现

本研究按信号日收盘时的行情状态筛选历史交易日，例如当日及近几日的涨跌、距高点的回撤、均线位置、波动率和 VIX；也可以在信号日之后设一段观察期，再按期间是否收复、是否跌破信号日收盘等继续筛选，然后统计之后 1 个交易日至两年的指数表现。条件由使用者自行填写，可以只填一项，也可以任意组合，也可以都不涉及单日大跌；参照日可以不设。设了参照日（如最新收盘）时，页面还能按它的读数自动选取一组条件，并比较参照日满足的全部单项范围及两两组合，挑出所选期限后扣除偶然性的胜率最高的一组（最佳组合），再用挑选时没用到的后一半历史检验它。纳斯达克 100 与标普 500 分别使用[收益研究行情目录](../data/return-comparison/catalog.json)中的 `index:^NDX`、`index:^GSPC`，口径为美元价格指数、不含分红，不是 ETF 价格或基金净值。来源、文件哈希及最新收盘沿用目录记录，页面随目录更新。VIX 收盘来自 Cboe 官方日线，单独记录在 [VIX 目录](../data/condition-study/catalog.json)；按盘中最高价判断收复时使用[最高价目录](../data/drop-study/catalog.json)。两者的来源与回退见下文。

页面入口为「事件后表现 → 行情条件」。原「指数大跌」页已并入本页，旧链接 `#drop-study?…` 打开后换算为相同的条件，见下文「原指数大跌链接」。

## 指标

所有信号日指标都截至信号日收盘，只使用当天及以前的指数收盘价和 VIX 收盘；追加之后的行情不会改变任何历史读数。N 日均指 N 个交易日。

| 分组 | 指标 | 定义 | 需要的收盘数 |
| --- | --- | --- | ---: |
| 近期涨跌 | 当日、近 3 / 5 / 21 / 63 / 252 日涨跌 | `(当日收盘 / N 个交易日前收盘 − 1) × 100%` | N + 1 |
| 近期涨跌 | 近 N 日涨跌 | 同上，N 在该行自填 1–2,520，默认 10 | N + 1 |
| 近期涨跌 | 近 21 日最差单日 | 含当日的 21 个单日涨跌中的最低值 | 22 |
| 近期涨跌 | 近 21 日大跌天数 | 信号日之前 21 个单日涨跌中，跌幅严格超过该行所填百分比（0.01%–99.99%，默认 5%）的天数；信号日本身不计 | 23 |
| 近期涨跌 | 另一指数当日涨跌 | 研究纳斯达克 100 时取标普 500，反之取纳斯达克 100：`(信号日收盘 / 前一交易日收盘 − 1) × 100%`。对方须有这两个日期的收盘，且两者在对方序列中也相邻 | 2 |
| 距高点与低点 | 距 252 日最高收盘 | `(1 − 当日收盘 / 含当日 252 个收盘的最高值) × 100%` | 252 |
| 距高点与低点 | 距近 N 日最高收盘 | 同上，N 在该行自填 2–2,520，默认 63 | N |
| 距高点与低点 | 距历史最高收盘 | 同上，最高值取自数据起点（1990-01-02）至当日 | 252 |
| 距高点与低点 | 高于 252 日最低收盘 | `(当日收盘 / 含当日 252 个收盘的最低值 − 1) × 100%` | 252 |
| 距高点与低点 | 252 日最高收盘后 | 当日距该最高收盘的交易日数；最高值并列时取最近一次 | 252 |
| 均线位置 | 收盘相对 50 / 200 日均线 | `(当日收盘 / 含当日的简单均线 − 1) × 100%` | 50 / 200 |
| 均线位置 | 50 日均线相对 200 日均线 | `(50 日均线 / 200 日均线 − 1) × 100%`，正值即 50 日线在上方 | 200 |
| 波动与节奏 | VIX 收盘 | 与信号日同一日期的 Cboe VIX 收盘点位 | 1 |
| 波动与节奏 | VIX 近 5 日变化 | `(当日 VIX 收盘 / 5 个指数交易日前的 VIX 收盘 − 1) × 100%`，两端都需有同日读数 | 6 |
| 波动与节奏 | 21 日年化波动率 | 含当日 21 个日对数收益的样本标准差 × √252 | 22 |
| 波动与节奏 | 14 日 RSI | Wilder 平滑：前 14 个涨跌取简单平均，之后为 `(13 × 前值 + 当日) / 14` | 15 |
| 波动与节奏 | 连续收跌 / 收涨 | 截至当日连续收低或收高的天数；收平记 0 | 见下 |
| 信号前一日 | 前一日相对 200 日均线、前一日距 252 日最高收盘、前一日 21 日年化波动率 | 同名指标在信号日前一个交易日的读数，不受信号日本身涨跌的影响 | 201 / 253 / 23 |

窗口不足时读数为未知，而不是 0；含未知读数的交易日不满足该项条件。连续天数一直追溯到序列首日仍未中断时，长度无法确认，也记为未知。相邻有效收盘相隔超过 10 个自然日，视为已知长断档，所有窗口、均线、RSI、连续天数和观察期从断档后重新累计，前一日读数和另一指数涨跌也不跨断档。当前两个指数文件都是自 1990-01-02 起的连续序列，没有这类断档。

「近 21 日大跌天数」沿用原指数大跌页的判断：按完整价格精度比较，跌幅严格超过门槛才计数，门槛为 5% 时恰好下跌 5% 的一天不计。

## 信号后观察期

观察期默认不设。设为 1–252 个交易日后（快捷选项为 1、2、3、4、5、10、21、42、63、126、252，也可自填整数），信号日之后的这几个交易日用于判断下列四项；后续收益改从观察期最后一个交易日（起算日）的收盘起算，观察期内的涨跌不计入后续结果。

| 指标 | 定义 |
| --- | --- |
| 观察期内收复前一日收盘 | 是／否。观察期内任一日收盘达到或高于信号日前一交易日的收盘，即为曾收复；先收复再跌回仍算曾收复。收复判定可改为「盘中最高价」，用同一指数已收盘交易日的最高价代替收盘作这项比较 |
| 观察期内跌破信号日收盘 | 是／否。观察期内任一日收盘严格低于信号日收盘；相等不算，不用盘中低点 |
| 期末收回比例 | `(观察期末收盘 − 信号日收盘) / (前一日收盘 − 信号日收盘) × 100%`，只在信号日收跌时有读数；负值表示期末低于信号日收盘，100% 以上表示已回到跌前点位 |
| 观察期涨跌 | `(观察期末收盘 / 信号日收盘 − 1) × 100%` |

- 观察期须在同一段历史内走完，交易日才可能成为样本。尚未走完的不计入，参照日状态写明还差几个交易日；跨越长断档的同样不计入。
- 按盘中最高价判定时，观察期内每天都须有可核实的最高价。任一天缺失、非正、不是有效数字或低于当日收盘，该交易日记为缺最高价，不以收盘代替，也不进入样本。期末收回比例、跌破与观察期涨跌始终只用收盘。
- 信号日是一段历史的首个收盘时，没有前一日收盘，收复与期末收回比例为未知。
- 「收复」看期间任意一天，「期末收回比例」只看期末收盘：一段样本可以同时是曾收复和期末收回不足一半；先跌破、最后反弹的样本也可以同时是曾跌破和收回过半。
- 两项是／否条件在页面上是「不限／曾收复／始终未收复」和「不限／曾跌破／未跌破」的三选一，每个选项旁显示选择后的段数。
- 设有观察期时，「全部交易日」对照同样要求假定信号日有前一日收盘、观察期已经走完（按盘中最高价判定时最高价完整），后续收益从对应的观察期末起算。

### 每日最高价

盘中最高价使用独立的[最高价目录](../data/drop-study/catalog.json)，不改动收益研究共用的指数收盘分片。目录与分片沿用原指数大跌页的 `data/drop-study/` 路径。采集器为 `scripts/build_drop_highs.py`：

- 来源为 Yahoo Finance chart：`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`，只接受 `^NDX` 与 `^GSPC`、`instrumentType=INDEX`、美元币种。参数为 `period1=631152000`（1990-01-01）、`period2` 为已发布收盘末日之后一天的 UTC 零点、`interval=1d`、`events=div,splits`、`includePrePost=false`。
- `timestamp[i]` 按来源的交易所时区转换为交易日，`indicators.quote[0].high[i]` 是该日最高指数点位；同条 `close[i]` 保存用于对照。复用现有日线规范化器，排除未收盘记录、盘后追加记录和重复的临时尾行。
- 指数的原收盘必须与来源的 `adjclose` 一致，再与现有收盘分片逐日对照，允许供应商精度造成的至多 0.005 指数点差异；高低点没有做复权推算，也不用收盘填补。日期缺失、最高价无效或收盘不符的记录保留具体缺项原因。
- 高价分片包含 `basis=price_index_high`、`closedSessionsOnly=true`、`series=[[date,high]]`、`closes=[[date,sourceClose]]`、原请求地址、来源字节 SHA-256、抓取时间及所校验收盘分片的地址与 SHA-256。目录按内容哈希引用分片。
- 刷新失败保留上一份有效最高价及原 `fetchedAt/asOf`，目录记下 `refreshMissing`，页面注明最近一次更新失败及沿用数据的截止日，不制造新的观察时间。收盘分片更新后，仍可使用逐日对照有效的旧最高价；新增日期或修订不符的日期按缺项处理。
- 页面读取时核对目录身份、分片路径、SHA-256 与分片口径，再逐日只保留来源收盘与已发布收盘相差不超过 0.005 点、且不低于该收盘的最高价。目录或分片无法读取、哈希或身份不符时，页面写明原因；此时按盘中最高价判定的观察期都记为缺最高价，没有样本，可改用收盘判定。

日常刷新随指数数据阶段更新最高价。手动刷新为 `python3 scripts/build_drop_highs.py --refresh`；从已保存原件复建为 `--offline`；仅校验发布内容为 `--check`。原始响应保存在本地忽略的 `.tmp-strategy/drop-study-{NDX,GSPC}-chart.json`，用于复核，不作为网页资源。

## VIX 日线

VIX 是 Cboe 按标普 500 期权价格计算的未来 30 天隐含波动率。研究纳斯达克 100 时同样使用这条序列，代表美股整体的恐慌程度，它不是纳斯达克 100 自身的隐含波动率（Cboe VXN）。

- **来源**：`https://cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv`，不带请求参数，会跳转到 `cdn-api.cboe.com`。表头为 `DATE,OPEN,HIGH,LOW,CLOSE`，`DATE` 是 `MM/DD/YYYY` 格式的 Cboe 交易日；只取 `CLOSE`，单位为指数点。
- **收录**：`scripts/build_condition_vix.py` 校验表头、字段数和日期顺序，缺失或非正的收盘记入 `missingObservations`，不进入序列。抓取当天的行要到纽约时间 17:00 之后才收录，以免把盘中读数当作收盘。结果写入按内容哈希命名的 `data/condition-study/VIX-<哈希>.json`；目录记录起止日期、行数、文件与原始响应的 SHA-256 以及抓取时间。原始响应另存于不入库的 `.tmp-strategy/condition-study-vix.json`。
- **更新与回退**：每日数据更新运行 `--refresh`，内容未变时保留原文件和原抓取时间。抓取失败、新文件缺少已保存的日期或格式不符时，保留上一份读数及其抓取时间，目录记 `refreshMissing`，页面注明最近一次更新失败。没有可用的旧文件时目录标为 `unavailable`，页面在 VIX 两行写明缺 VIX 日线，其他条件照常计算。`--offline` 只用已保存的原始响应重建，`--check` 只校验已发布的文件。
- **配对**：页面只按同一日期把 VIX 收盘与指数收盘配对，不向前补值。Cboe 有而指数没有的日期（如 2022 年起的美国节假日）不使用；指数有而 Cboe 没有的日期，当日 VIX 读数为未知。当前文件中这样的日期为 1991-03-01、1997-01-31、1997-11-26 和 1999-12-31，这些日期及其后第 5 个交易日的「VIX 近 5 日变化」也为未知。VIX 文件比指数旧时，最新收盘的 VIX 读数同样为未知。近 5 日按指数交易日计数，长断档后重新累计。

## 条件与样本

- 每项条件是含两端的闭区间，留空一端表示不限，至少填一端。范围最多两位小数，「252 日最高收盘后」、连续天数和「近 21 日大跌天数」只接受整数。比较时容许 `1e-9` 的浮点误差。
- 一个交易日同时满足所有已选条件，才算满足条件。页面分别显示满足条件的交易日数和样本段数；尚未选择条件时不显示这两个数。
- 一段要等起算后已有 5 个交易日的结果才算样本。段数、满足条件的交易日数、汇总、走势图、逐段记录和导出都只计这些段；刚满足条件的最新收盘自成一段时还没有任何后续结果，不计入；其他起算后不足 5 个交易日的段同样不计入。最新收盘并入此前已满 5 个交易日的一段时，该段照常计入，标为「含最新收盘」。匹配数旁写明另有几段未计入，悬停可见它们的信号日；没有其他样本时，逐段记录写明只有这几段满足条件。每行的「改选后匹配」和「按参照日匹配」的 10 段门槛用同一口径。
- 相近满足日的计法在匹配数旁切换。默认「合并为一段」：首个满足条件的交易日成为信号日，开启一段样本；其后不足合并范围（5、10、21、63、126 或 252 个交易日，默认 21）的满足日并入同一段，不另计后续涨跌；新的一段至少比上一段的信号日晚该范围。匹配数旁写明共有几天并入，逐段记录在信号日下注明并入几天、到哪一天，详情和导出列出这些日期。选「每天单独计」时（地址写 `gap=1`），每个满足日各算一段；从每天单独计改回合并时，沿用上次选的合并范围。
- 并入的满足日离信号日不到合并范围。期限短于合并范围时，它们各自的后续区间与信号日的区间大部分不重叠，结果可能相差很大，合并后这些结果不计入。因此合并且有满足日并入时，汇总表下方写明有几天未计入，并点出短于合并范围的所选期限尤其受影响；每天单独计时，则写明相近日期的较长期限结果大量重叠。
- 历史范围默认全部，可选「排除 2000—2002 年的信号」：按信号日是否在 2000-01-01 至 2002-12-31（含两端）排除，不删除价格，也不改变其他年份的读数和后续路径，例如 1999 年的信号后续跨入 2000 年仍照原路径计算。「全部交易日」对照按假定信号日采用同一范围。
- 参照日满足条件时，它要么开启新的一段，要么并入此前已开始的一段；逐段记录中该段标为「含参照日」，参照日为最新收盘时标为「含最新收盘」。该段起算后不足 5 个交易日时不计入，也不列在逐段记录中。

## 参照日

参照日默认不设：页面只按填写的条件筛选，不显示读数一栏、最佳组合、参照日状态和走势图蓝线，逐段记录不标「含参照日」，导出的参照日一栏留空，名称旁的说明也不提参照日。可以点「用最新收盘」，或选任一日期：非交易日取此前最近的交易日，早于数据首日时取首日。地址写入 `date=latest`（随每天的新收盘前移）或 `date=YYYY-MM-DD`。设参照日或改参照日时，已选各项的范围改按该日读数重取（见下文「手动填写」）；只设参照日不会自动加入条件。点「清除」或清空日期即回到不设：随参照日的范围按当时屏幕上的数字固定下来，参照日读数未知、暂不生效的项去掉。旧地址里有随参照日的项（`=ref`）而没有 `date` 时，按最新收盘读取。

设了参照日时，它决定页面上的读数一栏、历史分位、各行的建议范围与预览段数、自动匹配、最佳组合、随参照日的条件范围（见下文）、参照日是否满足条件，以及走势图中的蓝线。它不截断历史：样本仍来自全部已有行情，参照日之后满足条件的交易日同样计入，因此这不是站在参照日当时所做的回测。

## 后续表现

后续期限可在 1、2、3、4、5、10、21、63、126、252、504 个交易日中任选，至少一个，默认 5、21、63、252（约一周、一月、三月、一年）。汇总表、逐段记录、详情和导出都按所选期限显示；地址写入如 `h=1,2,5`，取默认时省略。

- **累计涨跌** = `(期末收盘 / 起算日收盘 − 1) × 100%`，不年化，不含分红。不设观察期时，起算日就是信号日。
- **期间最大回撤**：从起算日收盘起逐日更新运行最高收盘，取之后收盘相对该高点的最深跌幅。起算日之前的高点不计入。
- **自起算日最大跌幅**：期限内最低收盘相对起算日收盘的涨跌，包含起算日，因此最高为 0%。不设观察期时，页面写作「自信号日最大跌幅」。
- **自信号日最大跌幅**（逐段记录）：从信号日到「观察期末 + 所选最长期限」，最低收盘相对信号日收盘的跌幅，并记下那天的日期和距信号日的交易日数。其后收盘从未低于信号日收盘时为 0%，记作「未再跌破」。窗口尚未走完时统计到最新收盘，标为「至今」；遇到长断档时统计到断档前最后一个收盘，标为「断档前」。它包含观察期，也不要求期限走完，所以未到期的样本同样有读数。

每个期限分别判断是否完整：尚未走完的记为未到期，跨越长断档的记为行情断档，都不计入该期统计，也不以 0 代替。汇总给出中位数、平均数、上涨占比（只计严格为正的结果）和最深值，各段等权。「全部交易日」一栏用同一期限下所有有完整窗口的交易日作对照，说明这些条件下的结果与平常相比如何。

走势图把每段样本的信号日收盘设为 100，画信号前 63 至信号后 252 个交易日；设有观察期时另标出观察期末。至少 2 段有数据的位置画中位数（只有 2 段时即两段的平均），至少 3 段才画中间 50% 区间；悬停提示写明该位置有数据的样本数。有样本不足信号后 252 个交易日时，图注说明右侧只计已发生部分。样本超过 80 段时只画中位数与区间。设有参照日时，蓝线是参照日及其前 63 个交易日，以参照日收盘为 100；参照日早于最新收盘时，蓝线继续画出其后至多 252 个交易日的实际走势。未设参照日时不画蓝线。

## 按参照日匹配

点「按参照日匹配」，页面按参照日的读数自动选取条件，无需手工计算；未设参照日时以最新收盘为参照日。设有参照日、没有任何条件、地址中也没有 `mode=manual` 时就是这种状态，例如 `#condition-study?date=latest`。

1. 按固定顺序尝试 9 项：距 252 日最高收盘、近 21 日、近 5 日、当日涨跌、收盘相对 200 日均线、VIX 收盘、21 日年化波动率、近 3 日、近 63 日。其余各项与这些含义相近、更细，或要先设回看天数、观察期，不自动尝试，可以手动填写。参照日读数未知的一项直接跳过。
2. 每项以参照日读数为中心，宽度为 `0.75 ×` 该指标全部历史读数的稳健尺度（四分位距 / 1.349）。下限向下、上限向上取到该指标的步长（如当日涨跌 0.5%、近 21 日 1%、近 63 日 2%）。
3. 参照日读数处于该指标历史读数最低的 10% 时，下限放开；处于最高的 10% 时，上限放开，以免把极端行情限制在一个窄带内。达到指标自然边界（回撤、波动率和 VIX 的 0，RSI 的 0 与 100，252 日高点后的 251 个交易日）的一端也放开；整数指标向外取整。
4. 与已选条件合并后，在所选计法（每天单独计时一天算一段）、历史范围和观察期下仍有至少 10 段历史样本（起算后 5 个交易日的结果已完整），才保留该项，否则跳过。页面列出跳过的项。

同一份行情、同一参照日和同样的计法、历史范围与观察期，总得到相同的条件。勾选、取消勾选或修改任一条件即转为自选，并写入地址，可直接分享或收藏：

- **随参照日**：自动匹配留下的项、勾选加入的项，以及改参照日之后的已选各项，范围按参照日读数取（规则同第 2、3 步，不再检查样本门槛），地址中写作 `r5=ref`。改参照日、指数、观察期或回看天数时按新读数重取，因此参照日总满足这些项。地址中随参照日、但参照日读数未知的项（如观察期尚未走完的期末收回比例）保持勾选但暂不生效，页面写明是哪一项。没有参照日或参照日读数未知时，勾选只把光标移到这一项的范围框，标为「填写范围后生效」，填入数字后才生效；这种待填写的勾选不写入地址，换到别的地址即取消。只有完全没有历史读数的项（如 VIX 日线读取失败）不能勾选。
- **手动填写**：在范围框里改动数字后，这一项按屏幕上的范围固定下来（另一端一并固定），地址中写作具体范围，例如 `dd252=14~25`。手填的数字保留到参照日改变：设参照日、选另一日期、点「用最新收盘」或「回到最新」时，已选各项（包括手动填写的项和待填写的勾选）都按新参照日的读数重取，改为随参照日，因此范围总对应页面上的参照日。新参照日给不出范围的项（如当天缺 VIX 读数，或该指标历史读数不足 50 个）保留原来的数字。所选日期落在同一个交易日、或最新收盘随新行情前移时，不算改参照日，手填的数字不变。不改参照日时，取消勾选再勾选也可改回随参照日。改动的数字越过随参照日取得的另一端时，另一端改为不限，而不是提示「下限不能高于上限」；两端都是手填的范围仍照常提示。没有参照日时所有范围都是手动填写，页面不再逐项标注。是／否两项是明确的选择，也不随参照日变化。

例如只看当日跌 3% 以上：`#condition-study?r1=~-3`；只看 VIX 30 以上：`#condition-study?vix=30~`；以最新收盘为参照日：`#condition-study?date=latest&r5=ref&dd252=14~25`；以 2020-03-16 为参照日、观察 2 日：`#condition-study?date=2020-03-16&obs=2&r1=~-5&recov=no`。去掉观察期时，观察期各项随之去掉。「按参照日匹配」恢复自动条件；设有参照日时，「清除全部条件」写入 `mode=manual`。

每一行右侧的「改选后匹配」是改动这一项后的段数，单位与上方「匹配 N 段」相同：已勾选的一项写「取消勾选后 N 段」，未勾选的写「勾选后 N 段」（按参照日读数取范围，未设参照日时不显示），已选是／否的写「改为不限后 N 段」；是／否的各个选项旁也标出选择后的段数。名称旁的 i 按钮说明指标的定义和常用读法，以及它在本次匹配中是第几项、取了什么范围、加入时剩几段、为何勾选或跳过；「按参照日匹配」旁的 i 按钮概括上述规则。

至少 10 段只是为了能读出分布，不代表统计显著。自动范围和随参照日的范围依赖参照日读数，参照日或最新行情变化后，条件也会随之改变。

## 最佳组合

设了参照日时，条件区上方的「最佳组合」卡片从参照日收盘满足的范围中自动挑出一组条件，并给出它在所选期限后的历史胜率。未设参照日时不显示卡片。

胜率衡量一组条件的历史走势有多一致：已有该期限结果的段中，与多数段同向的比例。多数段上涨（上涨段多于下跌段，中位数不为负）时，胜率是上涨占比，这组条件看涨；多数段下跌时，胜率是下跌占比，看跌。上涨段与下跌段一样多时按上涨计。期末收盘等于起算日收盘的段计入段数，不算同向。胜率不是上涨占比：上涨 30%、下跌 70% 的组合胜率是 70%，看跌，段数相同时排在上涨 65% 的组合前面。看涨和看跌的组合一起比较。

- **候选范围。** 参与的 20 项指标：当日涨跌，近 3、5、21、63、252 日涨跌，近 21 日最差单日，距 252 日最高收盘，距历史最高收盘，高于 252 日最低收盘，252 日最高收盘后的交易日数，收盘相对 50 日和 200 日均线，50 日均线相对 200 日均线，VIX 收盘，VIX 近 5 日变化，21 日年化波动率，14 日 RSI，连续收跌和连续收涨天数。参照日读数未知或历史读数少于 50 个的一项不参与。门槛跟着参照日读数取，没有固定数值：在该指标的全部历史读数中，从参照日读数的位置往低处（或高处）数过全部读数的 0.25%、0.5%、1%、2%、3%、5%、7.5%、10%、15%、20%、25%、30%、40%、50%、60%，取该处的读数，按指标步长向远离参照日读数的方向取整（天数取整数）；读数有正有负的指标，在参照日读数一侧另加 0。单边范围为「≥ 低处门槛」或「≤ 高处门槛」，最多覆盖 85% 的历史读数；双边范围的两端分别取往低处和往高处数过 2%、5%、10%、20%、35% 的门槛，最多覆盖 70%。超出全部历史读数或落在指标自然边界上的门槛不取，相同的范围只留一个。因此每个范围都覆盖参照日读数，读数越极端，门槛离它越近。例如纳斯达克 100 在 2026-11-23 当日涨 6.86%，当日涨跌的候选为 ≥ 6%、≥ 5%、≥ 4%、≥ 3%、≥ 2%、≥ 1.5%、≥ 1%、≥ 0.5%、≥ 0%、≥ −0.5%；2026-11-20 当日跌 5.61%，候选从 ≤ −5%、≤ −4.5% 直到 ≤ +0.5%。2026-11-23 共有 456 个候选范围。
- **计数。** 与页面其他部分相同：按当前的相近满足日计法、历史范围和观察期，只计起算后已有 5 个交易日结果的段。另数「后续期间互不重叠的段」：按时间顺序取段，每段的信号日至少比上一段晚所选期限才算。合并 21 个交易日、期限不超过 1 个月时两者相同；每天单独计或期限更长时，相邻各段的后续期间大量重叠，同一段行情被重复计算，互不重叠的段少得多。
- **比较与排序。** 每个候选范围单独算一次，不同指标的两个范围再两两组合各算一次，全部比较；同一指标的两个范围不组合。纳斯达克 100 在 2026-11-23 共比较 98,194 组（456 个单项范围、97,738 组两两组合）。比较的组数这么多，总有一些组合只是碰巧走势一致：按通常的 95% 置信下限（z = 1.96）挑，挑出的组合在挑选时没用过的历史上与不设条件差不多（见下文复核）。所以排序用胜率的 Wilson 置信下限，样本量取后续期间互不重叠的段数，z = 5：同时比较约 10 万组时，要让所有组合的 95% 区间同时成立，每组的双侧显著性约为 0.05 ÷ 100,000，对应 z ≈ 5.0（Bonferroni）；双侧已经包含偏涨和偏跌两个方向，所以看涨、看跌一起比较不需要再加严。z 越大，段数少的组合扣得越多，只有段数足够多、或胜率高得多的组合才能排在前面。每组至少 20 段已有结果，其中互不重叠的至少 20 段；单独一项达不到门槛的范围不参与组合。两项的组合须比其中较好的一项单独时得分高 2 个百分点，否则不算。得分相同时依次取已有结果段数多的、项数少的、页面顺序在前的。
- **计算。** 每个范围在每个收盘是否满足记为一位，32 个收盘一组按位相与，再按与页面相同的间隔取段。相近满足日合并时，一对范围的段数、上涨段数、下跌段数和互不重叠段数都不超过其中任一范围按同样间隔能取到的最多段数，按全部同向估算仍不能胜出的组合不再逐段计算；每天单独计时，段数、上涨段数和下跌段数按位直接计数，互不重叠的段数以两项各自的较小值为上限。这两种跳过都不改变挑选结果，测试与逐段穷举核对。一次比较在浏览器中约需 0.2–0.4 秒，页面先显示其余部分，卡片先写「正在比较 2026-11-23 收盘满足的条件…」（日期为参照日），算完再填入；同样的设置不重算。
- **新数据检验。** 以第 ⌊N/2⌋ 个交易日为界（N 为该指数的收盘数；两个指数都是 2008-06-06）。只用分界日以前、期限已走完的段（信号日 + 观察期 + 期限 < 分界），按同样规则挑一组，段数门槛减半为 10 段，方向按这些段中多数段的涨跌定；再统计这一组在分界日及以后按这个方向的胜率，与 50% 及同期全部交易日（假定信号日不早于分界日）同方向的占比比较，取两者中较高的为对照。看涨的组合要高于同期的上涨占比，否则不如什么条件都不设；看跌的组合至少要对一半以上。两半历史的上涨占比不同，一年期尤其明显，所以不与全部历史比较。这里只判断一组，所以用通常的 95% 置信下限（z = 1.96）。结论分五种：通过——胜率的置信下限（同样按互不重叠的段数计样本量）高于对照；优势不明显——胜率高于对照，但置信下限不高于；未通过——胜率不高于对照；样本不足——之后互不重叠的段少于门槛的一半；无法检验——前一半历史中没有一组达到门槛。挑出的组合与卡片上的相同且方向相同时卡片写明，否则列出它的范围并写明它看涨还是看跌。
- **卡片内容。** 组合各项的范围；同时满足时的段数、多数段的方向和段数、涨跌中位数、最低与最高一段；这组条件的胜率（同向段数／已有结果的段数，互不重叠的段少于段数时另行写明）与不设条件时同方向的占比（全部交易日的上涨或下跌占比）；新数据检验的结论和数字；共比较了多少组。挑选依据的菜单写作「1个月后胜率」等，卡片标题旁的说明给出胜率的定义。没有组合时写明缺的是什么：参照日读数回看不足，或覆盖参照日读数的范围中没有一组达到段数门槛。
- **地址与使用。** 挑选依据写入 `best=期限的交易日数`（默认 21，即 1 个月，不写入地址）。旧地址中的限定情形 `scene=below200`、`above200`、`drop`、`rise` 不再使用：打开时忽略，下次改动设置时从地址中去掉。点「用这组条件」把组合写成手动填写的范围，替换原有条件，后续期限加入挑选依据所用的期限，例如 `#condition-study?date=latest&worst21=~-1.5&dd252=~16`；页面上的条件与组合相同时按钮显示「✓ 已使用这组条件」。之后改参照日时，这些范围和其他已选项一样按新参照日的读数重取。

卡片上的组合是在全部历史上比较约 10 万组后挑出的一组，按 z = 5 排序后，它的胜率仍平均偏高约 4 个百分点；挑选同样用到参照日之后的行情（见「参照日」）。复核中，新数据检验的胜率平均只比对照高 1.2 个百分点，480 次中 323 次高于对照，只有 2 次达到「通过」：这些读数对之后涨跌的区分力很弱，期限 1 日时尤其如此。两个指数在各期限都是上涨的时候多，复核中 z = 5 挑出的 480 组全部看涨；看跌的组合要下跌段明显占多数、段数又足够多才能排在前面。组合说明哪些历史读数与之后的涨跌同时出现，不是交易规则。

## 原指数大跌链接

原「指数大跌」页按单日跌幅、观察期内是否收复和若干分档筛选。这些设置都已成为本页的条件，旧链接打开时按下表换算并改写地址，例如 `#drop-study` 变为 `#condition-study?obs=2&gap=1&r1=~-5&recov=no`。原方法与历史核对记录保留在[大跌后的历史表现](drop-study-method.md)。

| 原设置（地址参数） | 本页条件 |
| --- | --- |
| 指数 `market` | 同一指数 |
| 单日跌幅超过 X%（`threshold`，3–10，默认 5） | 当日涨跌 ≤ −X%；近 21 日大跌天数的门槛也取 X% |
| 跌幅上限 `cap` | 当日涨跌 ≥ −上限；上限不高于 X% 时原页面没有任何样本，换算时去掉这个上限 |
| 观察期 `wait`（2–252，默认 2）与收复口径 `recovery` | 信号后观察期与收复判定 |
| 未收复／已收复／全部 `group` | 观察期内收复前一日收盘：否／是／不限 |
| 期末收回比例四档 `rebound` | 期末收回比例 ≤ 0、0–50、50–100、≥ 100 |
| 近 21 日是否已有大跌 `repeat` | 近 21 日大跌天数 0／≥ 1 |
| 跌前与 200 日均线 `trend` | 前一日相对 200 日均线 ≥ 0／≤ 0 |
| 跌前距一年高点 `drawdown` | 前一日距 252 日最高收盘 ≤ 5、5–10、10–20、≥ 20 |
| 跌前 21 日波动率 `vol` | 前一日 21 日年化波动率 ≤ 20、20–30、≥ 30 |
| 另一指数同日涨跌 `peer` | 另一指数当日涨跌 ≥ 0、−2 至 0、−4 至 −2、≤ −4 |
| 观察期内是否跌破 `low` | 观察期内跌破信号日收盘：否／是 |
| 距近 N 日最高收盘回撤 `peakDays`、`peakMin` | 距近 N 日最高收盘 ≥ 门槛；地址未写天数时 N 为 252 |
| N 日累计跌幅 `lossDays`、`lossMin` | 近 N 日涨跌 ≤ −门槛；地址未写天数时 N 为 5 |
| 历史阶段 `era` | 历史范围 |

## 解读与复现

满足条件的日期常常集中在同一轮行情中。合并只能减少重复，后续区间仍可能重叠，样本数不等于独立行情的次数；每天单独计时尤其如此。结果是历史条件分布，不是下一次的概率，也不说明条件导致了之后的涨跌。样本少时，范围稍有变化就可能明显改变结果；所有计算只用收盘价（盘中最高价只用于收复判定），不反映盘中波动、交易成本或实际成交价格。
