### 更新规则

政策是人工核对快照，尚未接入自动更新。`checkedAt` 是本次核对完成日，不能仅随构建日期刷新。`reviewAfterDays=14`，超过阈值时页面明确提示新的决议尚未复核；设备日期早于核对日期时也有提示。

后续出现央行决议时，应检查各地区最新原文、工具名称、幅度、发布日期和生效日，更新 `policies`、来源以及政策视图的解释。同步检查写入知识条目的日期实例（如港币HIBOR），再更新核对日。不能只更新日期，或把空缺的中国政策利率换成任意另一利率。

## 计算模型

模型位于 `assets/global-finance-model.js`，不依赖DOM，输入率以百分数传入。

### 债券

面值100、年票息4%、半年付息，在付息日将未来票息和本金逐笔折现：

`P = Σ[(F × c / m) / (1 + y / m)^k] + F / (1 + y / m)^N`

公式内利率为小数，`m=2`，`N=年数×m`。分别绘制2、10、30年剩余期限曲线，滑块范围0%–10%、步长0.25个百分点。结果为瞬时重估，不含后续票息、应计利息、违约、税费、赎回或收益率曲线形变，不将此公式当作所有实际债券的完整估价。

### 通胀

`今日购买力 = 名义现金 / (1 + 年通胀率)^年数`

以10万元、不产生利息、通胀逐年固定为假设。对应商品篮子的未来成本为 `今日成本 × (1 + 年通胀率)^年数`。0%通胀应保留完整购买力。

### 海外投资与汇率

`人民币回报 = (1 + 美元资产总回报) × (1 + USD/CNY变化) − 1`

以10万元等值初始本金、未套保、不含税费为假设；美元资产收益假设包含分配再投资。瀑布图把资产收益与随后对全部价值进行的汇率折算分开。+10%的资产收益和−8%的USD/CNY变化对应+1.2%的人民币收益，不能简单相加。

### 房贷

`月供 = 本金 × 月利率 / [1 − (1 + 月利率)^(−月数)]`

本金100万元、等额本息、年利率除12、全期固定利率；零利率单独取本金除月数。比较相同本金和期限的新贷款，基准年利率3%。已有房贷需另用剩余本金、剩余期限、重定价日与合同计算，页面明确这一限制。
