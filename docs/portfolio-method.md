### 添加标的的收益风险预览

列表中的1/3/5年年化与5年内最大回撤直接从该标的供组合模拟使用的含分红每日历史计算。使用标的原币（境内人民币、海外美元），不是当前组合权重、追加与再平衡策略的收益；产品年费已包含，未扣个人交易费与税款。

每个收益窗口结束于该标的实际历史末日，起点取对应周年日之前最近观测，最多相距14日；缺完整年份显示历史不足。年化为 `(末值/初值)^(1/max(1,实际天数/365.2425))−1`。最大回撤只在近5年内取运行峰值；不足5年按已收录连续历史计算并显示实际年数。风险继续使用研究页的日频密度、日期缺口及数值校验，不能拿全部历史最大回撤替代5年内回撤。

指标与各自日期保存在组合catalog中，无需打开页面就下载全部产品历史。构建和保留旧历史时一起重算；`--check`复算核对指标与历史文件一致，数值仅容许不同平台幂运算产生的末位差异（绝对误差不超过1e-9个百分点），日期、覆盖状态与缺项原因必须完全一致。`--sync-preview`仅从已发布且通过校验的历史回填列表指标，不联网、不修改行情日期。

## 日期与估值

- 窗口支持近1/2/3/5/10年、共同历史、自定义日期。指定完整窗口未被覆盖时停止并显示具体起始日，不能静默缩短。
- 开始日取指定日之前最近的**共同真实报价日**，最多相距14日；共同历史从最早共同报价日开始。
- 结束日不得超过任一持仓的实际历史末日；有美元持仓时还受汇率末日约束。对照标的不会缩短组合窗口。
- 估值日在持仓及所需汇率的实际观测日并集上取值，休市沿用最近已发布价格，最多14日；汇率最多7日。超限停止。日期不同于统一市场时点，各市场按当地日期收盘，不能据此宣称能同步执行跨市场收盘交易。
- 初次建仓、分批、择时、持续投入和再平衡只在所有正权重资产都有真实报价的共同日期执行。月份、季度或年份切换后，推迟至首个共同交易日。同日先入金，再执行本金计划及择时，最后执行周期再平衡。
- 境内ETF默认用净值，**不包含场内溢价和交易折价变化**。个股和海外ETF使用实际复权股价。

结果同屏提供近1年、近2年、近3年、近5年快照，结束日与当前模拟的实际结束日一致。每个窗口重新入金并独立执行本金、持续投入策略、再平衡、交易费和投资者税计算，不能截取长窗口曲线冒充短窗口的定投结果。权重、初始金额、基础月预算、两类投入策略、税率和对照标的均使用该次模拟的参数；历史未覆盖时只显示具体缺口，不缩短回报窗口，也不影响已覆盖窗口的结果。

## 本金与持续投入策略

`initialMethod` 与 `contributionMethod` 独立选择，覆盖投入策略页的6种本金方式和6种持续投入方式，可组合使用。初始金额为0时不执行本金策略（包括均线仓位切换），月预算为0时不执行持续投入。导入旧配置缺这两个字段时保持“一次性投入＋每月定投”；JSON、CSV和PDF保留实际策略参数。

| 本金方式 | 规则 |
| --- | --- |
| 一次性投入 | 起始共同交易日按目标权重买入 |
| 6/12/24个月分批 | 初始本金等分，在起始月份及后续各月首个共同交易日投入；短窗口余下本金保持现金 |
| 回撤阶梯 | 起点释放25%，前一个共同收盘从模拟起点后峰值跌10%/20%/30%时各释放25%，每档只触发一次；可同时触发多档；36个月后首个共同交易日释放余款 |
| 200日均线择时 | 前一个共同收盘高于200个共同收盘的均值时持有目标组合，否则整个已释放账户持有现金；只在信号切换时调仓，卖出费用与盈利税真实计入 |

初始全部本金在起始日进入账户并计入累计投入及资金单位，等待买入时为**零息现金**，不会把延迟投入当成未来免费获得的本金。`initialReserve` 是尚未从本金计划释放的金额；现金包含它，再平衡仅使用 `账户总值 − initialReserve`，不会提前买入。释放金额含交易费，目标权重未分配的部分仍留现金。

| 持续方式 | 月预算的使用 |
| --- | --- |
| 每月定投 | 每月投入1份基础月预算 |
| 每季度/每年定投 | 在该周期首个共同交易日一次入金并投入窗口内该周期月份数×月预算；最后不满周期按实际月份数；这是期初准备好整季/整年预算的假设，不代表工资提前到账 |
| 回撤倍数定投 | 前共同收盘回撤未到10%投1份，到10%/20%/30%分别投1.5/2/3份 |
| 均线顺势定投 | 前共同收盘高于200日均线投1份，否则投0.5份 |
| 均线逆势定投 | 前共同收盘高于200日均线投1份，否则投2份 |

信号参考组合以各标的**含分红、已含年费、人民币计价**历史按目标权重每日复位，未分配部分零息；参考日仅取所有持仓真实报价的共同日期。它不包含模拟账户的入金、待投比例、交易费、投资者税或择时仓位，避免入金和现金等待改变信号。每次只使用前一个共同收盘：日 `t` 的订单用 `t−1` 的回撤、均线，按 `t` 的报价成交。回撤峰值从每次模拟起点重置；200日均线可读取起点前真实历史，不足200次（或此前断档超过14日）时按常规投入，不把缺历史当作下跌信号。

持仓收益从真实首次买入起统计，卖出净回款包含费用及税；在实际首次买入之前的等待日期不填入持仓波动的零收益样本。模拟账户仍完整包含所有等待现金的日期。界面、1/2/3/5年快照和PDF共用同一模型。

## 权重与交易费用

每项权重非负，总计不能超过100%；未分配部分持有零息人民币现金。允许碎股及任意基金份额，不包含整手、起购金额、涨跌停、暂停申购、结算等待与流动性约束。新增标的不覆盖既有权重，用户可以显式点击均分权重。

“我的组合”的总投入金额就是回测配置中的初始投入 `initial`，统一使用人民币，包括海外资产。单项计划投入额为 `总金额 × 权重 / 100`；修改单项金额时按 `单项金额 / 总金额 × 100` 反算该项权重，其他标的权重保持不变，剩余部分为现金。修改总金额则保留各项权重并重算金额，不自动把超额配置归一化。金额显示到分，换算和模拟保留计算精度；配置仍保存总金额与权重，兼容已有导入文件。

金额是分配预算，实际建仓从总预算中支付下述交易费用后执行；不会在预算之外再收一笔手续费。持续投入独立于初始总金额，按所选计划入金及目标权重分配。初始总金额为0时关闭金额反推输入，保留占比编辑与仅定投模拟。

设当前目标仓位为 `e`（持有为1、择时退出为0）、目标权重为 `w_i`、可再平衡资产 `V = 账户总值 − 待投入本金`、旧持仓市值为 `h_i`、自定义双向交易费率为 `r`。再平衡联立求交易费用 `F` 和卖出盈利税 `T`：

```
F + T = r × Σ |e × w_i × (V − F − T) − h_i| + Σ 卖出盈利税_i
新持仓_i = e × w_i × (V − F − T)
现金 = 待投入本金 + (1 − e × Σw_i) × (V − F − T)
```

采用有界二分求解，买卖额均计费，费用从账户支付，不能借出隐藏负现金。首次买入、本金计划释放和持续投入金额为 `D`，按目标权重新增买入时：

```
可分配金额 = D / (1 + r × Σw_i)
买入_i = w_i × 可分配金额
保留现金 = (1 − Σw_i) × 可分配金额
```

统一自定义比例是研究假设，不代表每家券商或基金的真实收费表。默认0；不计最低佣金、阶梯申赎费、换汇价差等。期末默认持仓估值；开启期末清仓才执行卖出并扣清仓交易费与正收益税。

## 持续年费与投资者税费

默认“扣除”直接使用原始净值或复权股价，持续费用已经从产品资产扣除，不再重复扣费。[SEC对基金与ETF费用的说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/mutual-fund-and-etf-fees-and-expenses-investor-bulletin)区分了持续运营费用与投资者交易费用。

产品只使用真实扣费后历史，不提供加回年费的估算切换。旧浏览器偏好或导入配置中的扣费前选项在产品入口统一改用真实净收益；实际费率缺项不会阻止净值回测。管理、托管等标示费率留在产品资料中，不能再从净值收益扣一次。

模拟税率分别设置美股、A股、境内基金/ETF的卖出盈利税率与分红综合税率，并支持逐项覆盖。产品新配置默认美股两项20%、境内两组0%；旧JSON没有税率字段时按0%导入，保留原回测口径。分红综合税率是来源地预扣及抵免后境内补税的合计假设，不能把10%美国预扣再与20%境内税直接相加。ADR、REIT、返还本金等特殊分配请按实际记录设置有效综合税率，默认20%不代表每只美股的法定实际扣缴率。

法律依据：[个人所得税法](https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3970366/content.html)规定居民境外所得纳税及股息、财产转让所得20%税率，并以收入减原值及合理费用计算转让税基；[境外所得公告](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)规定抵免及申报。A股股息0%是长期持有假设，[财税〔2015〕101号](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n1465977/n1466017/c1967339/content.html)对超过一年持股的股息暂免个税；短期卖出可能触发20%或10%的差别化补税，本模型不自动重建登记结算持有期账簿，须自定综合税率。境内公募的个人税假设依据见[投资渠道方法](buy-location-method.md)。

### 分红税与成本

新增现金分红证据来自Yahoo普通收盘价和现金分配事件，与原有含分红复权序列并存，不改动既有收益、年费、历史日期或净值。除权日分红占总财富的比例 `f = 每份分配 / (除权收盘价 + 每份分配)`；当日已有持仓的人民币税前市值为 `V`，分红为 `G=V×f`，分红税为 `G×所设税率`。复权价已经全额再投，因此只减去税额对应的模拟份额，不再把分红加进账户；净分红 `G−税`加入该持仓的人民币成本。

新买入发生在分红事件之后，不拿到当天的分红。拆股已包含在复权路径中，不另算收入。Yahoo现金分配事件被视为按所设综合税率计税的现金分配，不声称识别每次分配的税务性质。基金净值的日收益包含分红，但不能反推为现金分红；缺完整现金分配、拆分明细时，非零分红或盈利税回测停止，并具名说明缺少的证据。

80只美股/ETF和71只A股新增分红依据。ADP、KO的2001-09-12事件没有除权日收盘价，税费明细只能自2001-09-17覆盖；原始股价历史仍完整保留。早于计税证据窗口的应税回测停止，不能把缺失分红当作零。

### 卖出税与期末清仓

成本采用人民币移动平均法。买入成交额及买入费、税后分红再投入增加成本；卖出按卖出市值占旧持仓市值的比例结转成本。`卖出税=max(0, 卖出成交额−卖出费−结转成本)×税率`，亏损不产生负税额，也不抵减其他交易。再平衡同时用费用与卖出税二分求可投资净资产，使净额目标权重与现金账簿相符。

默认期末是持仓估值，只扣实际发生的分配税与卖出税，不对未实现浮盈计税；选择“期末清仓”才在最后估值日卖出全部持仓，并扣清仓交易税费。股息和卖出税均在事件日预留，未模拟延后申报、跨笔/跨年亏损抵扣、外税抵免结转、ADR费用和个人其他所得；这是税率情景模拟，不是税单。

对照持有回报使用相同税率、单项覆盖与期末清仓设置，不计用户自定义交易费。JSON保留全部税率；每日CSV保留累计税额；持仓CSV/PDF列出卖出税、分红税和实际税率。产品内部已包含的费用/税负留在真实价格和净值中，不再次扣除。

## 组合净值、资金收益与持仓贡献

追加现金是外部本金，不是收益。设追加前净资产为 `A`、组合份额为 `U`，当前净值 `N=A/U`；追加金额 `D` 增发 `D/N` 份，随后交易费用才影响净值。初始净值基准为1，初次建仓手续费的损失纳入收益与回撤。

```
组合累计收益 = 期末组合净值 − 1
账面盈亏 = 期末账户资产 − 累计投入
组合年化 = 期末组合净值 ^ (1 / max(1, 实际天数/365.2425)) − 1
持仓盈亏_i = 期末市值_i + 累计卖出额_i − 累计买入额_i − 分摊交易费_i − 卖出盈利税_i
```

首年不足一年按一年补足，不把一个月5%放大成年化近80%。超过一年按真实日数年化；曲线沿用相同首年规则。持仓盈亏之和必须等于账户盈亏；现金无利息，贡献为0。

最大回撤基于现金流中性净值并包含初始费用；年化波动率使用相邻实际估值日净值收益的样本标准差乘 `sqrt(250)`，是这一混合交易日序列的年化约定。不能当成同步交易下每个市场的独立风险估计。

### 单个持仓的策略收益

持仓表使用模拟器真实交易流水，初次买入、分批、持续投入、择时、再平衡卖出及再买入均计入。以人民币计价，买入现金流为负的成交额加费用，卖出现金流为正的成交额减费用及卖出税；未清仓时将期末持仓估值加入终值，清仓时使用实际税后回款。

```
累计买入 = Σ(买入成交额 + 买入费)
累计回款 = Σ(卖出成交额 − 卖出费 − 卖出盈利税)
实际盈亏 = 期末市值 + 累计回款 − 累计买入
累计投入收益 = 实际盈亏 / 累计买入
策略年化收益 = XIRR(所有带日期的实际买卖资金流 + 期末市值)
```

累计投入收益的分母包含再平衡后再次买入的资金，不是组合新增本金；不能与组合时间加权净值收益混称。年化是资金加权收益，反映买卖时机及金额；它不等于将累计投入收益简单按年数开方。持有不足365.2425天时，年化栏使用累计投入收益并标明不外推。XIRR在对数利率范围 `log(1+r) ∈ [-log(1e8), log(1e8)]` 分段找根、二分求解；未找到根或检测到多个根时留空，不能任选一个。金额及收益与CSV使用同一结果对象。

最大回撤和波动按实际持仓的现金流中性净值计算，起始净值1。持有时按人民币含分红价格变动；无仓位时不承受价格涨跌。买入转入成交额与费用，再扣实际买入费；卖出先扣卖出费与卖出盈利税，再转出净回款。分红先按价格路径反映总回报，再只扣分红税。资金进出本身不制造收益或回撤。单次买入费用的净值因子为 `(交易前市值+买入额)/(交易前市值+买入额+费用)`，卖出为 `(交易前市值−费用−卖出税)/交易前市值`，分红税因子为 `(分红后税前市值−分红税)/分红后税前市值`。净值峰值至少为1，首笔建仓费也计入回撤。

风险路径仅使用该标的观测日、实际交易日、美元资产的汇率日及窗口端点，不因其他标的休市日增加零收益样本。年化波动为日净值收益样本标准差乘 `sqrt(250)`。风险是持仓过程的净值风险，不能把盈亏金额或追加资本造成的市值变化当作回撤。各持仓盈亏之和必须等于组合盈亏；持仓收益率不能加权相加冒充组合回报。

参考：[GIPS Standards for Firms](https://www.gipsstandards.org/wp-content/uploads/2021/03/2020_gips_standards_firms.pdf) 对资金加权收益与外部现金流的区分；这里是研究模拟器，未宣称GIPS合规。

资金年化用实际投入日期和期末市值计算XIRR，仅在完整一年以上显示。年度表现始终是该年度真实窗口的累计净值收益；首末年不完整时显示实际月日。

对照标的取同区间、同币种、同年费及投资者税率口径的持有回报，不计用户交易费；缺覆盖时仅留组合结果并显示原因。账户资产曲线与累计投入比较，避免把单笔持有基准金额冒充相同定投资金结果。

## 长 PDF 导出

模拟结果区的“导出 PDF”生成一张连续长页，包含完整配置（包括零权重标的）、目标与期末结构、初始与追加预算、实际首次买入金额、策略参数、收益风险概览、近1/2/3/5年快照、累计/年化收益、账户资产及回撤四种走势、持仓策略贡献、年度表现、数据来源与费用税务口径。每个来源链接可在 PDF 中点击。历史不足的快照保留具体缺口。

导出使用模拟结果中的配置，并复制结果及对应标的资料。若当前参数已修改，先按当前参数重新模拟；模拟失败或过程中参数继续变化时停止导出，避免新配置混入旧结果。生成期间继续编辑也不会改变已经冻结的报告。图表使用全部每日观测，表格使用全部行，与屏幕滚动位置、折叠状态和当前年化/累计开关无关；不改动用户保存的配置。

PDF 在浏览器本地生成，无服务端上传和外部脚本依赖。中文、表格与图表按两倍像素密度绘制，以相邻图片带组成单页，不受浏览器单张画布最大高度限制；特别长的页面使用 PDF 1.6 的 `UserUnit`。报告内容为高分辨率图片，文字不能直接选择复制；可编辑配置与逐日数值仍可通过原有 JSON、CSV 按钮导出。
