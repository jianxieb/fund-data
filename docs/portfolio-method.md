# 组合模拟：数据、现金流与费用

## 覆盖范围与数据更新

入口为 **组合研究 / 组合模拟**（`#portfolio`）。标的身份集合与基金研究的去重产品、个股研究的观察公司、指数观察的海外ETF一致；包括未通过当前筛选但仍收录在研究池的产品，不把单个价格指数当作可买产品。

首次发布覆盖1,711只：1,623只境内基金及ETF、71只个股、17只海外ETF。每只产品使用自身历史，不用关联指数或其他基金代替。

| --- | --- | --- | --- |

境内基金的旧历史可能有未提供涨跌幅的财务净值观察。仅在同一基金的 `https://fund.eastmoney.com/pingzhongdata/{code}.js` 明确给出匹配日期、相同单位净值及 `equityReturn` 时补入该收益值；包括**明确发布的0**。不会把缺失值猜成0。单位累计净值 `LJJZ` 不是分红再投资序列，不能用其比值计算回报。

历史仍存在早期无效净值、缺每日收益或长停更区间时，只保留后续可证明的连续历史；逐项记录真实起始日和被截断原因。缺数据时仍保留标的库身份，列明具体缺项，不生成模拟曲线。

`scripts/build_portfolio_data.py` 生成延迟加载的 `data/portfolio/catalog.js` 和逐产品JSON。文件名带内容哈希，客户端核对SHA256、身份、币种和日期，未选产品不下载历史。定时刷新增加 `portfolio` 阶段，基金历史先增量获取最近20行，缺接续才取全量；个股、海外ETF与汇率复用前序已刷新且核对过的缓存。刷新失败不能令已发布历史消失或末日倒退。

同一阶段使用已经验证的境内基金历史同步基金研究的3/5年风险。不足5年的产品使用实际已收录区间，标明日期与年数；收益窗口仍要求完整覆盖。单独执行 `--sync-risk` 可从已发布内容哈希文件复算风险，不联网，也不更新产品NAV或历史收益日期。阶段失败回滚同时保护catalog与snapshot。

## 日期与估值

- 窗口支持近1/2/3/5/10年、共同历史、自定义日期。指定完整窗口未被覆盖时停止并显示具体起始日，不能静默缩短。
- 开始日取指定日之前最近的**共同真实报价日**，最多相距14日；共同历史从最早共同报价日开始。
- 结束日不得超过任一持仓的实际历史末日；有美元持仓时还受汇率末日约束。对照标的不会缩短组合窗口。
- 估值日在持仓及所需汇率的实际观测日并集上取值，休市沿用最近已发布价格，最多14日；汇率最多7日。超限停止。日期不同于统一市场时点，各市场按当地日期收盘，不能据此宣称能同步执行跨市场收盘交易。
- 初次建仓、每月追加和再平衡只在所有正权重资产都有真实报价的共同日期执行。月份、季度或年份切换后，推迟至首个共同交易日。同日先追加，后再平衡。
- 境内ETF默认用净值，**不包含场内溢价和交易折价变化**。个股和海外ETF使用实际复权股价。

结果同屏提供近3年、近5年快照，结束日与当前模拟的实际结束日一致。每个窗口重新建仓并独立执行追加、再平衡及交易费计算，不能截取长窗口曲线冒充短窗口的定投结果。权重、初始金额、每月追加和对照标的均使用该次模拟的参数；历史未覆盖时只显示具体缺口，不缩短回报窗口。

## 权重与交易费用

每项权重非负，总计不能超过100%；未分配部分持有零息人民币现金。允许碎股及任意基金份额，不包含整手、起购金额、涨跌停、暂停申购、结算等待与流动性约束。新增标的不覆盖既有权重，用户可以显式点击均分权重。

“我的组合”的总投入金额就是回测配置中的初始投入 `initial`，统一使用人民币，包括海外资产。单项计划投入额为 `总金额 × 权重 / 100`；修改单项金额时按 `单项金额 / 总金额 × 100` 反算该项权重，其他标的权重保持不变，剩余部分为现金。修改总金额则保留各项权重并重算金额，不自动把超额配置归一化。金额显示到分，换算和模拟保留计算精度；配置仍保存总金额与权重，兼容已有导入文件。

金额是分配预算，实际建仓从总预算中支付下述交易费用后执行；不会在预算之外再收一笔手续费。每月追加独立于初始总金额，仍按权重分配。初始总金额为0时关闭金额反推输入，保留占比编辑与仅定投模拟。

设目标权重为 `w_i`、初始交易前净资产为 `V`、旧持仓市值为 `h_i`、自定义双向交易费率为 `r`。再平衡先求交易费用 `F`：

```
F = r × Σ |w_i × (V − F) − h_i|
新持仓_i = w_i × (V − F)
现金 = (1 − Σw_i) × (V − F)
```

采用有界二分求解，买卖额均计费，费用从账户支付，不能借出隐藏负现金。初始建仓也用同一公式。每月追加金额为 `D`，未启用再平衡时：

```
可分配金额 = D / (1 + r × Σw_i)
买入_i = w_i × 可分配金额
保留现金 = (1 − Σw_i) × 可分配金额
```

统一自定义比例是研究假设，不代表每家券商或基金的真实收费表。默认0；不计最低佣金、阶梯申赎费、换汇价差等。期末为持仓市值，不视为全仓卖出，因此不扣假设的期末清仓费用。

## 持续年费与投资者税费

默认“扣除”直接使用原始净值或复权股价，持续费用已经从产品资产扣除，不再重复扣费。[SEC对基金与ETF费用的说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/mutual-fund-and-etf-fees-and-expenses-investor-bulletin)区分了持续运营费用与投资者交易费用。

产品只使用真实扣费后历史，不提供加回年费的估算切换。旧浏览器偏好或导入配置中的扣费前选项在产品入口统一改用真实净收益；实际费率缺项不会阻止净值回测。管理、托管等标示费率留在产品资料中，不能再从净值收益扣一次。

这是投资者税前模拟：没有扣境外股息预扣、境内补缴、卖出所得税和个人申报税项。实际分红视为全额再投资。中国大陆税收居民通过香港券商投资美股的税后渠道比较仍见[投资渠道方法](buy-location-method.md)。产品内部已经反映在价格/净值中的费用或税负仍留在数据里，不声称还原税前指数。

## 组合净值、资金收益与持仓贡献

追加现金是外部本金，不是收益。设追加前净资产为 `A`、组合份额为 `U`，当前净值 `N=A/U`；追加金额 `D` 增发 `D/N` 份，随后交易费用才影响净值。初始净值基准为1，初次建仓手续费的损失纳入收益与回撤。

```
组合累计收益 = 期末组合净值 − 1
账面盈亏 = 期末账户资产 − 累计投入
组合年化 = 期末组合净值 ^ (1 / max(1, 实际天数/365.2425)) − 1
持仓盈亏_i = 期末市值_i + 累计卖出额_i − 累计买入额_i − 分摊交易费_i
```

首年不足一年按一年补足，不把一个月5%放大成年化近80%。超过一年按真实日数年化；曲线沿用相同首年规则。持仓盈亏之和必须等于账户盈亏；现金无利息，贡献为0。

最大回撤基于现金流中性净值并包含初始费用；年化波动率使用相邻实际估值日净值收益的样本标准差乘 `sqrt(250)`，是这一混合交易日序列的年化约定。不能当成同步交易下每个市场的独立风险估计。

### 单个持仓的同期表现

“持仓贡献”将**标的同期持有表现**与**组合内实际贡献**分组展示。每项同时列出年化收益、累计收益、最大回撤、年化波动；目标权重、期末权重、市值、盈亏贡献和交易费仍对应用户实际设置的组合策略。

标的指标采用该次模拟完全相同的开始日和结束日，以产品自身的含分红历史换算为人民币后计算。不能用上市以来或另一个滚动区间替代。设人民币复权价/净值为 `P_t`：

```
标的累计收益 = P_end / P_start − 1
标的年化收益 = (P_end / P_start) ^ (1 / max(1, 实际天数/365.2425)) − 1
标的最大回撤 = min_t(P_t / max_{s≤t}(P_s) − 1)
标的年化波动 = sample_std(P_t / P_previous − 1) × sqrt(250)
```

上述指标不受用户追加本金、权重或再平衡交易影响，也不额外扣用户自定义交易费；持续年费和分红口径与实际历史相同。组合内真实手续费仍计入交易费列、盈亏贡献和组合净值。这些收益率不能乘期末权重后相加，冒充包含现金流和再平衡的组合回报。

风险路径使用该标的自己的观测日期；美元资产再并入美元兑人民币实际汇率日期，反映休市期间汇率变化。路径补齐模拟起止估值点并仅沿用此前有效报价，不加入其他持仓独有的日期来人为稀释波动。年化波动沿用250个估值日的约定，少于两个区间收益时留空。现金为零息人民币，四项指标均为0。表格与“导出持仓”CSV使用同一结果对象。

资金年化用实际投入日期和期末市值计算XIRR，仅在完整一年以上显示。年度表现始终是该年度真实窗口的累计净值收益；首末年不完整时显示实际月日。

对照标的取同区间、同币种、同年费口径的持有回报，不计用户交易费；缺覆盖时仅留组合结果并显示原因。账户资产曲线与累计投入比较，避免把单笔持有基准金额冒充相同定投资金结果。
