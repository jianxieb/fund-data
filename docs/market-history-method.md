## 静态快照的新鲜度（2026-10-15）

历史统计窗口继续使用发布数据的 `asOf`，新鲜度改为单独使用用户设备的北京时间日期。整个数据刷新失败、旧文件继续提供时，不能用冻结的 `asOf` 证明旧观测仍然是“当前”。每次页面渲染会重新取北京时间日期；分位摘要缓存也包含该日期。

- 日频超过10天、周频超过15天、月频超过65天、季频超过140天时，显示最近观测日、距当前日期的天数与更新阈值。观测日早于/等于统计截止日的取样规则不变。
- 过期后保留原数值、曲线、历史分位和年度结果，改称“末次观测”，不把过期当作缺失数据；年度未满年期间改写为“年初至MM-DD”，避免旧快照继续声称“至今”。观测日晚于设备日期时提示检查设备时间。
- 原始数据文件、统计区间、样本、分位计算、年度收益及CSV内容未因时效提示而变更。新鲜度只说明是否仍可把该观测当作当前读数，不证明来源准确性。

回归专门冻结同一份发布快照，只推进设备核查日期，验证旧值与分位仍保留但当前措辞撤下；另外覆盖北京时间跨日、各频率阈值边界、未来设备日期差异，以及历史样本/分位/CSV不变。本段为计算和渲染层检查，不替代视觉验收或用户接受。

### 对齐、统计与年度边界

1. 主图使用原始日期并集作为可访问的读数时间轴，各序列只从自己的日期查值；没有精确同日记录时返回空值。短于20年的指标只在实际覆盖区间绘制；超过10日（日频）或15日（周频）的异常缺口断线。绘图降采样保留桶内极值与端点，分位统计始终使用全部原始观测。
2. 分位继续用中位秩 `100 × (小于当前值的观测数 + 0.5 × 等于当前值的观测数) / 有效观测数`。中位数与10%—90%范围使用R type 7分位。高分位只表示数值较高，不能把负回撤的高分位误称为高风险。
3. 自然年累计价格涨跌使用上一自然年最后收盘到本年最后收盘。当年截止报告日，标“年初至今”；首个年份若只覆盖年中之后，使用窗口内首个收盘作起点，标“窗口内”。这些日历期间不展示无意义的累计／年化切换，始终为累计价格涨跌。
4. 年度最大回撤从同一收益起点起按顺序追踪收盘峰谷，不是起止收益，也不是该年最后一天的滚动一年最大回撤。缺少上年有效收盘、区间内部超过10日断档、期末陈旧时，不发布该段年度涨跌与回撤。
5. 年度折线和“期末指标”严格取价格期末同日指标；期间中位数仅统计该期间的原始频率观测，另列观测数。没有精确同日值时不把邻近日期挪到期末。
6. 双轴各有独立量纲。只比较时间上的对应，不能把交叉点、斜率或曲线高低解释成数值相等或因果关系。

### 样本与计算

1. 以每个**已结束日历月**的最后实际交易日为观察日，只配对该日的指标与同一指数收盘。PE来源在非美股交易日也可能有记录，这些日期不参与收益样本；不把前一天PE沿用至缺失月末。
2. 估值图观察12、36、60个日历月后的月末收盘。研究的是观察日收盘到结束日收盘的历史关系，**不是下一交易日成交的可执行策略**。结束月尚未完整结束的样本剔除。
3. 累计价格收益为`P_end / P_start − 1`；年化为`(P_end / P_start)^(365.2425 / 实际天数) − 1`。美元价格指数，不含分红、税费，不替换成总回报。
4. 风险图固定为观察日后21个交易日的对数收益样本标准差乘`√252`。它与Cboe的未来30个日历日隐含波动期限接近但不完全相同；不能直接把差值称作可交易波动风险溢价。
5. 途中最大回撤包含途中形成的新高，取持有路径中收盘相对之前最高收盘的最差跌幅。任何区间超过10个日历日的行情缺口均剔除。
6. 默认保留所有符合条件的月末，可显示长期持有结果，但窗口可能重叠。切换“不重叠窗口”时，按观察日期顺序，后一样本起点不得早于前一终点；两窗口可以共享终点/起点收盘，但不共享日收益。该方法受首个观察日影响，也不保证经济意义上的独立性。
7. PE分组为`<20`、`[20,25)`、`[25,30)`、`[30,35)`、`≥35`倍。VIX边界为15、20、30，VXN为20、25、35。阈值预先固定，没有根据后续回报调优。
8. R²为样本内一元OLS拟合的解释度，至少3个样本且两个变量方差非零才展示。没有给显著性、预测准确率或因果结论。散点拟合线只画在历史输入取值范围内，不把回归交点画成当前目标回报。
9. 中间50%是R type 7的25%—75%分位，不是预测置信区间；期末严格负收益才计亏损。空组显示无样本，不输出0%胜率。不重叠样本不足12段仅作数量提醒，不是显著性检验门槛。摘要中R²低于15%的文字只是弱线性拟合提示，不声称策略有效性检验通过或不通过。
10. CSV导出每个散点的完整精度数据：指数、指标来源与口径、历史版本性质、抽样方式、观察日、终止日、起止价格、累计/年化收益、实际波动、回撤、USD价格指数标签。

## 计算及更新规则

每项在`[报告截止日−年数, 报告截止日]`内取有效原始观测，包含当前值；不跨频率加权，不补齐缺失日。

- 经验分位：`100 × (小于当前值的样本数 + 0.5 × 相同值样本数) / 样本数`。全相同为50%，最高唯一值略低于100%。
- 分布区间使用R type 7线性插值分位数。
- 实际波动率：21个交易日对数收益的样本标准差 × √252 × 100。
- 距一年高点：当前收盘 / 过去252个交易日最高收盘 − 1。
- 200日均线偏离：当前收盘 / 过去200日收盘均价 − 1。
- 期限利差：官方同日10年收益率减2年收益率，只配对同日观测。

高分位不统一代表贵、便宜或未来回报。历史线按时间桶保留极值；分位、分布、CSV使用全量观测；缺口断线显示。日频超过10天、周频超过15天未更新，主视图暂停该项当前读数与分位，不把旧日期改成采集日期。

### 数据与显示

- 日期滑杆查阅月末以及最新收盘的同日读数；指标缺失显示空值，不沿用前值。VXN缺少2009-09之前已核验官方历史，其图保留空白，相似分析也只从实际可用月份开始。

### 固定分组

每组均左闭右开，最外层无限延伸。阈值是此功能的固定描述参数，没有根据后续收益拟合，不能声称为最优买卖阈值。

| 指标 | 分组边界 |
| --- | --- |
| VIX（点） | 15、20、30 |

### 后续表现

1. 观察窗为报告日往前5、10或20年，只取已经结束的日历月份最后一个实际交易日。当前月份不作为历史信号。
2. 信号后下一个交易日收盘进入，持有21／63／126／252个交易日，界面简称1／3／6／12个月；不是逐日精确的日历月，也不是信号日收盘成交。
3. 截止日尚未走完全部持有期的样本排除。包含超过10个日历日价格断档的窗口排除，不对缺失行情作收益推算。
4. 相似组筛选与当前分组一致的信号月末；全部时期基准使用同一有完整指标和后续价格的月份池，不限制数值分组。两组分别从早到晚贪心选择，后一入场日必须晚于前一样本终止日，去掉组内重叠持有窗口。
5. 价格累计收益=`终点收盘/起点收盘−1`。无分红再投资，不含税费，也不把短期结果年化。
6. 途中最大回撤为整个持有区间中，收盘价相对其之前区间最高收盘的最差跌幅，包含途中新高。它与相对入场价的最大亏损、期末亏损均不同。
7. 汇总中位数、收益25%—75%分位、期末严格小于0的样本比例、途中最大回撤中位数、较差四分位与历史最差。采用R type 7线性分位插值，没有成熟匹配样本时返回空缺，不输出0%胜率或收益。
8. CSV同时导出相似与基准两组：信号日、起止日、价格、完整精度收益、最大回撤、固定阈值、该信号的指标读数、价格口径、币种及来源。样本日期可以在详情逐项查看。

### 解释边界与操作参考

主视图先对比相似组和全部时期的收益区间，再给出持有压力情景。相似样本不足12段时明确提示偏少；12只是提醒阈值，不是统计显著性的门槛。中间50%收益区间重叠时说明不足以单凭中位数择时；即使不重叠，也只提示历史差异仍待验证。这不是假设检验，不能据此声称存在或不存在预测关系。

去除重叠可减少重复计入同一段价格路径，但会减少样本并受起始月份影响，不意味着数据独立。两个组分别去重叠，保留日期可能不同；基准仍含部分相似时期，不能将其称为因果对照。当前条件是今天选出的历史类比，未实施样本外策略检验，历史来源也可能修订。图表与统计不构成已经验证的回测交易系统。

页面的操作参考限于：证据不足时不据单一指标变更既定配置；把相似历史较差四分位和最差回撤作为风险承受压力情景。如果无法承受，应先缩减计划投入规模，而不是用历史上涨比例保证未来获利。这些回撤不是未来损失上限。

方法风险参考：[CFA Institute《Backtesting & Simulation》](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/backtesting-and-simulation)，尤其是前视偏差、历史分布假设及结构变化。这里保留描述性历史情景定位，没有冒称完成该文所述的完整滚动策略验证。
