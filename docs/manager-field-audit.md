## 个人上任日期的修复

东方财富基金经理页的“变动一览”按经理组合划分时间段；有人加入或离任时，即使其他经理仍在管理，组合起点也会变化。因此从首个“至今”行读取起始期会错误低估个人任期。

- 050025：组合最新一段始于2021-09-23；万琼个人明确上任日为2015-10-08。
- 007721：组合最新一段始于2022-03-18；胡超个人明确上任日为2019-09-24。
- 539001：组合最新一段始于2026-07-28；朱金钰个人明确上任日为2021-09-22。

新解析只读取“现任基金经理简介”明确公布的姓名和上任日期，不根据组合表、成立日或证券从业日期推导。已在线取得46只基金的经理原始页，补齐55项个人任职记录；全部55项均有明确日期。9只由多人管理，7只的个人起点不同。

## 字段约定

- `mgr`：完整经理姓名，多人用“、”连接；英文姓名中的空格属于姓名。
- `managerRecords`：逐人 `{name,start,end,tenureYears,tenureText}`。当前任职的 `end` 为 `null`。
- `mstart` / `mten`：只有单人或全部现任经理拥有相同起点时填写；多人起点不同则为空，不能取最早或最近一位冒充团队统一任期。
- `managerTenureMin` / `managerTenureMax`：全员起点均明确时的个人任期范围。筛选满5年应按日期周年比较，不用显示时四舍五入的数字判定。
- `managerCheckedAt`：真实抓取时点；`managerAsOf`：该时点对应的中国日期。源没有给整页发布日期，所以标记 `managerDateBasis:'source_observed_at'`，不冒充正式披露日。
- `managerStartBasis:'explicit_individual_appointment'`：个人上任日期来自明确字段。
- `managerSourceUrl` / `managerSourceSha256`：原始页与原始页面摘要。缓存保存原文与抓取时点。
- `managerDataStatus`：`checked`、`cached`、`refresh_failed`或`unavailable`。离线回放保留原观察日；新抓取失败保留原资料并标出失败。

`tenureText`使用完整年数及剩余天数，例如539001在2026-09-21为“4年364天”，不会先四舍五入成5年参与筛选。`tenureYears`保留日数除以365.2425的数值精度。
