# 境内跨境指数基金

入口：研究对象 / 指数观察 / 第二页签。当前42只基金，指数与渠道均可多选，同一维度取并集、不同维度取交集；空选择表示全部。支持名称/代码搜索、溢价上限、申购状态、收益与费用排序、分页、最多4只并排比较，以及导出当前筛选结果。

## 两种收益序列

- 默认净值：基金每天的净值、供应商每日收益率或明确分红/拆分事件构成的再投财富序列。未计入场内溢价。
- 场内成交价：供应商分红复权收盘价，包含买卖两端的折溢价变化。场外仍按净值。缺成交价复权历史时明确留空，不回退净值并冒充成交价。
- 对同一ETF，两种口径以共同的实际截至日计算；每个周期的实际周年基日随结果保存。历史不足不显示短期冒充长期的收益。
- 管理、托管等产品内部费用已进入收益。投资者交易佣金、申赎费用及投资者税费在投资渠道页另算，本页不扣。

生成器 `scripts/build_crossborder_data.py` 读取基金快照并补齐所需历史，生成 `data/crossborder.js`。定时更新在基金分红事件归档后运行此步骤；浏览器使用静态数据。可用 `--offline` 复算本地缓存。

## 溢价与分红

快照溢价来自交易行情相对IOPV的报价，按快照日期独立展示；跨境交易时差意味着它不是最新海外收盘净值的实时精确溢价。溢价上限只筛选场内ETF，缺报价的场内产品被排除，场外基金不受此项限制。它与“是否将溢价纳入历史收益”是两个独立控制。

### 2026-10-09 全程溢价检查

“剔除溢价”使用整条基金净值总回报路径：指数观察的区间起点与终点、投资渠道每次定投及期末卖出、组合模拟每次投入及再平衡都按该路径计算。基金研究的收益与风险也来自每日净值。投入策略当前使用美股ETF复权股价，没有境内场内溢价调整。快照溢价只用于展示、排序和筛选，不参与历史收益计算。

在没有分红或拆分的简化例子中，若起点净值100、成交价120（溢价20%），终点净值110、成交价143（溢价30%）：成交价收益为19.1667%，净值收益为10%。两端调整公式是 `(终点成交价 / 起点成交价) × (1 + 起点溢价) / (1 + 终点溢价) − 1`，不能直接用历史收益减当前溢价。存在分红、拆分或多次投入时，使用完整再投净值序列逐笔计算，不应用这个简化端点公式。

回归检查覆盖两端均有正溢价、定投时中间溢价变化、当前溢价变化不改写历史，以及组合目录中所有境内基金/ETF整条历史均为净值口径。ETF实际买卖仍按成交价，净值情景是用于比较基金本身回报的假设。

现金分红均按再投资总回报处理，份额拆分只调整份额，不增加财富。底层证券股息已经反映在QDII净值中；本基金的对外现金分配另按事件再投，不重复加在复权序列上。国泰160213现金分红与国泰513100拆分不可混淆，具体官方公告见[投资渠道方法](buy-location-method.md)。

`fund_evidence.py` 合并带来源的分红档案与历史净值中的明确事件；较新的事件列表若遗漏历史拆分，不删除已有来源证据。详情的“未见现金分红”仅指所收录历史，不能解释为该基金不会分红。页面可逐只查看现金额、除息日、拆分比例、采集日期和原始链接。

“场外可申购”按快照状态判断，包含限额申购；限额在表格显示，不能据此推断任意金额都可买。LOF在本页按收录的场外份额路径归类，场内LOF交易费与溢价未单独收录。

## 159941历史拆分修复

2026-09-29核验发现，行情供应商的最新分红拆分列表漏掉了159941的2022年拆分，定时刷新曾以空列表覆盖旧事件，导致5年、10年回报与风险计算失真。已按[广发基金正式拆分结果公告](https://www.gffunds.com.cn/jjgg/zdsj/202207/t20220705_376047.shtml)在 `data/fund-actions.json` 保存带标的、净值日期、交易所除权日、比例、公告日与官方URL的 `verifiedEvents`。日常归档保留这些核验事件，历史净值填充也优先应用；无本机缓存、较新供应商空列表两种情况均有回归测试。已重算同一截至日的原基金快照，保证基金研究与跨境页一致。
